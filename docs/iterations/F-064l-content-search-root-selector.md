# F-064l 单文件夹正文搜索的根选择

## 功能

正文搜索面板可通过 `root:` 指定当前窗口的一个顶层文件夹，并与 `file:`、`path:`、`-path:` 混用。没有 `root:` 时沿用文件树选中的顶层文件夹。根名按完整名称区分大小写匹配；同名根必须用完整显示路径区分。选择器同时显示根名和路径，并将对应的 `root:` 条件回填到同一筛选栏。选择另一根会替换原根条件，保留其他筛选。

未加入、同名歧义和扫描未完成各有明确提示。筛选合计最多八条，其中最多一条根条件。此轮每次查询一个根，延续 16 篇和 64 KiB 边界。

## 最小实现

1. 共用解析器读取根别名和原 token 范围。选择器替换原范围或追加根条件。保留原有路径和文件名条件的写法与顺序。
2. 只在当前窗口的工作区快照中按根名或显示路径匹配别名，解析到当前根的 opaque handle 和扫描代。RPC 沿用已验证的单根请求，别名和显示路径不随请求传输。
3. 显式根别名必须在整个查询和定位期间解析为同一个根句柄。根移除、重加、别名变歧义或扫描代改变会使旧结果失效。当前目录扫描和定位授权守卫继续生效。

## 最小验收

- 加入两份同名根和一份唯一根。手输同名根名有歧义提示，选择器生成完整路径后只查询该根。切换另一根时保留其他筛选。手输唯一根名有效。
- 自动覆盖未加入的路径、重复根条件、混合上限、根删除后同路径换句柄以及未完成扫描。真实窗口核对筛选前后覆盖、定位和正常退出。

## 继承约束检查

- F-002 沿用本地授权与查询。离线留最终人工。
- 中文与外观沿用中文错误提示和原有主题。
- 命令与键盘沿用搜索表单和语义选择器。
- 安全与日志方面，根别名只匹配当前工作区中的根，既不扩展授权，也不进入日志或 RPC。

## 实际验收

- macOS arm64 unsigned canary `0.1.0-alpha.199`，包标识 `3dqmimmm98w0t`。隔离 WK 窗口加入两个名为「笔记」的根和「唯一目录」。输入 `file:内容 root:笔记` 显示同名歧义并禁用查询。根选择器列出完整路径，选甲组和乙组时各覆盖一篇，两次命中均打开对应目录的文件并定位。切换根保留 `file:内容`，旧结果清除。
- 手输唯一根名覆盖该根一篇。未加入的完整路径提示并禁用查询。清空根条件并选中文件树中的甲组根后，普通查询恢复覆盖一篇。三个测试文件 SHA 不变，窗口正常退出，查询临时目录为空。退出期间观察到一次系统 IMK 日志，窗口和进程正常结束。
- 规格与规范独立复核无阻断。源码定向 27 项通过，包内 Bun 1.4.0 配合原生资源定向 24 项通过，另有 5 项条件外层跳过，由隔离子进程执行。根替换和扫描代变化由定向测试和代码复核覆盖，实际窗口未进行根移除重加。深色、自然 IME 和最终离线未复验。
- 源码全量 1851 项通过、7 项条件跳过、0 项失败，共 38,831 断言。既有 FINAL-ISSUE-002 本次通过，仍保留历史问题记录。类型、Lint、文档、义务登记、锁文件和差异检查通过。
- 本片范围为一次一根。跨根查询、完整持久索引和四项延期义务继续承接。
