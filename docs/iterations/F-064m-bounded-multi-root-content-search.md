## 范围

工作区内部查询可接受一组已授权的根句柄和扫描代。所有根共用一个索引会话，返回一份覆盖与打开文档配对。任何根失效都会废弃整次查询。现有单根 RPC 和窗口继续使用单根入口，聚合结果的分组、搜索范围控件与持久缓存分片承接。

本片最多核对 16 个根，筛选前合计最多 16 篇。筛选后的候选共用 64 KiB 正文预算。每个路径条件相对其所属根解释。重复根、重叠根、重复绝对路径或条目句柄应拒绝；不同路径的硬链接继续沿用按路径区分的身份规则。

## 最小实现

1. 查询开始时一次性捕获全部完整根，拒绝失效或不完整的根。所有根共享同一文档授权准入票据。原快照守卫与取消信号共同决定整个批次是否仍有效。
2. 将已筛选条目按授权根交给既有原生索引适配器。逐根核对目录授权，再读取各根内的文件。正文、写入、查询、关闭与临时目录清理都使用同一个会话。没有候选的根仍需核对权限与版本。
3. 打开文档按 canonical path 找到所属根，再核对文件身份、版本与扫描条目。已确认在全部查询根之外，或经完整核对后被筛掉，才标记为范围外。未知配对、废纸篓隔离和原生结果未知继续按既有规则处理。

## 最小验收

- 原生隔离测试用两个不相交的授权根查询同名文件，覆盖各根、UTF-16 位置、相对路径筛选和已打开文档配对。
- 验证重复根、无效扫描代、超限、取消和零候选根失效。结果必须是整次拒绝或完整覆盖。复跑单根查询、原生关闭和未知状态路径。
- 正式包的 Bun 与原生资源复验内部聚合。真实 WK 窗口回归已有单根查询及退出，跨根界面留后续切片。

## 实际验收

- macOS arm64 unsigned canary `0.1.0-alpha.200`，包标识 `2fg73oqg47xhc`。包内 Bun 1.4.0 配合正式原生资源复跑 11 项通过，6 项条件外层跳过由隔离子进程执行。另单独复跑多根场景，26 条断言通过。
