## 功能说明

重启并重新授权目录后，如果本次恢复的单篇主区文档正文已经变化，优先回到此前看到的 Markdown 内容块。原块不可辨认时，按可辨认的邻近块、源码位置和滚动比例依次回退。

## 最小方案

- 复用已授权读出的当前正文和原检查点，正文摘要相同时沿用原视口坐标。只有正文变化且有内容块记录时，才将当前位置计算交给现有 Bun Worker。窗口收到有效坐标、偏移和比例。
- 优先使用原块及实测偏移。邻近块或缺少块偏移时，从所选块起点恢复。无可靠结果时沿用源码坐标和比例。交付前复核文档与检查点的有效性，保持已有记录。
- 取消、窗口导航或暂停恢复时中止单篇的后台计算，释放本次打开凭据。正常交付继续使用既有的标签和视口协议。
- 本轮接入单篇标签。成组恢复继续使用已有位置逻辑。

## 最小验收

- 用已保存块记录的合成文档，在关闭窗口后原地前插正文。重启、重新授权并恢复单篇后，核对原段落仍出现在窗口中。
- 删除原段落，核对可辨认的邻近块。定向验证重复块、无有效块、旧格式、迟到回执与授权失效，核对正文和检查点原字节。
