## 继承约束检查

- F-002：本轮只读取磁盘，编辑仅在内存。没有保存、转码、恢复文件或正文持久化；本地核心离线，延续 1 MiB 验证边界，超限不截断。样本字节/hash 前后核对。
- 中文与外观：验证入口、未保存提示和确认均中文；CM6 接入浅/深/系统语义色，不因主题切换丢失 buffer（内存正文）、选区或撤销状态。
- 命令与键盘：关闭/清空/重读沿用统一命令入口与实时状态；输入、选择、复制粘贴及基础键盘行为由编辑器处理，不扩大成完整 F-014 或 F-041 验收。
- 安全与日志：Markdown 仅作文本输入，不执行 HTML、链接、脚本或资产加载；RPC 新载荷有运行时校验，失败安全拒绝，不记录正文或路径。正常退出、主窗口关闭、应用刷新、更新重启不得绕过保护；强制终止/崩溃恢复不在本轮。

## 1. 功能说明

- 用 CodeMirror 6 原文编辑验证入口替换只读正文，支持输入、删除、选择、复制粘贴。界面明确“当前编辑尚不支持保存”；不是完整即时预览编辑模式、正式源码模式或新增第四种产品模式。
- 每个文档有独立内存正文、编辑版本与磁盘基线；标签切换/重复打开不能替换未保存内容。选区和滚动随标签保留，未保存标识由当前正文与基线关系得出，不独立维护易漂移布尔状态。
- 本片完整承接 OBL-062：保持 BOM、未触及混合 LF/CRLF、孤立 CR 和结尾属性；用户明确编辑目标范围可改变相应字符。新增换行采用光标上下文，不能全篇规范化。
- 关闭有变更标签确认放弃该文档；清空、关闭主窗口或退出一次确认全部；有变更时重读先确认。无变更不弹框，取消不修改正文、标签、集合、基线或授权。
- 应用刷新、更新重启须经同一保护；同路径被替换后重新选择也不得静默丢弃原标签内存修改。确认期间不能发生未纳入授权的新编辑再被丢弃。
- 不提供写盘保存、即时排版/标记显隐、正式模式切换、完整撤销/输入法专项、会话或崩溃恢复。仅建议测试文件，确认放弃或异常退出会丢失内存修改。

## 2. 最小技术方案

- 编辑状态按 documentId 独立保存；区分 bufferRevision、磁盘快照 revision/hash 和原始正文。当前原文唯一真源仍为磁盘；内存修改不是另一套持久正文库。
- CM6 内部行结构与原始字节文本之间使用明确的坐标/换行保真适配；先用混合换行/BOM/删除跨行/粘贴/撤销测试验证，而不假定控件默认字符串转换无损。局部 transaction（编辑事务）只改变对应原文范围。
- 主区只挂载活动 EditorView（编辑视图），非活动文档保留状态；不为无消费者场景提前创建 Worker 或缓存系统。不冻结性能门槛，记录实际验证。
- 防丢决策由当前编辑状态统一提供，异步确认取消时不执行破坏性动作。原生退出、窗口关闭、刷新与更新重启通过受控握手请求前端批准；异常/超时不当作同意。清理必须在批准后发生，避免关闭事件到来前先丢正文。
- 最小新增依赖限定 CM6 所需包并记录实际锁定版本。代码构建前递增 alpha，构建后核对产物版本。
