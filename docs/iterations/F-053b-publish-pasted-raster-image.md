# F-053b 发布粘贴位图并插入链接

> 状态：alpha.274 已由 Agent 受托验收。前置为 F-053a 的有限入站验证。

<!-- deferred-obligations: none -->

## 功能说明

在主窗编辑模式中，向当前已授权工作区精确覆盖、已保存且可写的文档粘贴单张 PNG 或 JPEG。应用先将图片复制到 Markdown 同目录的 `./assets/`，再用相对路径插入图片语法。现有文件始终保留，同名时生成安全后缀。图片链接可用一次撤销移除，磁盘上的图片由用户管理。

本片只接管单张位图、没有文本或 HTML 内容的系统粘贴。Finder 拖入、混合剪贴板、源码模式与资产目录模板由后续切片承接。主窗普通文本粘贴、源码纯文本粘贴及强制纯文本行为沿用原路径。依据 [F-053](../mvp-product-spec.md) 和 [E-24、E-25、E-25a、E-25b](../product-capability-register.md)。

单独选择文件的授权只覆盖文件本身。F-015 的同目录暂存服务于替换该文档，F-022 的资产授权只读。正式粘贴先使用完整且仍有效的工作区扫描条目和创建租约，随后在文档写屏障中复核。独立文件的资产写权限另行承接；已有 `assets` 本身不授予权限。

## 最小方案

- **入站前置。** [F-053a](F-053a-paste-single-raster-image.md) 已验证系统 PNG 入站、1,043,090 字节端到端和 1 MiB 上限两侧。正式入口重新核对自己的限制及已验证覆盖，不能把源端恰好 1 MiB 的回执写成真实 WK 剪贴板证据。
- **实施顺序。** 先实现不接 RPC 的 Bun 内部文件发布，以可信工作区创建目标和已验证的现有 `assets` 为输入。其后补缺失目录的排他创建与父目录同步，再接工作区租约、文档写屏障和编辑事务。
- **编辑入口。** 在 [`memory-editor.tsx`](../../apps/desktop/src/components/memory-editor.tsx) 的现有 CodeMirror 视图接入系统粘贴事件。接纳前核对当前文档、激活代、视图、编辑模式、正文版本和单个选区，并预留插入链接所需字节。脏文档提示先保存。只读、无文档、忙碌、冻结、失效视图及 IME 组合期间不发请求。普通剪贴板内容仍由原入口处理。一次仅处理一个粘贴意图。
- **Bun 授权。** 在 [主窗 RPC](../../apps/desktop/src/bun/rpc/index.ts) 接收请求标识、已有文档授权句柄、文档 ID、保存版本、摘要和位图数据，目录、文件名及路径均由 Bun 决定。通过 [DocumentService](../../apps/desktop/src/bun/documents/index.ts) 的 `withCreateBarrier` 等待保存收尾，核对原授权和版本，复用 `verify`、`capability`、`stableBytes` 验证目录授权、当前磁盘正文摘要及写能力，并检查废纸篓隔离。以 Markdown 的规范父目录为基准，固定子目录为 `assets`。目录不存在时使用 [`create-folder-disk.ts`](../../apps/desktop/src/bun/workspace/create-folder-disk.ts) 的私有暂存及排他发布；已存在则由持有的父目录描述符用 `openDirectoryAt` 打开，拒绝符号链接或非目录。图片必须通过 [`imageFormat`](../../apps/desktop/src/bun/documents/image-format.ts) 的 PNG/JPEG 结构及 16 MP 限制，扩展名从检测结果派生。
- **排他写入。** 沿用 [`duplicate-disk.ts`](../../apps/desktop/src/bun/workspace/duplicate-disk.ts) 的描述符写入和复核顺序。通过 [`save-primitives.c`](../../apps/desktop/native/save-primitives.c) 的 `createTemp` 创建私有暂存文件，写入并同步，复核字节、文档及目录身份，再以 `publishExclusive` 调用 `RENAME_EXCL` 发布。只在明确收到 `PUBLISH_EXISTS` 时尝试下一安全 ASCII 后缀，次数有上限。同步目标目录，并通过 `openFileAt` 复查已发布文件身份和摘要后，才返回已确认的相对图片名。明确不支持排他发布时拒绝写入，通用 `PUBLISH_FAILED` 以及发布后同步或复核失败按结果未确认处理。
- **提交链接。** 收到确切回执后重查原文档、视图、版本、模式、选区及 IME 状态，从当前 CodeMirror 状态经 [`updateEditor`](../../apps/desktop/src/client/documents.ts) 提交一笔独立撤销的图片链接事务。任何未确认回执均不改正文、不自动重发。目录可早于图片创建成功，后续失败时可能留下空目录。若图片已发布但编辑意图过期、事务被拒绝或回执迟到，保留图片并提示链接未插入。关闭、放弃编辑或撤销均不删除已发布资产，也不按文件名清理身份未确认的暂存对象。

## 最小验收

- 先以真实包主窗核实系统剪贴板位图入口和入站字节摘要。产品接通后，用合成 Markdown 文件验证缺失与已有 `assets` 两种情况。确认相对链接可在编辑模式呈现，保存前磁盘 Markdown 字节不变，一次撤销恢复原文并保留图片。制造一次目标同名，核对旧文件字节不变，新文件使用后缀。
- 定向覆盖无正文授权、已变化的磁盘摘要、只读、未保存、组合输入、忙碌或冻结、伪装格式、超限、`assets` 符号链接和确定冲突。分别控制发布前授权变化、发布后编辑器切换及不确定回执，核对正文、图片和提示各自状态。文本粘贴走现有行为。实测和注入证据分别记录。

## 继承约束检查

- F-002 本机剪贴板和文件写入，离线专项留最终人工。
- F-004、F-015 继续使用原文档授权和写屏障。只发布到已验证的固定子目录，绝不覆盖现有文件。
- F-014 链接经过现有事务和撤销历史。F-022 只展示受控本地 PNG/JPEG，独立阅读窗资产接入留后续。
- 中文与外观沿用现有编辑主题和中文提示。
- 命令与键盘沿用系统粘贴，不添加快捷键。
- 安全与日志不记录剪贴板正文、图片字节或实际路径。

## 当前验证

- 新内部发布函数在已有 `assets` 时使用描述符相对打开，缺失时仅按确定的 ENOENT 进入排他创建。父目录同步及重新打开的身份确认完成后，才可暂存图片。目录或文件结果不明确时保留现场，调用者得不到可插入的路径。
- 在 alpha.273 的 Bun 1.4.0 中运行源码定向测试，仓库测试加载的原生保存资源与包内逐字节相同。全链定向 25 项、274 条断言通过。覆盖原文件同名保留、后缀次数、链接或替换、目录并发与发布不确定、图片发布前后授权失效、当前工作区授权及请求重放。目录同步实际运行，未单独注入同步失败。
- 正式主窗接管可识别的纯位图粘贴。发写请求前还需能把图片插在普通单行段落或独立空行，预估真实 UTF-8 文档大小。选区、模式、文档、组合输入或工作区授权变化会废弃旧意图。序号只在当前窗口维护，重载后先读取当前序号。回执已确认的图片用独立编辑事务插入，超时不自动重发。
- 2026-11-07 在 macOS arm64 unsigned alpha.274 / `2lqom689iif70` 正式包中，以真实系统 PNG 剪贴板分别验证创建 `assets` 及复用已有目录。726 字节小图和 1,043,090 字节近上限图，磁盘资产的 SHA-256 与独立剪贴板接收的字节一致。正文显示安全相对链接并标记未保存，编辑位置离开后显示图片组件。一次撤销使正文回到已保存，磁盘图片仍在，原 Markdown 和已有 `keep.txt` 的 SHA-256 不变。
- 系统剪贴板 1,049,234 字节图被拒绝，普通文本粘贴与撤销有效。仅单独打开的测试文件显示需要工作区授权，磁盘未创建其相邻 `assets`。真实同名原生冲突和未知结果在定向测试覆盖，未在界面制造冲突。没有真实 JPEG 剪贴板或自然 IME 的本轮实操证据。测试只写入合成文件及合成剪贴板。
- 同包归档摘要及包内全量结果见 [F-022d](F-022d-one-authorized-image-in-independent-reader.md)。既有长空白超时仍保留。
