# F-037e 跨进程验证主区标签恢复候选

## 功能说明

验证两个独立进程能串起已保存主区标签的采集、目录来源核对、元数据读回及重新授权后的候选匹配。

## 最小方案

- 在隔离目录中使用真实主区文档控制器、工作区及根名册。第一个进程打开两份同名目录中的合成文档，设置顺序、模式、固定状态和活动项，采集并写入隔离会话记录后退出。
- 第二个进程只读历史记录，确认目录仍待授权。以相反顺序重新选择目录，按原标签索引核对当前候选。用受控选择器回调提供合成路径；不会自动打开候选，也不会替换缺项。
- 父测试在两进程之间替换一篇同路径文件。记录原字节不变，当前授权和扫描都完成后，被替换的文件仍不能继承旧标签。

## 最小验收

- 分别使用本地及正式包中的 Bun 跑两进程演练。核对进程退出码、历史标签状态、早期回执失效、被替换位置缺失和未创建文档授权。
- 本片仅新增测试。沿用同包正式 WK 普通打开、退出证据，受控选择器回调不作为真实系统交互验收。

## 继承约束检查

- 中文与外观没有变化。
- 命令与键盘入口没有变化。OBL-054 留正式恢复入口。
- 安全与日志验证只使用合成夹具。正式会话写入时机、启动入口、未授权项处理和草稿恢复仍开放。

## 实施与验收（2026-11-10）

- 写入进程经真实主区控制器打开三篇合成文档，写下顺序、固定状态、模式及活动索引。读回进程最初有两个待授权根，当前根、文档授权和打开标签均为零。两个同名根反序重新选择，首次回执随根名册变化失效；重新取得的候选对应原索引 0 和 2。中间被替换的文件没有候选，未把其余项补到这个位置。
- 两个进程退出码均为 0。历史记录字节和未替换文档均未改变；读回结束仍未建立文档授权或打开标签。源码 Bun 与 alpha.292 实物包内 Bun 分别通过 1 项、16 次断言；完整类型检查及涉及文件的 Lint 通过，独立复核无阻断。
- 仅增加隔离测试，未重打包。正式窗口只沿用 [F-037d](F-037d-bind-main-tab-session-metadata.md) 同包普通打开和退出的证据。
