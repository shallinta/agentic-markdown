## 功能说明

普通窗口正文搜索在选定一个文件夹，并输入 `file:`、`path:` 或 `-path:` 筛选时，可以先缩小目录范围，再读取匹配文档。适用于目录超过 32 篇、实际只需搜索其中一部分的情况。

## 最小方案

1. 前后端使用相同的准入规则。单根目录超过 32 篇且有文件名或路径筛选时，可从最多 256 个已扫描条目中缩小范围，文件和目录都计入。原来支持的 32 篇以内目录继续按现有范围处理。
2. 对完整的有界扫描快照应用现有筛选。筛选后最多读取 32 篇、单篇 64 KiB、合计 128 KiB。未匹配的文档不读取正文。保留快照、打开文档的权限与未保存内容映射核验。
3. 无文件名或路径筛选、当前窗口混合范围、原生索引和筛选选项列表沿用已有边界。正文命中使用现有定位流程。

## 最小验收

- 33 篇以上的真实目录中，无条件整根查询仍受限。输入文件名或路径条件后，只搜索符合条件的正文，能打开并定位目标。无关的超限文件不影响筛选结果。
- 筛选后仍超过 32 篇、需要扩展且目录条目超过 256 个，或匹配文件超限时拒绝。检查前后端规则、旧扫描失效和混合范围。
- 正式包复跑，实际 WK 从筛选前拒绝切换到筛选后命中、定位并退出。
