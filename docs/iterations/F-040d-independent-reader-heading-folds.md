# F-040d 独立阅读窗标题折叠

> 状态：alpha.297 受托代验通过。

<!-- deferred-obligations: none -->

## 功能说明

在独立阅读窗的顶层标题左缘提供折叠箭头。折叠只隐藏本章节后续内容，标题保持可见。切换父章节不清除子章节的折叠选择。折叠状态属于当前阅读窗口，不写正文，不联动主窗。

## 最小方案

- 只在普通独立阅读快照启用顶层章节投影。箭头用鼠标和键盘均可操作，展开时在标题悬停或按钮聚焦时显示，收起时常显。按钮与根块由阅读窗登记并核对结构，不接受文档提供的控件。安全纯文本降级和实验窗不加入口。
- 保留正文节点、查找登记与图片状态。折叠只更新受控根块的显隐及按钮状态。主题切换与视口测量使用可见块；查找高亮请求跳过隐藏范围，全文计数与上下项导航不变。
- 用户明确跳转到隐藏命中时，只展开包含它的祖先，再测量位置并滚动。常规查询、滚动和主题切换不解除折叠。过期的高亮回执不覆盖当前视口。

## 最小验收

- 真实窗口验证 ATX、Setext、父子章节、鼠标和键盘、查找展开目标祖先，以及主题锚点、代码复制和图片回归。核对正文不变。
- 定向验证隐藏的 2048 条以上命中不占可见额度，晚回执不重画旧视口，伪造控件或结构不纳入审计。嵌套容器标题、大纲、跨窗状态和最终离线留后续。
