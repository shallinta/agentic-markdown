## 本轮范围

先交付 Bun 内部服务的一次性授权快照：对一个已完成扫描的目录根，从当前工作区文件集合读取有限样本，提交到 F-064d 索引并查询。使用显式内部调用和自建测试根验证。工作区搜索界面、筛选、跳转、跨根搜索、未保存文本和监听增量由后续切片承接。

## 接入边界

- 工作区服务掌握根、代数和条目映射。内部入口只接受现有根句柄及扫描代数，调用者不得提供磁盘路径或缓存路径。扫描进行中、暂停、失效或撤销时拒绝建立索引快照，禁止把不完整集合当作已完成扫描。
- 以当前扫描文件表为准，复用 `workspace/authorization.ts` 的 `authorizeEntry`，核对根及父目录链、条目指纹和当前隐藏策略。实现前从 `documents/index.ts` 的 `stableBytes` 核对描述符读前、读后与 UTF-8 保真所需约束，保持读取服务和可见文档状态分离。每个描述符都须在完成或失败后关闭。
- 捕获根代数及条目身份，在读取前后、提交前后和查询结果返回前检查快照是否仍有效。取消或失效后隔离结果。若提交已经进入不可撤回阶段，等待原生回执后关闭并废弃该会话，遇到 UNKNOWN 禁止自动重放。文件外部修改的检测依赖描述符校验与已有扫描生命周期，本片不承诺实时增量。
- 复用 `index/session.ts`，仅接受根句柄、扫描代数和查询词。内部用服务端生成的索引 ID 映射扫描条目句柄，索引不存真实文件路径。预检现有 `INDEX_LIMITS`（16 文档、65,536 字节正文、70,000 字节请求），单批提交，超限或读取失败均拒绝整个快照。全进程同一时间只接受一次快照查询。
- 缓存使用系统临时目录下的固定私有槽，通过原子创建目录取得独占权。已有槽直接拒绝并保留内容。查询后等待关闭回执与 Worker 正常退出，再回收自己创建的槽。若关闭状态未知，保留槽并拒绝本进程的新快照查询。产品持久缓存的配额、重用和迁移留到后续。

## 验证

1. 用自建根走实际扫描、授权读取、正式原生提交和查询。断言命中 ID 和 UTF-16 范围正确，确认未产生可见标签页或新增长期文档授权。
2. 覆盖过期代数、扫描未完成、隐藏条目、替换/符号链接，以及读途中撤销根。断言没有未授权结果，描述符全部关闭。
3. 覆盖超文档数、超正文或请求大小，验证无部分提交。注入提交或查询等待点，验证根变化及关闭后的迟到结果不可交付。保留 native UNKNOWN 后禁止自动重放的验证。

## 当前实现与待验

内部入口位于 Bun 工作区服务。单次调用完成授权读取、索引提交、查询及收尾，命中仅返回工作区扫描条目句柄及 UTF-16 区间。测试把真实扫描与原生索引放在一个隔离子进程中，另用传输模拟子进程验证提交和查询期间的失效以及关闭状态未知时保留缓存。两组子进程分别使用测试自建的临时目录。

源码测试使用现有原生产物。需重新构建应用，并在新包中核对资源解析和内部链路，才能记录本片的包验结果。

主线全量测试记录为 1804 项通过、2 项由外层条件跳过、1 项失败。唯一失败是已登记的 FINAL-ISSUE-002 长空白测试超时。两组工作区测试均在各自子进程内执行通过。打包所需的 Rust 1.90.0 固定组件首次下载在 180 秒后超时，已另起重试。
