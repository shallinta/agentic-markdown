## 功能说明

重新授权后，成组恢复的主区标签也能在正文变化时定位原内容块。找不到可靠的原块时，沿用邻近块、源码坐标和滚动比例的回退顺序。

## 最小方案

- 使用成组恢复已授权读出的各篇正文，沿用现有后台解析。优先处理原活动标签，其余按标签顺序处理。同一组共享 5 秒后台解析时限，剩余位置沿用已有坐标和比例。这一时限只约束位置解析。
- 每个结果只用于对应标签，整组继续按原顺序交付。取消恢复时中止后台计算，完成交付前重新核对文件和原检查点。

## 最小验收

- 在普通窗口保留两篇带位置的标签，退出后分别前插正文及删除其中一篇的原块。重新授权后核对活动标签、原顺序、两篇各自的定位及正常退出。
- 定向验证跨目录、取消、过期文件和检查点、后台时限及未变化文档。核对测试正文和检查点原字节。

## 继承约束检查

- 中文与外观沿用普通窗口。

- 安全与日志验证位置归属、文件交付凭据和原检查点保全。
