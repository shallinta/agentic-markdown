## 功能说明

普通主窗成功固定、取消固定、重排持久标签或切换编辑与源码模式后，如果整组仍符合会话记录条件，就更新记录。无需再切一次标签。记录仍只包含顺序、固定状态、模式和活动项。

## 最小方案

- 文档控制器在已有操作成功提交后发出轻量通知。键盘和鼠标共用原操作；无效放置、无变化和普通键入不触发。
- 复用 F-037g 的合并、单请求、同份去重及 F-037f 的授权写入。会话通知与最近使用顺序独立，不制造新的文档激活。
- 未保存、空记录和非目录授权保持原记录。此次不接显式关闭后的清理、启动恢复、副区、草稿或离线。
