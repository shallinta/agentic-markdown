# F-037m 重新授权目录后恢复单篇标签

> 状态：alpha.334 普通窗口代验通过。

<!-- obligations: none -->
<!-- deferred-obligations: OBL-034, OBL-054 -->

## 功能说明

普通窗口重启后，用户从「待重新授权的目录」重新选择原目录。如果窗口尚未发起打开文档或加入其他目录，且上次会话只记录了该目录中的一篇文档，就在主区恢复该标签原来的模式和固定状态，显示文件当前正文。用户选择其他目录时，仍可按原流程加入目录。

## 最小方案

- 关联用户点击的历史目录 ID 与本次选择真正新增的根。等待该根同代扫描完成，再走 F-037l 的读取校验。只处理这次明确的重新授权，后续选择、换代或先行打开文档使意图失效。
- 普通主窗通过单个受保护的 RPC 请求取得回执。窗口使用现有文档加载保护，在首次显示前一次性应用模式及固定状态。采纳成功才交接授权，过期或放弃的请求释放本次新增授权。释放结果未知时保留隔离状态，当前页面不再接收新恢复请求。每页保留至多 128 个请求标识，已取消的旧请求即使迟到也不能重新打开文档。
- 启动、退出及普通加入目录沿用现有流程。恢复不算一次用户激活，历史记录的主动认领和关闭失效另行接入。

## 最小验收

- 普通 WK 在一个进程中加入合成目录，打开并固定一篇源码文档，等会话记录落盘后退出。第二个进程初始为空，原生重新选择正确目录后恢复当前正文、源码模式和固定状态。
- 验证取消、选错目录或已先打开文档时保留各自状态。定向覆盖窗口生命周期、过期回执释放和历史根身份。核对 Markdown、会话记录及 MRU 的相关证据。

## 继承约束检查

- F-002：本地授权及读取，最终离线留人工。
- 中文与外观沿用现有目录和文档控件。
- 命令与键盘沿用「重新选择」，无需新入口。
- 安全与日志：历史路径仅参与核对，正文按既有受保护传输。
