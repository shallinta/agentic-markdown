## 功能说明与范围

为已确认的 F-028 clean 文档自动刷新准备无副作用的外部版本候选：对当前进程已打开、仍获授权且叶文件身份未改变的 Markdown 文档，有界读取真实磁盘正文，并将候选绑定到当前文档身份、授权生命周期和已接受的磁盘基线。候选可以检查有效性及丢弃，但本片没有接受候选或推进基线的入口。

本片是自动刷新的必要安全前置，不改变产品决定。F-027a 继续只提示变化；当前窗口正文、模式、选区、撤销历史、dirty、磁盘基线、mirror 和 revision 都不因取得或丢弃候选而变化。普通 1 MiB 读取边界、UTF-8/BOM/换行保真与授权边界不变。候选不是正文真源，也不代表其取得后磁盘不再变化。

不接自动刷新 UI，不新增实验台或正式命令；优先通过真实 Document Service 与临时文件集成验证内部能力，不为了展示基础接口扩大窗口范围。不得把服务集成测试写成真实窗口自动刷新验收。

## 最小技术方案

1. 从现有服务抽取或复用无提交的受控读取步骤；不得调用会推进 baseline/mirror 的现有 `read` 路径冒充候选读取。使用当前 opaque handle，而非调用者传入任意路径。
2. 请求捕获 documentId、授权 lifetime、预期已接受 revision/hash 与候选请求代次。读取前后复核授权、祖先/叶文件身份及读取一致性，使用有界读取和真实内容 hash；身份替换、缺失、越权、非法编码或超量返回明确失败，不猜 rename，不重授权替换后的文件。
3. 候选绑定旧基线与实际读取版本；返回前再次复核生命周期及旧基线，期间保存、释放或授权换代须使旧结果失效。候选 hash 相同可收敛为无变化，不生成新的已接受 revision 或 mirror。
4. 候选按已打开文档生命周期有限持有，每文档仅保留最新候选/请求；请求合并、队列与并发采用现有调度能力，保存不被候选读取饿死。丢弃、后续候选替换、保存换代、关闭/释放和服务销毁清理持有数据；取消不冒称可中断已经阻塞的底层文件系统调用。不新增永久退休 token 集合或产品文档数量上限。
5. 候选检查只证明其文档身份、授权生命周期与已接受基线绑定仍有效，不证明该候选仍是磁盘最新内容；即使检查成功，磁盘也可能再次变化。该检查不执行接受。未来消费者必须另行复核并处理提交竞态；本片不提供绕过保存基线校验的写接口。候选失败不得删除原内存或把失败状态当作 unchanged。
6. 本片以内部服务接口和集成测试为交付面；没有当前消费者需求时不提前增加 RPC、窗口 UI 或实验开关。日志只含必要诊断，不输出用户正文、敏感路径或候选全文。

## 最小 happy path 与边界验证

- 真实临时 Markdown 经现有服务打开后，同身份外部修改，候选取得最新正文/hash；原 documentId、已接受 revision/hash、mirror 及既有读取快照不变。丢弃后再次请求可取得当前磁盘内容。
- BOM、LF、CRLF 与中文样本保真；相同内容、非法 UTF-8、超过现有读取边界均按既定语义处理。
- 候选读取期间保存换代、释放、后续请求替换与销毁：晚结果不能成为当前有效候选，不回退服务基线、不泄漏持有资源。
- 真实临时文件 missing/replaced、父目录或授权失效：不读取替换目标正文、不扩权，原基线和服务保护保留。
- 多文档及事件密集场景验证 latest-only、队列有界与保存优先；记录实际测试规模、耗时和限制，不设新的性能门禁。
- 回归保存前外部冲突保护：取得或丢弃候选不能让旧基线写入成功，亦不改变 F-027a 的观察/风险状态。
- 故障注入与真实文件测试分开记录；独立复核后才能标内部切片受托代验通过，不冒称用户亲验或自动刷新产品体验通过。

最初仅建立方案草案；主线确认及独立 Spec 最小方案无阻断后，实施如下：

- `TrustedDocumentService` 新增内部 `readRefreshCandidate`、`checkRefreshCandidateBinding` 与 `discardRefreshCandidate`，未增加 RPC、UI、实验开关或用户命令。
- 复用现有 snapshot 的授权、保真、有界读取步骤，但不执行 commit；只提取正文/hash/字节数/fidelity，候选不含已接受 revision 或 mirror。请求与返回分别复制，嵌套 fidelity 与私有候选隔离。
- 独立队列全局单候选读取、每文档最新意图/候选；不占用既有前台 read 的 running/pending 槽，因此保存不会因候选任务被判 BUSY。前台已有任务、保存与写屏障期间不开始候选任务，活动任务每个读取阶段及返回前检查有效性。保存入队即失效相应文档候选，普通 commit、释放/撤权及销毁同样清理。
