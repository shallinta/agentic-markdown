## 1. 功能说明

1. 提供显式启用的实验入口，默认正常启动不运行基准，不增加日常后台负载。
2. 比较 1/10/50 MB（十进制字节）的合成文本在真实 WebView、Bun、Worker 链路中的全量、分块和小范围 patch 成本；报告基线建立成本与后续 patch 成本，不以小 patch 替代首次全量加载指标。
3. 先探测 RPC 是否保留二进制类型与内容；不支持则明确记录，不用 JSON 数字对象冒充原生二进制。Bun/Worker 的 clone/transfer 可以独立比较，但不能声称是 WebView 原生二进制传输。
4. 记录端到端往返、可观测阶段、CPU、内存采样、有效载荷与编码尺寸、取消后状态释放。无法直接观测的复制次数、WebView heap 或单向传输时间标记不可用，不制造精确数据。
5. 复用当前原文编辑状态对大文档和异常超长单行做建立、局部编辑、撤销与原文保真检查；实际视口操作与状态层耗时分开。没有完整 Markdown 解析/装饰的结果不能推广到正式模式。
6. 不提前设定性能门槛，不因为实验规模改变生产读写上限；本轮依据结果给出下一轮优化建议，不冻结完整传输架构或引入整篇降级。

## 2. 最小技术方案

- 实验模块按显式启动条件加载，独立的合成数据会话，不借用真实文件授权或保存接口。
- Electrobun 2.0.1 真实 RPC 传输使用现有官方 API；Worker 隔离保留单个有界测试会话。串行运行样本，取消使旧会话结果失效；超时不当成功。
- 每个样本验证长度及内容摘要，patch 复核基线/版本、范围和结果；分块验证顺序与完整性。报告 metadata 不包含合成正文。
- 当前主要传输实验为 WebView 向 Bun/Worker 发送大文本并收到小型校验回执，其 RTT（往返耗时）不等于双向全文传输或打开文件耗时。未实测的 Bun → WebView 全文响应、严格单向分解及引擎内部复制峰值须列为 OBL-003 后续责任；本片不会据此关闭整个承接项。
- 取消是合作式边界：Worker 请求可被失效并终止，但 WebView 正在同步执行 JSON 编码或 CodeMirror transaction 时，点击取消要等当前同步段返回；不宣称可立即中断 UI 线程。请求超时与真正观察到 Worker 退出分别记录。
- 使用当前 `createRawEditorState` 检验编辑与撤销；记录状态处理耗时。浏览器帧机会只标为代理指标，不宣称系统输入到真实像素的端到端延迟。
- 可见 `EditorView` 首轮限制为 1 MB 多行与长行样本；10/50 MB 先测真实编辑状态，不自动挂载巨型软换行视口，视口指标明确记为未执行。此实验安全边界不构成正式产品的大文件降级策略，也不声称已覆盖 10/50 MB 真实视口。
- 本地官方 SDK 的 RPC 序列化及 CodeMirror 官方 viewport 文档作为实现依据；技术结果写回本文件，保留局限。

## 3. 最小 happy path 与风险验证

1. 普通启动仍显示原工作区，不自动执行实验，既有读写与防丢测试无回归。
2. 显式实验启动后完成 1/10/50 MB 链路比较，看到每项的成功、失败或不支持及测量值；重复运行不混入旧结果。
3. 运行中取消后可重新开始，后台会话不保留上一份大文本；校验异常/过期 patch/越界参数被拒绝。
4. 大文本、混合换行和长行的局部编辑/撤销恢复原始内容，报告可复现的处理成本；人工查看实验界面和运行/取消操作。
5. 类型、Lint、相关及全量测试；独立规格/规范复核；代码打包前递增 alpha，核对实际产物版本。

### 实现依据与初查

- 本地 Electrobun 2.0.1 SDK `.hutch/devkit/api/browser/index.ts` 的 `createTransport()` 对 RPC 执行 `JSON.stringify`；`BrowserView.ts` 回程也有 JSON 序列化。二进制类型是否存活仍以真实小探针确认，不因 Worker 支持 transfer 就推断整个 RPC 通道支持。
- [CodeMirror 官方系统指南](https://codemirror.net/docs/guide/)说明大文档按视口渲染；这不代表本项目外围原文状态处理自动具备增量性能，也不等于长行无成本。
- [Bun 官方 Worker 文档](https://bun.sh/docs/runtime/workers)仍提醒 Worker，尤其终止行为，属于实验性 API。本轮仅合成实验使用该路径；取消报告区分自有引用释放、Worker 退出确认和实际 RSS，不能声称系统内存立即归还。
- 本机 macOS 27.0（26A428）、Apple M1 Pro、10 核、32 GiB。一次 Bun 1.3.14 状态层初查复用 `createRawEditorState`，在 1/10/50 MB ASCII 多短行样本末尾插入 `!`，分别约 15.6/97.1/450.7 ms；单行约 10.7/99.4/463.9 ms，六项撤销均恢复原文。此为单次、非隔离环境的调查数据，不是 WebView、实际输入或 paint 测量，也不据此冻结预算；正式实验结果与可复现入口在下文补充。

### 打包 WebView 实测

以 `AGENTIC_MARKDOWN_PERF_LAB=1 AGENTIC_MARKDOWN_PERF_AUTO=1 AGENTIC_MARKDOWN_PERF_AUTO_EXIT=1` 启动已解包的 alpha.16，真实 WebView 发起实验并生成 [完整匿名报告](evidence/F-018a-alpha16-perf.json)。40 行中 39 行成功、1 行 RPC 二进制探针为“不支持”，没有失败；完成后已核对进程退出。

以下每格为“多短行 / 单长行”的单次结果，单位毫秒。不是重复采样、P95、输入绘制延迟或性能门槛。

| 十进制大小 | 全文上行 + 摘要回执 | 当前串行分块上行 + 摘要回执 | 小 patch 往返（不含建立基线） | 原文编辑状态 transaction |
| --- | --- | --- | --- | --- |
| 1 MB | 58 / 38 | 190 / 192 | 11 / 11 | 13 / 26 |
| 10 MB | 315 / 249 | 1782 / 1762 | 21 / 19 | 67 / 141 |
| 50 MB | 2244 / 1771 | 8821 / 8738 | 107 / 85 | 341 / 780 |

- 50 MB patch 的前置基线建立另需 1667 / 1403 ms；patch 的 CPU/内存采样包含该前置阶段。不能把 patch 数值当首次打开成本。
- 30 个传输样本均验证摘要和长度，并观察到 Worker 退出；Bun/Worker clone 与 transfer 数据一致，transfer 发送端 ArrayBuffer 已 detached。该结果不代表 WebView RPC 支持原生二进制。
- 1 MB 两种形态的真实视口通过，双帧机会分别 32 / 38 ms，不代表实际 paint 完成。10/50 MB 只有状态层测量，无真实视口数据。
- 自动取消样本 `completedBeforeCancel=0`、`workerExitObserved=1`，13 ms 后观察到退出、自有文本状态为零；不代表 RSS 立即归还。
- 最大 Bun RSS 采样约 1.087 GiB，仅是顺序执行过程中的采样，不是整 App、峰值或单个动作的内存分配量。CPU 为 Bun 进程（含 Worker）的微秒差值，不含 WebView。
- 原始报告中的 JSON 编码尺寸、原生复制次数、WebView heap 为空；正文下行、严格单向拆分、完整模式及多轮统计尚未测量。某些生成耗时为零受到计时分辨率/惰性字符串影响，不能解释为零成本。

当前结论：本实现的逐块串行 RPC 吞吐较差，小 patch 值得继续验证；原文状态处理仍有随全文规模增长的同步成本。先保留正常 1 MiB 边界，不冻结生产传输方案；后续优先评估增量原文状态/传输，再补全文下行和更大视口测试。OBL-003 整项仍未完成，父 F-018 未完成。

## 5. 人工验收

这是实验能力验收，不是要求把 50 MB 真实工作文档打开到当前正式工作区。

1. 在实验台点击“运行 1 MB”，应逐项产生中文状态并生成临时报告；RPC 二进制“不支持”是本次框架实测结果，不是失败。其余项应成功。中间的合成编辑视口仅在测量时短暂挂载，结束后清空，不是正式文档阅读区。
2. 点击“运行 50 MB”或“运行全部”，运行中点“取消”；等待当前同步段结束后恢复按钮，再点“运行 1 MB”，确认可以重跑、不混入上一轮结果。不要把同步段内无法立刻响应误认为承诺了即时抢占。
3. 查看结果说明与“复制结果”，应只有合成测量数据；检查浅深外观下可读、按钮能通过 Tab/Enter 使用。
4. 退出实验台后不带开关正常启动，应仍是原文档工作区，普通文件上限不变、不自动运行实验。

如果需要重新打开实验台，先退出已运行的 App，在仓库根目录执行：

```sh
AGENTIC_MARKDOWN_PERF_LAB=1 AGENTIC_MARKDOWN_PERF_AUTO=0 AGENTIC_MARKDOWN_PERF_AUTO_EXIT=0 'apps/desktop/build/canary-macos-arm64/Agentic Markdown-canary.app/Contents/MacOS/launcher'
```

首次构建产物的 launcher 是自解包器，应等待安装完成；已解包后上述路径会运行实际应用。去掉三个实验变量即恢复普通启动，不修改 shell 配置或系统环境变量。不要在存在真实未保存文档时强制退出旧窗口。
