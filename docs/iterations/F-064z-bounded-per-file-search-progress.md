## 范围

给内部片段查询增加逐文件通知。第一篇完成稳定读取并关闭描述符后，可以在下一篇完成前得到进度。已有的整次查询回执仍负责覆盖、版本映射和最终成功或失败。窗口传输与流式展示由后续切片承接。

## 最小实现

1. 只在有界片段查询中启用进度。每个已完成读取的文件发出一次，携带递增序号、文件句柄和受限片段。读取、授权复核或关闭描述符失败时，不发出该篇。
2. 对全部已打开文档遮蔽临时磁盘片段。只要有一个打开句柄无法解析，整次进度只提供已处理文件的标记。已关闭的独立文件按其原授权读取。最终回执仍按现有版本映射供窗口使用未保存正文。
3. 发出前检查取消和范围有效性。进度数据独立复制，观察回调失败不改变最终查询。若后续文档超限、取消或失效，整次查询仍失败，进度不能作为已确认结果。

## 最小验收

- 验证打开路径和未解析句柄遮蔽，已关闭文件可发出片段。覆盖回调失败、越限和范围失效。
