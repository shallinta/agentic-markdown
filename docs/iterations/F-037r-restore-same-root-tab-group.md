# F-037r 重新授权后恢复同目录标签组

> 状态：alpha.339 包内验证与普通窗口代验通过。

## 功能说明

在尚未打开文档或加入目录的普通窗口中，从「待重新授权的目录」选回原目录。若上次会话中的主区标签都能在该目录内重新授权，按原顺序恢复整组、各自的编辑或源码模式、固定状态和活动项。任一项失效时只加入目录。

## 最小方案

- 沿用会话的 64 篇上限和单文件读取上限。Bun 先返回数量与活动索引，窗口按顺序每次接收一篇。最后一篇发出前重新核对整组；交付中断时收回未采纳的授权。
- 窗口在每次传输间准备编辑器状态并让出事件循环。后台编辑器从创建起暂停解析。全部就绪后一次显示。恢复不写最近文档，显式关闭沿用会话记录更新。

## 最小验收

- 定向验证 5 篇和 64 篇有序交付、容量、终检、取消及部分交付拒绝。验证后台编辑器、原子采纳、关闭收尾。
- 使用正式包在普通 WK 重选原目录，验证多篇顺序、活动项、固定状态、模式和当前正文。核对会话、最近文档和夹具摘要，正常退出。

## 继承约束检查

- F-002：本地目录授权和磁盘读取，最终离线留人工。
- 中文与外观：复用「重新选择」、普通窗口标签栏和现有模式提示。
- 命令与键盘：复用目录选择、标签切换和关闭。恢复后以活动项为窗口内最近顺序的起点。
- 安全与日志：历史记录与授权见证留在 Bun。窗口逐篇接收受保护快照，沿用失效和未知清理。
