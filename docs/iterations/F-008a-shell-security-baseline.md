# F-008a：当前外壳安全、日志隐私与设置版本基线

> 状态：已验收；2026-09-21 用户确认模块 1～6 验证通过，L1 方案 A 基础范围完成
> 父功能：F-008；前置：已验收的 F-003a、F-004a、F-005a

## 1. 功能说明

- 只覆盖当前外壳和单文件只读链路。Markdown 始终按不可信纯文本显示，不触发脚本、导航、下载或资源请求。
- 收紧当前 WebView 的内容安全策略及导航/新窗边界，保留本地包和必要框架桥接；开发服务器仅在开发渠道例外开放，不放宽生产渠道。外链仍只能通过受校验的显式应用命令交系统浏览器，不因文档内容自动打开。
- App 自有日志只输出固定事件码与允许的匿名元数据；不序列化原始异常、正文、搜索词、凭据或完整路径。本地日志限量保留、不上传；框架与系统内部输出单独说明覆盖边界。
- 为现有磁盘设置提供版本、旧格式迁移、备份和原子提交；未知未来版本不覆盖。只迁移当前已有设置，不提前创建 session/recovery/index 等未来数据库。现有外观等 renderer 本地偏好保留兼容，不改变用户有效偏好。
- 不实现 Markdown HTML 渲染、图片授权、插件、遥测、正式更新验收、编辑或保存。未来消费者的安全接入仍归相应层。

## 2. 最小技术方案

- 先查锁定 Electrobun 的本地 API 和原生实现，再采用真实可用的导航控制；使用最小生产 CSP（内容安全策略），首帧主题脚本用受控 hash/外部静态资源等方式兼容，不用任意脚本权限解决启动问题。
- 统一匿名日志入口，在实际错误/生命周期调用点接入。对日志轮转、未知元数据、写入失败与并发进行验证，失败不阻塞文档服务；配额为可调实现参数，不是性能目标。
- 复用当前设置存储职责，加入独立版本化封装及幂等迁移；写入前备份旧权威设置，临时文件加 rename 提交。未知未来版本只读保护，损坏数据保留原件/备份，不静默丢失。测试使用临时 App 数据目录，不破坏用户现有配置。
- F-002：不写 Markdown，不把文档正文放入日志或设置，核心读取继续离线；安全测试仅用本地恶意样本，不连接外部服务。

## 3. 最小 happy path

1. 新包启动，中文/主题/命令、选择/读取/清空继续可用，恶意 Markdown 仍是字面文本。
2. 验证生产 CSP 与导航规则拒绝脚本协议、远程页面，捕获链接/下载点击和表单提交；保留应用自身初始化和受校验的显式外链命令。原生下载沙箱的已知缺口见下方，不将捕获点击等同原生全面拦截。
3. 输入含敏感内容的异常/日志候选，最终日志仅保留允许字段；达到容量后轮转，失败不影响核心流程。
4. 旧设置迁移后有效偏好保持、再次读取不重复迁移；未来版本或损坏源保留原字节和备份且拒绝写入；迁移写失败仍能读取旧有效偏好。
5. 定向测试、全量测试、类型、Lint、格式、构建和真实窗口回归后，记录证据并进入集中人工验收。

## 4. 实现与验证

### 4.1 实际改动及边界

- 生产构建按最终首帧内联主题脚本生成 SHA256 CSP 授权，不允许任意内联/远程脚本或 eval；当前 Shell 仅允许本地资源、必要 loopback 框架桥接，禁 frame/object/worker/form。开发渠道单独保留开发服务器连接。
- WebView 导航采用精确入口白名单；preload 捕获链接、下载点击、辅助点击和表单提交。原文显示组件始终用 React 文本节点，八类恶意语料按字面输出；命令 RPC 增加运行时参数校验。
- Electrobun 1.18.1 原生 macOS `shouldPerformDownload` / response 下载路径可绕过 navigationRules，且当前接口不提供取消下载 API。源码证据为锁定依赖 `nativeWrapper.mm` 的导航/下载委托（约 2115～2244 行），新窗返回 nil（约 2318～2341 行）。此处不补未验证原生框架；L1 仅对不可信纯文本负责，任意已执行脚本不在该保护证明内。F-020 引入富内容前必须解决缺口，详见 MVP 规格第 6.1 节。
- 匿名日志从事件白名单构造，只允许受限匿名整数 count，不读 getter、不序列化错误对象/路径/正文；Bun 接入启动、关闭、环境及更新错误。renderer 使用相同固定事件格式输出 console，不额外扩展上报 RPC。框架/系统内部输出不属于自有日志覆盖承诺。
- Bun 本地日志为 App 数据目录 `logs/app.log` 和 `app.previous.log`，每份最多 256 KiB，待写队列最多 128 条、单任务写入；满队列丢弃，IO 失败本进程停止日志，不阻塞文档读取。退出不强制等待日志刷盘，不保证最后一条落盘。这些是可调整配额，不是性能门槛；无上传。
- locale/window/updater 三份已有磁盘设置分别使用 `{version:1,data}`。同进程同路径串行；旧对象首次读取时迁移，备份原字节到 `.bak` 后以临时文件 fsync+rename 提交。损坏源和未知版本读取默认、拒绝更新，保留主文件与备份；迁移写失败仍返回有效旧偏好，显式更新报告失败。不宣称多进程锁或完整断电 durability，不自动修复损坏配置。
- renderer 外观/侧栏 localStorage 保持兼容，不把现有标量偏好当未来 session schema。未创建正文库、session/recovery/index 空壳；保留固定中文及有效窗口/更新偏好，不升级更新业务的草稿状态。
