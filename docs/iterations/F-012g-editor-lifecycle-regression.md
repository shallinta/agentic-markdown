## 1. 功能说明

对已有编辑、源码、安全源码消费者落实生命周期及统一命令回归：旧事务、已关闭/重开文档、旧故障会话不得污染当前正文或模式；命令执行时读取当前只读、输入法候选与活动上下文。不新增格式命令、阅读、副区、后台解析 Worker 或生产尺寸上限。

本片只承接 OBL-012 / OBL-041 的当前消费者范围，统一跨任务队列、优先级、完整预算及未来格式/副区入口仍保留同一开放责任，父 F-012 未完成。OBL-020 非活动派生缓存由 F-012h 接续；OBL-068 新外观由相关呈现切片验证。

## 2. 最小技术方案

优先对现有控制器与统一 registry 增加独立回归，不为测试创造平行生产链路。`updateEditor` 以 transaction.startState 对当前 EditorState 的身份检查拒绝过期事务；安全源码切换移除原解析配置，旧故障会话在文档重开后失效。统一命令 guard 每次执行读取实时状态。

现有主区每次只挂载一个 EditorView，切换文档销毁旧 View；CM ParseWorker 自身调度一次待运行 idle 工作并于 destroy 取消。此处为本地依赖源码审查事实，不冒充真实浏览器 idle 回调运行证据。若需生产修正，先报告接口变更并由主任务协调，当前不修改生产文件。

## 4. 最小 happy path

1. 编辑后提交旧事务，当前正文和模式不变；关闭重开后旧 lifetime 仍被拒绝。
2. 进入安全源码后拒绝旧事务；关闭重开拒绝旧 fault session，并恢复新编辑会话。
3. registry 在 composition gate 与只读状态改变后立即改变可用性；只读仍可切换源码而不改正文。
4. 集中人工快速切标签/关闭重开/模式往返，确认无旧内容回流、输入法和键盘流程不退化。真实视图取消与产品体验不能用静态源码观察替代。
