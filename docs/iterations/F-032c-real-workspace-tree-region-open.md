# F-032c 真实目录树的主副区打开

## 功能说明

在现有隔离真实副区窗口，通过原生选择器加入一个测试目录。文件树单击只选中；双击或按 Enter 持久打开。新文档按最后活动区打开：无活动文档、主区活动或副区收起时进入主区；副区活动且空间够时追加到底部。副区满载则在主区打开，并提示「空间不足，已在主区域打开」。已经打开的文档只激活原有实例，保留模式和草稿。本片限一个目录，沿用三篇文档、两篇副区文档的实验上限。

## 最小方案

复用普通文件树组件、文件夹服务和文档 RPC。只从当前树节点的根和条目句柄请求打开，已有标签只用当前有效条目复用。文档控制器提供明确成功回执，失败或过期回执不会参与分配。发起时捕获活动区及分配，完成后确认新文档仍活动、区域分配没有变化，再应用现有高度规则。区域意图过期时不改副区。实验上限与实际像素满载分开提示。

只在现有实验入口启用。正式展开方式、正式主窗接入、文件树拖入、单击预览、重启恢复和最终离线另行承接。

## 最小验收

- 正式包隔离 WK 通过原生选择器加入临时目录；单击无文档，双击在主区打开。用现有实验按钮把一篇移入副区，按 Enter 打开第二篇副区文档；已有主区或副区文档只激活，标签不重复。
- 另起 65 px 场景，副区一篇时打开新文件，确认主区标签与提示，副区布局未变。关闭目录派生标签后从树重开；夹具字节不变。普通窗口同包回归。
- 定向覆盖失败、过期回执、打开后活动文档变化、已有实例、上限与像素满载。

## 继承约束检查

- 命令与键盘：沿用双击和 Enter 语义，单击不改变活动文档。
