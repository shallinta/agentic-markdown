## 功能说明

在隔离真实文件窗口，可拖动副区文档标题栏来调整两篇的顺序。拖到有效位置显示插入线，松开后文档带着自己的高度移动。无效或取消放置不改变布局。标题聚焦时，Option+↑/↓ 可等价调整。

## 最小方案

只改变副区视图元数据中的有序 ID 与对应高度。使用同一文档控制器和稳定文档身份，不读写文件、不切换活动文档。鼠标拖动开始与结束时核对活动操作状态和当前副区成员；离开有效目标、失去捕获或关闭文档时清理插入线。点击标题仍按原规则激活，拖后不补发激活。分隔线仍只调高度；跨区域拖放另轮承接。

## 最小验收

- 在真实 WK 打开三篇临时文档，B、C 入副区后调成不同高度。从标题拖动改变顺序，核对插入线和每篇仍携带原高度，A 留主区。无效放置不改变布局。
- 用标题键盘等价操作换回，核对焦点、活动文档、草稿和撤销。关闭或移动仍使用当前真实文档，普通窗口打开与退出回归。夹具不写盘。
