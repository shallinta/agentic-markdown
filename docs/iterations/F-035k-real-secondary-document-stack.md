## 功能说明

现有真实文件移区实验可打开三篇文档，最多两篇同时放在副区。副区按移入顺序纵向平铺，两篇都可激活、原位编辑和保存，主区仍可参照。副区装不下时保留原文档与归属。关闭或移出时将高度交给下一篇，无下一篇时给上一篇；最后一篇离开后收起副区。

## 最小方案

区域层只保存有序副区 ID 和高度。以同一文档控制器名册为准，沿用活动写入与文件授权。复用 F-034 高度分配和移除计算，隔离窗口以固定实验宿主检验空间边界。移入时至少保留一篇主区文档；关闭后可暂时没有主区文档。保留主区上次显示的有效文档，旧文档移出后才回退。关闭副区沿用原有具名确认。正式展开、动态窗口缩放、拖放和排序不在本轮。

## 最小验收

- 在真实 WK 打开三篇临时文件。在 65 px 副区放入一篇，第二篇因空间不足留在主区；66 px 恰好容纳两个 33 px 标题栏，顺序和关闭时高度转移正确。
- 恢复 320 px 实验宿主，先后移入 B 和 C，实际查看 160 / 160 px、A 留主区、各自独占写入。关闭第一篇后另一篇得到全部高度，移回最后一篇后副区收起。
- 用临时文件验证副区编辑和撤销、不误写其他文档，确认退出保护和普通启动无回归。真实中文候选仍随 OBL-052 跟踪。

- 真实 WK 的固定宿主实测：65 px 时 B 占 65，C 移入显示空间不足并留在主区；66 px 时 B、C 按序各占 33，焦点落在 C 标题。关掉非活动 B 后 C 占 66、仍为活动文档。测量宽度为 639.5 CSS px。
