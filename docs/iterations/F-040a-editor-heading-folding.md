## 功能说明与范围

- 承接 F-040 的标题章节折叠有限切片：主窗口编辑与源码共享文档内折叠状态，折叠到同容器下一个同级或更高级标题之前，不删除或改写 Markdown。
- 支持已支持的 ATX H1–H6 与 Setext H1/H2；保留标题自身，折叠其后章节。无可折叠正文不显示入口。引用/列表内标题不越过所在容器；围栏内伪标题不是标题。
- 标题左缘独立箭头：展开时 hover/focus 显示，折叠时常显；标题文字本身不变成折叠按钮。提供等价键盘命令和中文可访问标签。
- 标签及编辑/源码切换保持折叠；查找或选区定位进入隐藏内容时展开必要范围。只读可改变显示折叠，不可改变正文。组合输入期间不执行主动折叠。
- 不实现大纲/TOC UI、阅读子窗口及其状态同步、代码折叠/摘要、Frontmatter、全局折叠快捷键套件或跨重启恢复。不关闭完整 F-040、F-030 或后续消费者责任。

## 最小技术方案（候选）

1. **先做有限结构验证，再批准实现。** 使用当前真实 Lezer 解析消费者，经独立 adapter 输出绑定当前 Text/解析代次及 completeness 的轻量标题/章节范围，不新增第三套解析或复制 AST。对照 canonical 的标题级别、容器与范围，覆盖 Setext 多行、quote/list、BOM/CRLF/CR、围栏伪标题及部分树。该实验只能证明有限语料，不冒称全语义等价。
2. **完整性与成本。** 未知章节尾部不得以当前部分树尾伪装真实章节末尾；后台解析尚未覆盖所需范围时暂不提供可用折叠。不要在点击、每次可见行或每次按键中强制完整同步解析；索引构建按树/文本代次失效，分片与预算由实验确认，只有当前代结果可发布。视口 gutter 只创建可见标题节点，不生成全文隐藏 DOM。
3. **复用官方展示状态。** 采用公开 codeFolding/foldState/effects 实现隐藏和变更映射，放在编辑/源码共用扩展层而非模式 presentation compartment；私有标题限定 gutter 和命令只消费轻量结构结果，不调用默认泛块 foldable。安全源码降级、parser 暂停和失效期间不能残留不可恢复隐藏内容；具体清理效果需与现有生命周期一道验证。
4. **入口与定位。** 可见 gutter 箭头负责点击，统一命令注册折叠/展开当前标题入口，先核键位冲突再选择快捷键。保留当前选区；如折叠将吞掉已有光标，须在最小方案收敛时明确安全处理，不能静默移走用户光标。公开 foldState 默认仅针对 selection.main.head 自动展开，需补所有活动选区及已有查找/链接/恢复定位的必要范围，不把主光标通过当作多光标全部通过。
5. **内容变化。** CM change mapping 只是坐标映射，不证明标题语义仍成立。标题级别/容器/分隔结构变化后必须失效并重新验证受影响折叠；不得把旧范围错误地套到新章节。方案先优先安全展开受影响范围，精细保留优化以后按证据补齐，不改正文、历史或保存状态。

### 供主线收敛的最小实施细化（未批准生产）

- **结构遍历**：当前树按块节点一次有序游标遍历，容器入栈/出栈；每容器维护最多六级开放标题栈，遇同级/高级关闭相关项，遇真实正文块标记开放项有内容（下级标题自身算上级内容）；跳过 inline 子树。每 task 累计访问及输出分片，旧 Text/Tree/代次任务取消，输出前仍核身份；以真实块判定无正文，不按字符长度或 trim 判定。
- **完整性**：以公开 `syntaxTreeAvailable(state, upto)` 加当前 Tree/Text 身份为资格，不用 `tree.length === doc.length` 单独宣称完整。首版可保守等待整份树，但公开文档明确后台可能停在视口附近、不保证最终全文完成，因此该保守策略不能冒称所有普通文档最终可折叠。若使用 partial 前缀，必须只发布由已覆盖的下一个同级/高级标题明确闭合的范围；部分树尾、可能继续延长的容器尾均不发布。该部分可用边界及真实 parser 调度仍需实现前验证；不调用 `ensureSyntaxTree`/`forceParsing` 强制同步全文，不新增每键全文解析或 canonical 管线。
- **原文与选区**：范围保留完整标题与下一标题整行前缀；标题正文空白无入口。主动折叠与任何活动选区内部相交则原子拒绝，不移动选区、不改正文；折叠后的查找/选择定位按全部 ranges 展开相交隐藏范围。官方端点与实际 WK 行布局仍待验证，不把纯字符串模拟当 GUI 通过。
- **变更和模式**：优先在文档变化、safe/parser 失效时安全展开现有隐藏范围；重新生成当前树索引后才可再次折叠。编辑/源码共用官方 foldState，不放入模式 presentation compartment；不得默认挂泛块 foldGutter。键位、统一命令、IME guard 与 readonly 展示操作在正式接线方案明确。
