# F-034a 副区新增文档高度分配

> 状态：alpha.299 隔离实验代验通过。

<!-- obligations: none -->
<!-- deferred-obligations: OBL-051 -->

## 功能说明

验证副区新增文档时的高度分配和满载拒绝。每篇最低占位 33 CSS px，包括标题栏 32 px 和分隔线 1 px。既有顺序不变，新文档只追加到底部。

## 最小方案

- 按已确认公式先把旧高度乘以 `n/(n+1)`，钳制到 33 px。若剩余不足，再让尚有余量的旧文档平均分担缺口，触底即退出分担。仅在确实无法容纳时失败，旧数组和顺序不变。
- 使用纯函数返回分配或满载结果。复用已有主副布局实验窗的合成副区，展示实际高度和结果；不接真实文档、拖放、正式展开入口或双击降级。

## 最小验收

- 验证首次占满、正常比例缩小、旧文档保持最低、均摊后有旧文档触底、恰好装入及不足失败。总高度保持，失败不修改输入。
- 用正式包的隔离布局实验验证恰好装入和满载拒绝，普通窗口打开和退出不受影响。
