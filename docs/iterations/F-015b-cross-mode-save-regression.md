## 功能说明与范围

- 保存捕获不可变正文及 revision；保存期间继续输入不被旧回执清除。成功只推进已提交快照的磁盘基线，新输入仍 dirty，失败不前进基线。
- 模式变化只影响视图，不改变保存目标、内容、选区或撤销历史；非活动标签的回执不能覆盖当前活动标签状态。
- 安全源码保留现有安全隔离与显式恢复边界，不以保存为由重新启用故障扩展。
- OBL-065 仅本片当前消费者范围；副区、自动保存/恢复和其他未来消费者仍留 F-035 / F-065 / F-066 等对应接入迭代，整项与父 F-015 不关闭。OBL-002 / OBL-009 / OBL-044 / OBL-063 已验收历史不重开或重复冒领。
