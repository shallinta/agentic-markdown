## 功能说明

验证 Markdown 原块缺失或出现歧义时，按邻近块、源码位置、滚动比例的顺序恢复位置。沿用 R-15 的顺序，为正式会话接入准备可验证的定位结果。

## 最小方案

- 复用现有块索引。原块无法定位时，只使用新旧正文中都唯一的紧邻块。前后邻块都存在且顺序一致时，优先后一块。仅有一个可用时使用该块，两个可用块换序时转到源码位置。
- 源码位置使用原始 UTF-16 坐标和对应的视口偏移。坐标超出当前正文、位于代理对或 CRLF 中间时，改用保存的滚动比例。比例对应当前可滚动范围，实际视口应用在窗口接入时验证。
- 原块起点与源码位置分别使用各自测得的视口偏移。邻块结果提供区间和前后方向，供窗口接入时对齐。空白位置仍可采集源码坐标和比例。
- 实验沿用 1 MiB 文档边界。正式会话格式、采集时机和窗口接入继续由后续切片承接。

## 最小验收

- 用本地合成文档验证原块优先、删除目标后选择后一块、后一块缺失后选择前一块。邻块重复或换序时验证源码回退。
- 用缩短正文、CRLF 和 emoji 验证位置边界和比例回退。用同包普通窗口回归标签重新授权、恢复和退出。
