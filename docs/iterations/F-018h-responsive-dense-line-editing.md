## 功能说明与边界

用户授权“先按这个方向尝试改进”：密集长行输入先响应，语法呈现随后更新。F-018g 只完成诊断与有限归因，未交付生产优化；本片不能把诊断通过当作优化目标达成。

本轮尝试把昂贵解析移出输入同步路径，同时保留原 Markdown 解析语义、BOM/原文及混合行尾、现有软换行、普通 1 MiB、选区/撤销历史和保存规则。允许语法呈现随后更新，不允许旧结果冒充当前版本、覆盖新输入或把临时语法状态当正文真源。验收须有真实输入同步成本改善及交互正确性证据，不提前设定数值门槛。

OBL-003 仅承接本轮输入响应局部优化；完整大文档、其他传输/复制与性能余项仍开放，不关闭父 F-018。`deferred-obligations: none` 只表示没有另一个主承接 ID，不表示 OBL-003 已完整覆盖。未来消费者不纳入本片；不提供新的降级产品模式。

## 最小技术方案草稿（具体接入核查中）

1. 候选为公开 Parser 适配与后台 Worker：沿用原解析器的语义，在后台处理当前版本快照，前台通过公开接口接收结果，使输入无需等待整段密集语法解析。仅为候选，解析树传递/恢复、CodeMirror 调度及呈现更新是否可正确接入仍须核查，不预写为可用实现。
2. 解析请求与结果绑定当前文档会话和文本版本。实际接入以当前 Text 对象身份与会话内 requestId 拒绝过期结果，不是保存 revision；解析配置随会话固定。只发布匹配当前文本的结果，拒绝迟到、乱序或已销毁会话结果；安全源码不得被后台回执重新启用解析。不能以旧树伪装新树消除等待。
3. 使用有界待处理任务与最新版本合并策略，避免连续输入积压完整快照/语法树；明确运行中任务和待处理任务的所有权。取消、切换/关闭、重建及故障路径清理 Worker、回调与引用，过期任务即使不能立刻中断也不得影响当前状态。资源限额及实现细节按核查结果在本文件补记，不提前冻结完整调度框架。
4. 保存继续消费当前原文与既有保存捕获快照，不等待或依赖语法树成为真源；模式往返、选区、撤销/重做与权限/关闭保护仍遵循既有控制器。后台呈现更新不得制造编辑事务、推进 dirty 或清除新输入。
5. 不 fork 或修改依赖私有实现，不擅自替换解析语义、取消软换行、提高文件上限或放宽安全规则。若公开接口不足、必须引入上述以外关键行为/路线变化，先说明证据并取得用户确认；若无法在边界内取得真实收益，如实报告未解决，不用实验开关或测量变化掩盖。

## 继承约束检查

- F-002：离线、本地 Markdown 为唯一正文真源；仅一次性样本用于验证，不动用户未保存文档。1 MiB、原文字节和安全保存边界不变；Worker 只处理已授权内存数据，不自行读取文件或网络。
- 中文与外观：中文反馈、浅深/系统主题及源码纯代码外观保持；明确区分原文即时更新与语法呈现随后更新。中文候选期间不能因异步呈现破坏输入、选区或候选；真实 IME/视觉留实际验证。
- 命令与键盘：继续复用当前模式、权限、保存与关闭命令上下文，输入/选区/撤销重做保持；无新增鼠标专属入口或拖放/分隔线。安全源码仍隔离，后台结果不能解除保护。
- 安全与日志：Markdown 只作数据，不执行脚本/资源；结果严格校验会话和版本，失败不丢原文。报告仅匿名标量，不泄漏正文/路径；取消、故障、退出与过期回执均检查释放和拒绝行为。

1. 同机、同视口、同普通/密集 10k/50k/200k 样本，分别记录改动前后真实生产输入同步路径及语法可用时点；区分首次与重复、隔离探针与生产控制器、同步耗时与绘制机会，保留重复原始值。目标是实际同步成本改善，不以诊断行成功替代；不设预期阈值。
2. 输入后原文和光标立即正确，随后当前版本语法呈现与原解析器一致；连续输入、撤销重做及模式往返后，迟到/乱序结果不覆盖当前内容、不错误恢复旧装饰。
3. BOM/混合行尾、保存捕获快照与 dirty、选区/历史、长行保护、只读和安全源码回归；保存不因等待后台解析阻塞或保存旧内容。真实中文候选和输入手感与合成事务证据分开记录。
4. 快速输入积压、关闭/切换/重建、取消及 Worker 失败能保留正文并清理任务；无过期发布或无界排队。无法观测的资源释放如实标未知，不把移除引用当 GC 字节证明。

## 本次尝试的最小接入（2026-09-28）

- 复用既有 10,000 UTF-16 单位长行识别，仅含长行文档尝试后台解析，普通文档不改变同步路径；阈值是已有实现参数，不是新的文件上限或性能门槛。
- 使用同版本 CommonMark/BOM 解析器，在固定应用 Worker 中解析。通过公开 `Parser` 与 `ParseContext.getSkippingParser(promise)` 将未完成状态交给 CodeMirror，完成后返回当前文本对应的真实树；不访问或写入依赖私有状态。顶层占位用途需要实际测试，不以文档推断冒充可用。
- 每会话至多一个运行中任务、一个最新待处理文本引用；切换、销毁和安全源码解除解析扩展时终止 Worker，不把旧树当新树。失败沿用安全源码机制，不能静默退回昂贵同步解析。
- 使用 Vite 内联的固定 Blob Worker，避免依赖 `views://` 直接加载 Worker 的平台支持。外壳 CSP 仅增加 `worker-src blob:`，不增加页面脚本、远端网络、eval 或 Markdown 代码执行权限；Worker 接收文本数据，无文件读取和资源请求逻辑。必须在打包的 WKWebView 验证启动与故障，不只在 Bun 验证。
- 复用已有实验台增加同包同步/后台对照，真实文档控制器加 EditorView，合成内存授权数据；历史诊断入口保持同步配置，避免悄悄改变旧报告口径。实验不是产品模式开关。
- 实施前源码快照：`/private/tmp/agentic-markdown-f018h-before.28Tpng`。本轮与先前未提交的 alpha.33/34 工作区分别评审，保留已有修改。
