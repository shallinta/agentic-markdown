# F-064s 独立文件的保留授权快照

## 范围

给 Bun 内部搜索准入补一条受控读取能力。单独打开的 Markdown 文件在标签关闭后仍留在窗口文件树。只要原有文件授权仍有效，内部搜索便可获取该文件的有界正文。文件夹派生的普通授权仍使用目录扫描的搜索路径。

这一片验证保留授权的只读快照。顶层独立文件与目录的查询合并、父目录吸收去重、范围控件和点击定位由后续切片接入。

## 最小实现

1. 沿用 `captureContentSearchBindings` 的文档准入。只为明确的独立文件授权提供只读函数，绑定同一句柄、身份、canonical path 和当前准入代。调用只接受剩余字节预算和继续有效的守卫。
2. 复用文档服务的稳定读取与路径链校验，通过已授权文件的描述符读取，限定 64 KiB。读入前后核对文件身份、准入和废纸篓隔离。不会创建新授权或更新当前文档的磁盘基线、正文、撤销历史或观察状态。
3. 被替换、撤销、隔离、超限或途中取消的文件拒绝返回正文。已授权 inode 在读取前被外部原地修改时，可读取当前稳定字节，仍保持文档原基线供后续版本比对。

## 最小验收

- 读取保留的独立文件，确认 BOM、CRLF 和 UTF-8 原字节，正文与版本数据不变。
- 验证普通目录授权没有此读取能力。覆盖限额、文件替换、授权撤销、取消和废纸篓隔离。
- 正式包 Bun 复跑独立文件准入，真实 WK 窗口回归现有有界搜索和退出。

## 继承约束检查

- F-002 沿用本地文件授权。离线留最终人工。
- 中文与外观沿用已验收窗口，本片内部错误由后续查询接入。
- 命令与键盘沿用已有搜索与文件树。
- 安全与日志方面，只读取原授权文件，不扩展到父目录，不记录正文和路径。

- macOS arm64 unsigned canary `0.1.0-alpha.205`，包标识 `3i546dhnpdgxt`。包内 Bun 1.4.0 复跑准入测试，7 项、72 条断言通过。覆盖关闭观察后的原字节读取、同身份原地改写、预算、路径替换、撤权、取消和废纸篓隔离。
- 独立 WK 窗口中打开 `研发笔记.md`，关闭标签后顶层文件仍在，双击可重开。加入另一目录后用 `root:笔记 file:内容` 搜索，覆盖 1 篇，打开磁盘命中 `[5, 10)` 并定位到甲组正文。两份夹具 SHA 不变，⌘Q 后启动器退出码 0。退出记录包含一条 IMK 日志。
