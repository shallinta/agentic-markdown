## 功能与边界

文件树选择一个已授权目录根或其可信子目录，经影响清单和明确确认后，把该**真实完整目录**一次移入系统废纸篓。包括未显示的隐藏文件、非 Markdown 资产和其内部目录；文件树只是选择入口，不是删除清单。没有永久删除、清空废纸篓、逐个文件递归删除或自动恢复覆盖。

确认明确 canonical 目录路径，并说明“整个实际目录及未显示内容都会移入系统废纸篓”。根目标还明确“该目录根将从当前窗口移除”，不能把 F-061 的仅从窗口移除混同磁盘操作。只读子文件不等于目录不可移动，以平台实际结果为准，不要求先打开正文或变更权限。

当前可信树不提供符号链接目录入口：目标本身或必需祖先若是链接/身份已变化，拒绝，不沿链接去移动外部目录。目录内部已有符号链接随目录项整体进入废纸篓，App 不遍历或跟随其目标；不得把这些链接指向的外部文档作为待删除对象。旧 picker 曾 canonical 化的目录根只确认已经授权的实际 canonical 实体，不宣称删除原链接入口。

所有受影响已打开文档先列出。沿 F-059a 的确认期 owner 捕获 handle/documentId/editorState/bufferRevision：对需要保护的文档**逐一**选择放弃、取消或先保存；任何取消保持全部原内存和历史，先保存结束本次目录操作，用户正常保存后重新 prepare。各次“放弃”只累计本轮意图，不提前关闭；最后再确认完整目录磁盘操作。新编辑、打开或版本变化使旧意图失效，不能拿旧放弃许可清新内容。clean 文档列在影响清单，不新增无变更放弃弹窗。

平台确认成功后才同步关闭受影响标签、撤销其授权及更新树/目录例外/已有元数据消费者。与目标无关的文档模式、选区、dirty、撤销历史和其他根保持。失败保留原 UI/恢复数据；unknown 保留内存、查询原槽、不重发。MRU 历史不主动删除，按当前授权/存在性过滤。阅读子窗、完整副区与将来索引消费者仍按其父项接入，不冒本轮全完成。

## 已查实的接点与路线选择

推荐沿 F-059a 窄桥扩展为“单个文件系统对象”的严格 file/directory 类型分支，共用阶段/单槽，不另写通用文件系统框架。

本地公开 SDK：`Foundation/NSFileManager.h` 的 `trashItemAtURL:resultingItemURL:error:` 接收 item，YES 表示移入成功，NO 表示未移入；`NSURL.h` 的 `fileReferenceURL` 是对象引用，可随路径变化但不可跨重启/remount持久存储。不能从相邻 `removeItemAtURL` 的递归删除文档推出 Trash 的自定义递归实现。现有 F-059a 原生代码只允许 `S_ISREG`，正式目录行为仍需验证，旧文件探针不冒目录已测。

官方来源：本机 SDK `/Applications/Xcode.app/Contents/Developer/Platforms/MacOSX.platform/Developer/SDKs/MacOSX.sdk/System/Library/Frameworks/Foundation.framework/Headers/{NSFileManager,NSURL}.h`；[Apple Trash API](https://developer.apple.com/documentation/foundation/filemanager/trashitem(at:resultingitemurl:))；[Apple 对象引用 URL](https://developer.apple.com/documentation/foundation/nsurl/filereferenceurl())。仍不使用现 Electrobun `moveToTrash(path)` 的路径式 NSLog 桥。

### T1：可信目录目标与一次平台调用

- `shared/trash-document.ts` 增加严格 directory 目标变体，包含 root/generation 与可选 child entry；不可把 file entry 或 renderer path 当目录授权。prepared 返回目标 kind、canonical 路径、受影响绑定；publication 明确根移除与子树投影区别，原文件分支严格回归。
- `workspace/index.ts` 的 `creationTarget` 已能从当前目录例外或 Markdown 的祖先链提供子目录证明，并验证 root lifetime/generation、根内连续 chain（128层）；提取最小只读目录证明 helper 供创建和 Trash 共用，不调用会创建条目/注册例外的分支。
- worker 接收可信 root/chain/目标 fingerprint；从现 `scan.ts::openDirectoryDescriptor` 提取仅 descriptor 与最小类型的叶 helper，以公开逐级 `openDirectoryAt` + `O_NOFOLLOW`/fstat 取得目录 fd，不让 worker 导入扫描器/解析器。授权祖先仍最多256。目标与祖先 fd 由 worker 独立持有，宿主退出交接不得关闭它们。原生增加严格 directory kind 检查，建立临时 reference 前后核身份/祖先，不回退到路径式 Trash。
- 系统调用只对原 reference 进行一次 `trashItemAtURL`，不枚举子树再逐项删除。沿预构造返回值、固定 stage buffer、先记录平台 YES 再后验的合同；目录结果 URL 只留可信后端且核原目录 identity。后验或回执丢失不变成 NO，不重复破坏性调用。
- 仍是普通本地 App 内并发模型，不承诺任意外部用户在末检后改名/替换/跨授权边界移动时的绝对 CAS。参考建立前替换须拒绝；不能称事后 unknown 修复已发生的误移动。

### T2：有界影响与确认、提交

- prepare 在完整批次 park + 文档 mutation lease 下捕获当前可信目录 proof、所有受影响 grant 和树投影，随即释放后台 lease；不跨用户确认长期持 park/fd。renderer 本轮 owner 贯穿逐一保护与最终确认。
- 受影响成员从全部可信 grants 判定，不能由树 files 投影推全集，也不能仅裸字符串 `startsWith`。可信祖先含目标目录 fingerprint 的身份匹配独立成立，与分段 `containsPath` 路径范围为 OR，不先按当前路径过滤掉改名后的旧绑定。路径命中或旧身份命中但证明无法可靠复核时，整次前拒并重新确认，不静默漏掉 dirty。现 `FolderGrantBinding` 不含 directories，须由后端授权记录/inspect 增加最小可信 ancestor 证据，不接收 renderer 自报证明。独立授权、隐藏或未投影但位于子树的打开文档均包含；外部链接目标、目录外 hardlink 和无关兄弟不因共享文件 inode 被当作已移动对象。目录清单各 fileName 取相对目标目录的可信路径，旧路径不在范围内时用原路径，同名不同子目录可区分；单文件仍 basename；按可信绑定去重，不加载正文。
- commit 重新取得专用全局准入、保存排空、完整批扫描 park；重新核 root lifetime/generation、目录 identity、影响绑定与确认 token。任何新增/变化的受影响项拒绝并重新确认；不能在排空保存后继续用过期目录 proof 或旧 editor 放弃许可。
- 沿用最多1024受影响绑定、最多32根及联合4MiB元数据模型，不新发用户文档大小限制。扫描当前缓存/授权集合每64项让出并核 owner，预先计费影响数组/图副本/输出；超预算整次前拒绝，不部分移动。隐藏/非md磁盘子树不枚举、不读取正文，不虚报文件总数或完整磁盘资产清单；确认文案明确它们全部包含。OS 操作耗时由 worker 承担，不把同步原生调用放主线程。

### T3：成功投影、永久失效与收据

- 破坏调用前准备根或子树的精确旧绑定和有限新图，系统成功后在同一同步段提交 documents 与 workspace，再通知和附带清理。先保存平台事实，图/清理失败保成功事实及待接纳收据，不能重发 Trash。旧回执不得清新根、同路径新目录或新编辑器。
- 根目标：专用 Trash publication 移除该 root、撤销其已搬走子树对应 grant，关闭 root scopes、scan/reconciliation/observation。**不直接调用 `folderRemoval.commit("keep")`**，因为磁盘已经移动，不能迁移或提升这些原路径为独立授权。
- 子目录：删除其完整缓存子树（目录节点、files、byPath、directories），保留其余节点；在 created-directory registry 增加窄的可靠子树撤销接点，清除相应例外并推进版本，旧 inode 返回亦不复活，隐藏关闭不能让已确认删除的例外残留。旧 scan key 在代数推进前捕获，候选/观察全部失效，后续重扫不重新注入旧图。
- publication 对全部当前可信投影统一准备：目标范围内的 root 撤权移除，存续祖先 root 剔除相同目标子树，独立 leaf/covered 记录、各 root registry 与 asset scope 按同一实际范围收口，目标外根保留；不是仅改被选 root。现正常父子 root 选择会去重，不虚构真实可达双嵌套根；多投影防御分支可用局部 seam 验证并明确非真实授权集合，真实消费者仍用现可达根与独立授权组合。
- 保留 F-059a 同步 prepare/swap/effects 的两store收口。根显示偏好等非磁盘设置清理作为成功后的附带操作，失败保匿名告警/原偏好，不把已移动目录称未移动，也不以第二个 settings 操作触发再次 Trash；不引入跨重启删除恢复事务。该与 F-061“仅移除根”的设置事务区别须独立复核。
- 与 F-059a 共用一个破坏性单槽和 session/sequence；文件/目录不能各自绕过未明槽。ack 只能清已知失败或已接纳成功，unknown 不解除身份隔离。

### T4：未知子树隔离与正常退出

现 F-059a guard 只看单路径/原文件 fingerprint，不能直接复用为目录安全证明。目录槽保存**一个原目录 fingerprint + 完整授权链**及有限已捕获 grant 绑定，不保存整个磁盘子树 map：

1. 对原 canonical 子树及同父工程等价目标（既有 NFC/lower 名称规则）保持路径范围隔离；使用分段关系，不把 `/a` 当 `/ab` 前缀。
2. 对现有或再次授权的文档，结合其可信 `directories` 中的原目录 identity 识别同一被移动子树；目录改名后重新授权不能仅因路径变化绕过。可信 ancestor 证明须从授权/descriptor获得，不能采 renderer 字符串。原已捕获绑定仍隔离，避免其路径/来源在处理中变化后销掉 dirty。
3. 新建文件/目录/副本的目标父 chain 同样核隔离；原子树外无关父目录、文档仍可用。原对象移走后原位置被新目录占用，不能用旧收据删除新对象；未知期间该原路径范围仍保守禁写。

上述是一个目录身份及有限已登记绑定的隔离，不承诺识别外部任意移出、此前未登记且已不含原目录祖先的单个子文件来源；没有这种历史证明，也不为此新增无界对象账本或绝对 CAS。

需要把 Bun-only `trashBlocked` 的窄只读参数扩至可信祖先链/目标类别，并覆盖保存、重新授权、自动接受/重读、创建/副本；不能靠 renderer uncertain 集合或只按 documentId。正常重载同 backend 不清槽，根移除/readd 不清槽。不扩跨重启 tombstone/自动恢复；明确仍由用户在系统核对。

退出沿 F-059a：`beforeExit` 在实际 `withWriteBarrier` 前只交接本方 lease，保子树隔离；全部 dirty 保护无新增 clean 确认。获准后一次2秒收据软预算（不含用户答复时长），晚回执不复活旧UI，超时中文非阻塞告警并正常退出，不把进程结束当动作取消。不专门 terminate 工作中 worker；runtime.stop 不重新无限等。取消退出保内存/槽、恢复无关操作。
