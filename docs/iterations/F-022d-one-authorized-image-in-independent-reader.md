# F-022d 独立阅读窗口显示一张已授权本地图片

> 状态：alpha.274 已由 Agent 受托验收。

<!-- obligations: none -->
<!-- deferred-obligations: OBL-010, OBL-031 -->

## 功能说明

从当前文档打开已保存阅读快照时，普通独立阅读窗口显示正文中第一张符合本地引用语法的 PNG 或 JPEG。先显示占位，图片通过授权及内容检查后原位显示。第一张不可读取时保留占位，其余图片继续沿用现有占位。

## 最小方案

- **从保存快照选一张图。** 复用现有受控 Markdown 解析和本地图片引用规则，在后台从已捕获的正文确定第一个本地 PNG/JPEG 候选，支持直接引用和定义引用。跳过代码、原始 HTML、远程地址和未使用的定义。正文照常一次性投递，图片使用独立的一次投递额度，解析或读取失败时不改选下一张。
- **票据归本次子窗。** Bun 内部为这一张图持有单独票据，绑定原有文档授权及其代数、资产范围、已保存正文的 ID、revision、字节摘要、真实文件 stat，以及具体子窗实例和固定页面。正文投递结束后，图片票据仍可完成一次。读取前、异步返回后和提交前重验当前性及 Trash 边界。保存、磁盘正文修改或替换、授权或范围改变、主窗离开、子窗关闭和退出均阻止旧结果投递。新开的子窗有独立票据。
- **分别验证正文和图片。** 正文来自已有稳定读取。读取图片前后核对同一保存版本和该次读取确认的正文文件身份、大小及高精度修改与状态变更时间，覆盖同 inode 原地改写。复用已有本地资产授权与原生描述符读取，核对实际图片文件和祖先边界，拒绝越界、链接、替换和读中变化。单次图片读取与投递均最多 1 MiB，读取前用实际图片 stat 拒绝超限，继续使用现有像素上限和格式检查。正文与图片是分别校验的读取，窗口中的已显示图片保持快照状态。
- **固定单向投递。** 普通子窗在正文接收前装好一次性图片接收器。Bun 仅向票据所属的固定页面提交受限事件，载荷只有本次投递标识、固定槽位，以及不可用状态或经过校验的格式、尺寸和规范 Base64。接收端最多暂存一份符合预期的载荷，等正文定位占位后原位更新，超时或关闭时释放。由接收端构造固定 MIME 的图片数据地址。维持 sandbox 和固定导航，只有普通阅读快照页的 CSP 允许 `img-src data:`，合成实验页仍为 `img-src 'none'`，两页保留 `connect-src 'none'`。载荷不含路径、授权句柄、文档标识或文件指纹，子窗没有请求图片、回执或通用 RPC 的通道。

## 最小验收

- **源码和包内定向测试。** 核对直接与定义引用选择同一解析顺序、后续图片不替补、1 MiB 及加一字节的分界、格式和尺寸校验、规范 Base64 与载荷字段白名单。用受控延迟分别验证原地修改或替换正文、图片 stat 变化、Trash 或授权失效，以及 A 窗口关闭再开 B 后 A 的旧读取返回。核对占位、旧投递丢弃和新窗口只接收自己的图片。
- **真实打包 WK。** 用两个独立保存快照分别验证直接引用 PNG 和定义引用 JPEG。观察占位至实图，核对不同夹具的像素尺寸与可见内容，记录正文和实际图片文件验前验后的 stat 与摘要。再测上限图及超限图、远程地址、越界路径、SVG 和第二张图片保留占位。用有界的受控延迟验证 A 关闭后才完成的旧读取不会进入 B，并验证正文在捕获后变更时仍保留旧正文、旧图片结果被拒绝。若真实窗口未捕捉到受控竞态，分别记录源码或包内延迟证据及真实窗口实测范围。
- **核对窗口边界。** 验证普通与合成页面的实际打包 CSP、固定 URL 和 sandbox，合成页继续无图，普通页无特权桥、回程通道或路径载荷。两窗正常关闭，夹具未被 App 改写。
