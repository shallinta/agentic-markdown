## 功能说明与边界

沿用 U-02/U-18 已确认规则，在 F-021a 主区阅读基础上提供两个随 App 分发的 ThemePackage（主题包），每包含 `theme.json` 与 `theme.css`。用户通过中文统一命令选择主题，同一窗口的所有阅读文档共享该选择；切换标签、关闭再打开文档或模式往返不重置窗口选择。只改变阅读正文样式，不影响 App 外壳、编辑或源码模式，不重解析 Markdown、不改写正文。

本片局部承接 F-021 唯一主承接 OBL-029。`deferred-obligations: none` 只表示没有同父功能的其他 ID，不代表完整 OBL-029 已关闭：窗口主题选择随会话恢复留 F-037 接入，副区阅读统一应用留 F-035 消费者联动与 F-021 后续复验；义务保持开放。本片仅窗口内存状态，新建窗口/重启先用默认随包主题，不写 App 全局偏好。不是取消已确认的窗口恢复要求。

不提供主题导入、安装、打开主题目录、编辑、自定义/第三方分类或市场；不加载外部 CSS、网络字体/资源或用户路径，不建立插件 API。可选 `assets/` 本片无需求，不加入资产加载链路。完整阅读块增量更新、Raw HTML、图片、链接、副区与待专项设计项不进入本片。

## 最小技术方案

1. 在源码内静态注册“纸页”（浅暖白、serif 衬线字体）与“墨夜”（深蓝灰、sans 无衬线字体），默认纸页；这些仅为随包呈现参数，不新增产品偏好。统一 manifest 仅含当前需要的稳定 ID、中文显示名与版本字段，CSS 通过构建工具随包导入；不提前冻结外部主题 schema/兼容 API。校验 ID 唯一且仅能选择注册项，无效 ID 保持现有选择并给出中文提示。
2. 主题选择由当前窗口工作区拥有，采用每个 workspace 实例独立的 `createReadingThemeSelection(capture)` 小型状态容器，便于验证隔离和重复选择幂等；与文档模式/正文状态分离。不写本地存储或 App 设置，不在模块级跨窗口共享。后续 F-037 将这个选择接入窗口会话，不在本片提前实现恢复 schema。
3. 两包 CSS 都只作用于明确的阅读正文作用域，使用局部变量控制背景、正文色、字体、字号、行高、段距和可读宽度等；外壳工具栏、状态条、诊断、编辑/源码、弹窗不被主题规则污染。颜色和排版由阅读包独立定义，切换 App 浅/深/系统不会替换所选阅读主题。窄容器不溢出，不新增围栏换行策略。
4. 禁止主题脚本、HTML、远程 URL、`@import`、外部字体及目录外访问。仅审查随包已知 CSS，不做通用第三方 CSS 安装器；现有受控内容 DOM 与惰性资源规则保持，不能因主题放宽 CSP/协议权限。
5. 通过统一命令注册提供“阅读主题：纸页”“阅读主题：墨夜”两个零参数中文命令面板入口，复用面板键盘操作；不增加源码可见入口，不挤入只含模式 toggle 的悬浮工具栏，不新增设置页。读取实时窗口/冻结/IME 上下文：冻结或输入组合期间不应用切换，命令与实际处理双重检查；无活动阅读文档也可设置窗口选择，下一次阅读生效。
6. 切换仅替换阅读容器的主题标识/变量，不调用 canonical.request、不变更解析配置或原文 revision，不重建阅读节点/编辑状态。捕获当前阅读块位置与视口偏移，样式提交后按现有有界定位恢复；不以重新解析换取布局刷新，不增加每键全文遍历。相邻快速切换只应用最后选择与对应位置恢复，清理过期布局回调。
7. 静态 CSS 编译错误由构建检查阻断，不承诺运行时检测所有样式缺失；注册结构与无效 ID 通过受控检查验证，运行时无效选择保持原主题并给中文提示。普通日志不含文档、路径或主题正文，不读取用户包。

## 最小 happy path 与验证计划

- 打开两篇阅读文档，通过命令面板选择另一主题：当前正文外观改变，切到另一文档同样应用，编辑/源码及 App 外壳不变；重新激活已打开文档不重置选择。
- 在带 BOM/混合换行长文中部切换主题、重复切换并切换模式；同内容块附近位置保持，正文、dirty、编辑选区/撤销与磁盘字节不变，不承诺像素绝对相同。
- 自动验证同一正文解析结果/请求计数及受控 DOM 节点身份保持，不因换主题重启 Worker；记录真实样本布局行为，不预设耗时门禁或性能收益。
- 窗口状态工厂的两个独立实例互不串扰；重建实例使用默认值，不声称已验证未来原生多窗口或会话恢复。无效主题 ID、冻结/IME、快速切换和卸载有受控回归。
- 检查两个 theme.json/theme.css 的主题数据与样式经构建进入产物、CSS 作用域和禁止资源模式；不要求构建后保留源文件名。真实 WKWebView 离线切换两个主题，浅/深/系统 App 外观与阅读主题独立，中文命令可键盘操作、焦点可辨，位置不跳顶。
- 构建按规则递增 alpha 并核验版本，独立双轴复核后进行受托代验；真实工具超时按用户要求间隔重试，不能用合成状态冒充实际操作，失败在本片修复并复验。
