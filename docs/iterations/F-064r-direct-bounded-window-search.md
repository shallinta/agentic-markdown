# F-064r 普通窗口有界正文直接匹配

> 状态：alpha.204 已通过本片非离线受托代验和独立复核。

<!-- obligations: none -->
<!-- deferred-obligations: OBL-006, OBL-018, OBL-026, OBL-035 -->

## 功能

普通窗口当前有界的单根与多根查询，对已授权读取的原文直接匹配字面量。仍区分大小写，每篇返回首个 UTF-16 命中。文件名、路径与根筛选、未保存正文覆盖、定位和异常提示继续沿用已验收的入口。

F-064q 的两批已读取 64 KiB 样本显示，直接匹配的查询成本最低。本片应用于既有 16 根、筛选前 16 篇和正文 64 KiB 范围。原生会话保留给隔离实验、测试和后续持久索引。

## 最小实现

1. 在现有工作区快照查询保留共同的根与条目校验、描述符读取、字节预算、SHA 和 UTF-8 解码。在普通窗口接入直接匹配策略，走同一份覆盖与打开文档配对。
2. 直接匹配不创建原生索引会话或临时索引目录。返回前再次核对参与根的物理授权和当前版本，包括筛选后没有候选的根。取消和根失效不产生部分结果。
3. 原生策略仍走既有入口，沿用其会话、清理和 `UNKNOWN` 规则。直接匹配仍由 Bun 处理，渲染端沿用搜索结果验证及定位 RPC。

## 最小验收

- 自动对照直接和原生的覆盖、摘要、BOM/CRLF/中文与 emoji 偏移、筛选及空命中。覆盖总字节上限、取消和根失效，验证直接路径无原生索引会话。
- 正式包复跑定向。真实 WK 窗口回归两根查询、不同根定位、未保存覆盖与正常退出。性能证据沿用 F-064q 固定输入范围，本片记录实际窗口行为。

## 继承约束检查

- F-002 沿用本地授权和正文查找，离线留最终人工。
- 中文与外观沿用现有搜索面板和错误提示。
- 命令与键盘沿用已有入口、范围与结果按钮。
- 安全与日志方面，正文继续经 Bun 描述符读取，摘要和不透明句柄用于匹配及定位。筛选和正文不进入日志。

## 实际验收

- macOS arm64 unsigned canary `0.1.0-alpha.204`，包标识 `2cjcx4be3673w`。包内 Bun 1.4.0 和正式原生资源复跑 14 项通过，7 项条件外层跳过由隔离子进程执行。直接场景单独复跑，26 条断言通过。
- 直接与原生策略在实际授权两根上返回一致摘要、字节数、BOM/CRLF、中文与 emoji 的 UTF-16 命中。直接查询在原生索引临时槽被占用时仍成功，未发出索引 Worker 操作。验证单根、多根、路径筛选、大小写零命中、总字节上限、取消、扫描代失效及零候选根被替换后的整批拒绝。原生隔离场景通过，规格与规范独立复核无阻断。
- 真实 WK 窗口查询两个同名根，两个结果分别打开甲组、乙组文件并定位。新增未保存的乙组词得到仅乙组的内存命中 `[12,17)`，定位保留未保存状态，撤销后旧命中失效。正常退出，夹具 SHA 不变，窗口与包测临时目录均为空。
- 源码全量 1863 项通过、10 项条件跳过、1 项失败，共 38,928 断言。唯一失败为既有 FINAL-ISSUE-002 长空白用例超时。类型、Lint、文档、义务登记、锁文件和差异检查通过。F-064q 的成本数据限已读取的固定输入，真实窗口本轮核对交互与一致性。
