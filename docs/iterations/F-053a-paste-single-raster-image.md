# F-053a 系统位图粘贴入站验证

> 状态：alpha.273 隔离实验已由 Agent 受托验收。正式写盘和编辑事务由下一片承接。

<!-- deferred-obligations: none -->

## 功能说明

用合成位图确认打包 macOS 主窗能否从真实系统粘贴得到单个文件，再把有界字节传给 Bun。实验只返回字节数和摘要。依据 [F-053](../mvp-product-spec.md) 和 [E-24、E-25](../product-capability-register.md)。

## 最小方案

- 隔离包同时启用 `AGENTIC_MARKDOWN_PERF_LAB=1` 和 `AGENTIC_MARKDOWN_PERF_PASTE_IMAGE=1`，仅打包主窗接入探针。普通窗口保持原入口。接收真实粘贴事件，只允许单张 PNG 或 JPEG 文件且没有文本类型。文件读取、编码和 RPC 各自核对长度，同一时间只保留一个意图。
- 走已有主窗 JSON RPC。1 MiB 原字节最多 1,398,104 个 Base64 字符，另计 JSON 信封。Bun 以双开关及打包路由复核，校验请求版本、ID、解码长度和规范编码，只回传 ID、字节数及 SHA-256。实验没有文档、路径、写盘权限或正文操作。
- Electrobun 锁定 SDK 的浏览器 `createTransport` 与 `sendMessageToHost` 经宿主套接字或原生消息桥发送序列化 JSON。RPC `maxRequestTime` 是时限，既有图片下行读取上限与本片入站能力分开。

## 最小验收

- 以系统复制及粘贴核对小图、接近上限和超限位图。以独立接收端实际拿到的文件摘要比对 Bun 回执，转码前的源文件摘要单独记录。
- 纯文本不走位图 RPC。源码固定 1 MiB 恰好通过、1 MiB 加 1 字节拒绝，另核不规范编码及开关关闭。普通启动无探针，测试实例正常退出。

## 继承约束检查

- F-002 本机合成剪贴板，不断网，最终离线留人工。
- 中文与外观沿用现有壳层主题和中文提示。
- 命令与键盘沿用系统粘贴，无新增快捷键。
- 安全与日志不读文档，不记录剪贴板内容、图片字节或路径。

## 验证记录

- macOS arm64 unsigned alpha.273，包标识 `3t1sdjmhg44vu`，归档 SHA-256 `9649ca647cf2d05141d1c2a1670d3e756eea499fd7567e806bb27ff5b36db066`。隔离双开关实例的真实系统粘贴已到 Bun；普通实例显示常规欢迎页。
- Safari 将合成 PNG 放入系统剪贴板。小图在剪贴板实测 726 字节，大图 885,352 字节，近上限 1,043,090 字节。三档在独立 Safari 粘贴接收端和 Bun 的长度、SHA-256 一致。最近一档摘要为 `d6930aa1cf95eb8ffd5de6381f44d62bf807db3e1fda4cf5ee72ba53343f7da7`。剪贴板可转码，因此未把转码前的 PNG 文件当作入站字节。
- 1,049,234 和 1,490,957 字节的系统位图均在传输前提示超限。纯文本提示需一张 PNG/JPEG。两个测试实例分别自然退出 0，临时目录无残留，F-056a 三份合成 Markdown 摘要不变。验收使用合成数据，系统剪贴板最后为合成 PNG。
- 源码及独立定向验证覆盖恰好 1 MiB、上限加 1、非规范编码和禁用；实际剪贴板未测到恰好 1 MiB 或 JPEG。此片不证明正式图片写盘、原图字节保真、相对链接或撤销；F-053 保持开放。
- 同包全量仍有一项已登记的长空白用例超时，计数见 [F-056a](F-056a-copy-independent-reading-selection.md)。
