## 功能说明

混合会话保存新测量位置时，可从已授权的磁盘正文计算 Markdown 块锚点。目录文件和独立文件都使用同一规则。

## 最小方案

- 复用已保存正文核验及现有后台解析。可信混合入口可核对目录授权和独立文件授权。每次写入最多尝试一篇新测量文档，优先活动项。已存锚点和同一正文的相同几何可直接沿用。
- 计算结果必须匹配当前正文摘要和视口。读取失败或来源凭据失效时拒绝发布。无可用块、解析忙或新增锚点会超出记录容量时，保留可用坐标和比例。
- 块锚点仍随正式混合记录受控写入，遵循已有位置合并、备份和旧记录终检规则。显式清除归属、普通窗口保存与混合恢复继续承接。

## 最小验收

- 用真实目录和独立文件的授权正文，先后验证两种来源的新块锚点、一次最多计算一篇、旧锚点沿用及另一进程读回。
- 验证计算途中替换正文或撤销授权、块不可用及记录容量，复核权威、备份和正文原字节。普通 WK 回归带位置的目录恢复及正常退出。

- 包内 Bun 运行工作区源码，用真实目录和独立文件授权及原样磁盘正文执行后台解析。活动标签先计算，下一次测量计算另一篇。相同位置无需重算，另一进程读回两类锚点、坐标和偏移一致。真实无块位置保留坐标和比例。独立文件正文保留 BOM 与 CRLF，原目录入口仍只接受目录授权。
