# F-064bc 移除已确认的空待回收目录

> 状态：alpha.240 已通过本片非离线受托代验。前置 F-064bb 提交为 `3318af6`。

## 范围

只移除已经确认且仍为空的固定待回收目录。保留私有槽、v3 清单、历史名册和空目录确认记录。开发验收仅操作隔离夹具。

## 最小实现

1. 内部显式请求提供范围键、代数和 v2 摘要。取得合法租约后，核对三份固定记录的字节、身份及绑定关系。只接受原名缺失，且待回收目录为原身份且确实为空，或固定待回收名已缺失。额外成员、链接及记录不符均拒绝。
2. 持有私有槽和待回收目录描述符，临操作前复核目录、三份记录、租约和调用方。原生入口只对固定名称调用 `unlinkat` 的空目录移除形式。非空目录由系统调用拒绝。
3. 通过系统调用结果、持有目录描述符的稳定身份及固定名称缺失复核移除，同步私有槽描述符后再次核对三份记录及租约。同目标的缺失重试只同步并复核已有状态。结果无法确认时返回 `UNKNOWN`，保留三份记录。
4. 三份记录保留到后续收尾，旧入口继续拒绝该布局。没有自动清理、遗留租约解除或槽位复用。

## 最小验收

- 正式原生隔离夹具经单成员清理及空目录确认，移除固定空目录后记录与私有槽保持原样。新进程重复调用报告固定名称已缺失。
- 覆盖重新出现的文件、目录替换、链接、取消、租约及移除后同步失败。同目标重试保留记录。单独验证原生入口不会移除非空目录。
- 包内定向复跑，实际 WK 回归普通搜索和定位。

## 继承约束检查

- F-002 沿用私有 App 数据边界，离线留最终人工。
- 中文与外观沿用普通搜索界面。
- 命令与键盘没有新增窗口入口。
- 安全与日志方面，调用不接收任意路径，只返回缺失状态。
