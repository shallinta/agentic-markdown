## 本片范围

给 F-064h 的单文件夹结果添加键盘可达的打开定位入口。复用现有主区持久标签和文件树授权打开，已有标签继续沿用原缓冲区。复用关系和 F-063a 相同，完整 F-032 的跨区域路由、预览、阅读子窗口和副区仍由各自迭代承接。

命中只定位到其原内容版本。版本、目录代数、文件身份、编辑器实例或操作意图失效时，提示重新查询。点击结果不会刷新、保存或覆盖已有标签中的未保存正文。

## 准备与 Bun 核权

1. F-064h 已返回每个覆盖条目的实际读取 SHA、可选首命中和可信的打开句柄配对。结果展示时为每项保留这些证据与原查询，未保存命中还绑定已配对编辑器的实例和缓冲区版本。点击先核原结果仍有效，同步签发一次性定位意图。此后的意图使用独立的窗口、文件集合及文档目标检查。现有 `load` 会发布 `busy`，不能一直用 F-064h 的整体捕获谓词作为定位守卫，否则本次正常打开也会使自己失效。
2. 专用准备请求绑定同一普通窗口的 RPC 和工作区，只携带请求 ID、根句柄、扫描代、文件条目、期望磁盘 SHA，以及需要复用打开标签时的已配对句柄和文档版本。路径、正文、编辑器实例和客户端 clean/dirty 标记不进入请求。当前 `workspace.open` 校验根与条目，但请求没有扫描代，也没有索引版本承诺。搜索准备需校验当前根、精确代数、完整扫描、可见条目与文件身份，并复用现有根链和描述符授权。期望 SHA 只是比较条件，不能授予文件访问。
3. 对未打开的磁盘命中，沿用文档授权打开和持久标签路径。用这次实际读取生成的文档快照 SHA 比对搜索证据。在 `openAuthorized` 提交前复核根、条目、文件字节及请求寿命。Bun 和渲染端采用同一份完整快照校验。准备回执失效或未被采纳时释放新句柄，必要时等待正在进行的保存和写屏障结束。正常文件树打开接口语义保持原样。
4. 对已打开标签的命中，无论来自磁盘或内存，都走复用分支。Bun 按同窗现有 grant、文档身份、作用域与当前扫描条目重新核对配对，用受控描述符重新核对实际磁盘 SHA 与索引基线。该路径只做授权和版本确认，不再读入编辑器、不替换 handle、不更新缓冲区。实际磁盘变化、scope 失效、未知或多义配对均拒绝。现有状态代数、取消及收尾规则继续生效。

## 激活后定位与焦点

1. 只采用准备响应所绑定的目标。未打开目标走现有打开保护和文档响应验证，增加在收到响应、接受标签前和可能的异步确认之后的意图检查。当前 `openWorkspaceEntry` 的 `current()` 只在入口与受保护的发起边界检查，不能独自用于这个异步定位。已有目标按现有主标签激活；若期间发生新的打开、标签切换、根代变化、结果关闭、查询变化或用户操作，废弃旧意图。已由当前意图正常打开、而随后发现定位版本失效的标签可以保留，不能应用旧区间。
2. 选择区提交前检查目标仍是活动文档且匹配准备响应。磁盘命中要求本次文档 SHA 等于搜索 SHA，且当前编辑原文仍等于该磁盘基线。内存命中要求相同 handle、documentId、基线 revision/hash、编辑器实例和准确的缓冲区 revision。保存状态不明、外部风险、故障态、IME 合成、冻结或已撤销时拒绝。对当前 `rawText` 验证 `[from,to)` 边界及对应字面量，并用现有 `editorOffset` 转为 CodeMirror 坐标。用 `rawOffset` 检查两端可往返；夹在 CRLF 中间的端点不得钳制成其他范围。
3. 沿用 `MemoryEditor` 当前活动视图的注册和就绪检查。定位票据只消费一次，注册或实际提交时再核同一视图、当前 editor state、活动文档、工作区及操作意图。目标视图尚未挂载时可等待这次激活对应的注册，取消或其他用户交互后立即失效。选择区和滚动在同一无内容修改事务中提交，不进入撤销历史。首片只处理可见编辑器范围，折叠内容或无可定位编辑器的模式显示明确提示，保持现有模式和折叠状态。
4. 本片定位只提交选区和滚动，保留操作时的焦点。搜索激活显式抑制该目标挂载时原有的自动聚焦，等待视口恢复完成后再提交一次定位。普通标签激活继续沿用原来的焦点行为。用户聚焦别处或启动另一操作时废弃旧定位。打开结果期间不锁住后台的正常保存或编辑。

## 最小验证

- 实际普通窗口从磁盘命中打开未打开文档，确认在含 BOM、CRLF、中文和 emoji 的夹具中选中准确正文，且滚动到目标。已打开标签的磁盘命中复用标签。只读文档仍可在可定位视图选择。
- 从未保存命中激活同一已打开文档，确认 handle、内容、撤销历史及磁盘字节不变，准确选中内存命中。编辑后撤销到原字面量也不能复活旧票据。
- 点击到准备回包间替换文件、修改正文、撤销根或更新扫描代。提交前失效须拒绝发布新授权。已完成准备而尚未采纳的句柄须释放，旧结果不可移动选择或焦点。覆盖重复点击、手动切换标签、聚焦其他控件、关闭结果与迟到挂载。
- 模拟不一致 SHA、错误范围、CRLF 中间端点、文件身份不符和伪造句柄。覆盖 IME、冻结、折叠、编辑器故障及前后台文档切换。新包验证真实查找、选区、退出和回收。

## 实际验收

- macOS arm64 unsigned canary `0.1.0-alpha.196`，包标识 `2rh9v8tjr09wj`。直接启动解包后的应用，用独立数据目录和两份自建夹具验收。
- 真实 WK 窗口查询覆盖两篇。键盘打开磁盘命中 `[533,538)`，新标签滚到含 BOM、CRLF、中文和 emoji 的长夹具文末，画面仅选中五个汉字，AX 焦点仍在原结果按钮。编辑另一篇后查询到未保存命中 `[18,23)`，键盘定位保留按钮焦点。切到另一标签后再点击此命中，原未保存标签重新激活，正文仍为未保存。一次撤销移除测试插入并使旧命中失效。两份磁盘文件 SHA 与测试前一致，`⌘Q` 正常退出且查询临时目录为空。
- 独立 Spec 与 Standards 复核无阻断。源码定向 56 项通过，覆盖提交前磁盘变化、取消和废纸篓未知状态，以及无效快照及授权回收。渲染定向覆盖视口就绪、选区、折叠、短暂输入阻挡、编辑再撤销与程序化激活交错。包内 Bun 1.4.0 配合正式原生资源复跑 8 项通过，外层 3 项条件跳过由隔离子测试运行。
