## 功能说明与范围

在 F-025a 目录工作区中，阅读模式图片可使用文档当前所属授权根内的资源。例如 `root/notes/a.md` 引用 `../assets/a.png` 时仍相对 Markdown 所在目录解析，`root` 只限定读取授权，并非链接解析基准。独立文档仍以其父目录为资产范围；显式隐藏独立文件不因存在外层目录而自动扩权。

已被扫描实际覆盖的普通独立文档，以及子根被父根吸收后的派生文档，由后端明确迁移资产授权；文件树移除重复项不等于授权已迁移。当前内存正文及 documentId、dirty、历史、模式和位置不变，不通过重新读取正文刷新权限。

硬前置为 F-025a 目录归属/授权、F-022a 安全图片服务与阅读池、既有当前文档状态与阅读消费者。本片局部承接 OBL-010/031，无延期 ID 不代表完整义务关闭。仅沿用 PNG/JPEG 阅读能力，不新增格式、远程加载、编辑消费者、跨根 capability 组合、watcher 或正式移除根 UI；父 F-022 和完整义务开放。

## 最小技术方案

1. 后端根据已验证的文档归属构造不可变 asset scope 快照及独立 asset epoch（资产授权代次），不复用扫描 generation。Renderer 仍只发送文档 opaque handle 与相对引用；Worker strict schema 的授权范围仅由主进程提供。独立文件转实际目录覆盖、子根被父根吸收、保存身份更新与撤销均复核归属，不能只消费 `coveredHandles` 的 UI 去重信息。
2. 沿用 F-022a 的单次路径解码、realpath 范围发现与 Node-API fd 相对安全读取、祖先/目标身份复核、固定 PNG/JPEG MIME 及资源预算。解析基准始终为 Markdown 目录；读取前后校验捕获的不可变 scope 与 epoch，拒绝陈旧授权和旧回执。不通过路径前后检查替代 fd 安全，不宣称文件系统快照原子性。
3. 授权变化以 metadata-only 更新通知前端资产代次；不读取或替换正文，不改变正文 revision/磁盘基线，也不新增每键全文处理。阅读池清理旧成功和失败缓存，忽略晚回执并重新按新授权获取当前需要的图片；主题切换不变更 scope，不重取已缓存图片。保留文档状态、阅读位置与受控 DOM 安全边界。
4. 缓存身份包含文档及资产代次，跨文档同名引用隔离；离开、关闭、撤销与销毁沿用清理。失效只表示旧结果不得使用，不冒称 Worker 阻塞 I/O 硬取消。沿用当前有界队列、字节/像素/缓存保护，变更须记录实际测量；不设新性能门禁或声称 RSS 降低。
