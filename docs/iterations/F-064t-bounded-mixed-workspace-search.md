# F-064t 目录与独立文件的有界查询

## 范围

给 Bun 内部增加混合查询。调用方传入当前窗口的完整目录根列表，以及本次要查询的已授权独立文件句柄。目录列表可以为空。此接口供后续窗口接入，调用方仍需给出完整的顶层独立文件列表才能覆盖整个窗口。

目录与独立文件共享最多 16 篇候选、合计 64 KiB 正文的限额。保留现有文件夹查询。普通窗口范围控件、传输及独立文件定位由后续切片接入。

## 最小实现

1. 沿用同一查询占用位，检查整个目录根列表和一份文档准入。对打开文档与独立文件句柄取并集捕获，返回时仅为调用方提供的打开文档生成映射。
2. 同一路径和文件身份已经出现在可见目录扫描结果中时，使用目录条目。隐藏文件若仍留在顶层且授权有效，按独立文件处理。身份不一致时整批拒绝。
3. 独立文件复用保留授权，以文件名参与文件和路径筛选。目录和独立文件使用同一字面量匹配与字节预算。筛掉的文件只校验授权和身份，不读取正文。
4. 在异步读取、映射和返回前复核取消、目录根列表、文档授权及废纸篓状态。查询保留磁盘快照摘要及打开文档的基线，供后续安全定位和未保存覆盖核对。

## 最小验收

- 无目录时读取已关闭标签的独立文件，核对命中、SHA 和 UTF-16 区间。打开的独立文件可映射到原版本，外部原地修改后能区分磁盘摘要与基线。
- 两个目录和独立文件共用范围。验证可见父目录吸收后不重复，隐藏独立文件仍可查，授权不同的硬链接路径各自保留。
- 验证候选与字节上限、筛掉大文件、撤权、替换、废纸篓隔离和进行中失效。包内复跑，真实 WK 窗口回归文件树与已有目录查询。

## 继承约束检查

- F-002 沿用本地文件授权。离线留最终人工。
- 中文与外观沿用已验收入口，本片无新增控件。
- 命令与键盘沿用现有搜索入口。
- 安全与日志方面，只使用已授权目录和独立文件。正文、路径和授权凭证不新增日志。

## 验收结果

- macOS arm64 unsigned canary `0.1.0-alpha.206`，包标识 `13skpqbbtkwyl`。包内 Bun 1.4.0 和正式原生资源复跑准入、快照和现有 RPC，22 项通过、8 项条件跳过、128 条断言。隔离混合查询单独复跑 33 条断言通过，包括根列表中途变动、共享限额、路径去重、撤权和隔离。
- 真实 WK 窗口关闭独立文件标签后，顶层文件仍在。加入甲、乙组两个同名文件夹，原有全文件夹查询覆盖两篇，并以目录区分两个 `[5, 10)` 命中。乙组结果打开并定位正确。三份夹具 SHA 不变，⌘Q 后启动器退出码 0，临时目录为空。退出记录包含一条 IMK 日志。
- 源码全量 1868 通过、11 项条件跳过、0 失败，38958 条断言。此前已登记的 FINAL-ISSUE-002 保持开放。类型、Lint、文档、锁文件及差异检查通过。独立规格复核无阻断。
