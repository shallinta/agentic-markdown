## 功能说明

通过显式实验入口，把主窗当前已授权文档的一份已保存快照交给独立阅读窗。阅读窗从收到的正文解析，不打开文件。首轮验证一次性投递和字节保真，正式入口、未保存同步和主窗模式迁移另行承接。

## 最小方案

- 主窗只提交现有文档凭证、身份和已保存的版本及摘要。Bun 文档服务重用现有有界读取和授权核验，读取的字节须匹配该已保存版本，并核对对应文档的观察绑定。首轮入口只在当前主窗文档干净时可用，最多投递 64 KiB，实验上限留在该入口。
- 阅读窗仍不启用 RPC。独立固定入口等待一次由 Bun 单向投递的有界数据。正文经 Base64 传递，子窗还原 UTF-8 后复用现有阅读解析与安全呈现。无文件路径、授权凭证和外部导航。投递前复核窗口归属、导航目标及请求有效性。
- 原生投递 API 无送达回执，验收以真实窗口显示为准。一次成功调用只代表已提交对应快照。关闭、失败和晚到事件应收回本轮引用。

## 最小验收

- 从实际 WK 主窗选择合成的已保存文件，通过实验入口在阅读窗显示内容。核对 BOM、CRLF、中文、emoji 与特殊符号，拒绝超限、错误版本和过期请求。
- 验证关闭阅读窗后主窗仍可编辑。阅读窗不会写原文件，普通启动没有实验入口。

## 继承约束检查

- F-002 沿用本地边界，离线留最终人工。
- 中文与外观以明确实验入口提示快照含义。
- 命令与键盘沿用现有选择和关闭，正式命令待接入。
- 安全与日志方面仅在现有授权内读取，子窗无 RPC，日志无正文和路径。

## 验收记录

- macOS arm64 unsigned alpha.263，包标识 `28g0jfzp8nal4`。独立核对 19 项源码摘要、固定阅读入口、CSP 与包内投递路径，11 项原生资源与 alpha.262 逐字节一致。包内 Bun 独立复跑 13 通过、121 条断言。源码定向 90 通过、853 条断言。源码全量 1947 通过、55 跳过、0 失败、39787 条断言。类型、Lint、文档、锁文件和差异检查通过。
- 实际 WK 从主窗打开带 BOM、CRLF、中文、emoji、引号、反引号和反斜杠的合成文档。实验入口打开独立阅读窗，原正文显示并通过安全检查。源码与包内测试核对编码往返字节一致。
- 主窗后来修改后，阅读窗仍显示已保存版本，实验入口禁用。红灯关闭阅读窗后主窗可撤销，原快照可重新打开。65,537 字节文档可在主窗打开，但实验入口禁用。普通启动无该入口。两次启动器均以 ⌘Q 自然退出，夹具摘要相同，临时目录为空。
- 正文投递只发生一次，回执只记录已提交；实际显示由 WK 观察确认。投递前凭据检查限于 Bun 内逻辑状态，读取时已校验磁盘字节，投递不重新读盘。64 KiB 是本轮实验限制，正式入口、更多容量、未保存同步和旧主窗阅读迁移仍待接入。OBL-029、F-041d 冻结和最终离线保持开放。
