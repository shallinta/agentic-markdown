# F-056a 复制独立阅读窗的纯文本与安全 HTML

> 状态：alpha.273 已由 Agent 受托验收。前置独立阅读窗及已验只读正文。

<!-- obligations: none -->
<!-- deferred-obligations: none -->

## 功能说明

在独立阅读窗选择正文并使用系统复制，同时提供可见纯文本和保留基本排版的安全 HTML。代码缩进和正文换行跟随选区。输出排除应用按钮、诊断、链接目标及内部属性。富文本超出复制预算时提示并提供完整纯文本。

## 最小方案

- 在真实系统复制事件中处理当前已审计阅读正文。只读取当次选区，允许将全页选区裁剪到正文，搜索栏等输入控件沿用原行为。按 [W3C 剪贴板事件规范](https://www.w3.org/TR/clipboard-apis/#overriding-the-copy-event) 同步写入纯文本与 HTML。
- 在现有受控 DOM 上有界遍历选区。富文本只输出固定安全标签和转义文字，不输出原 HTML、运行时属性或外部资源。纯文本与富文本来自同一选区，正文成本越界时明确提示，不产生部分内容。
- 保持沙盒和固定 CSP，剪贴板由用户复制手势触发。主窗编辑和源码的富文本规则另行承接。

## 最小验收

- 复制包含强调、普通文本、链接名和代码的选区，核对系统剪贴板纯文本与富文本表现、换行和空格。确认按钮、链接目标和事件属性不出现在导出。
- 验证纯文本降级、搜索输入复制不被接管、关闭后下一窗口无旧状态。只使用合成文本和独立接收目标。

## 继承约束检查

- F-002 本机剪贴板，最终离线留人工。
- 中文与外观沿用阅读窗，降级与错误提示用中文。
- 命令与键盘通过系统复制事件，支持已有 ⌘C 和菜单复制。
- 安全与日志维持正文审计，输出采用静态标签，日志不含选区。

## 当前验证

- 复制事件仅在普通阅读窗中已审计的当前正文生效。纯文本保留代码空白，富文本仅保留固定标签，无链接目标、DOM 属性或外部资源。
- 富文本上限为 256 KiB。正文投影另有 32,768 个节点、128 层及 1 MiB 纯文本上限，超出时明确提示且不写部分内容。因此本片不能承诺所有可打开文档的任意选区都能降级为纯文本。编辑模式、源码模式及完整 X-17 继续登记。
- 定向 23 项、229 条断言通过，独立相关定向 26 项、241 条断言通过。类型、全量 Lint、文档、锁文件及差异检查通过。独立复核核对了事件、裁剪、HTML 转义和预算边界。
