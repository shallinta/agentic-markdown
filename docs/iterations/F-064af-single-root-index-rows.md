## 范围

从一个已授权且扫描完整的目录读取当次扫描清单中的 Markdown 正文，为后续索引复用准备行记录。本片只在 Bun 内返回内存快照。索引写入、窗口入口和未保存内容合并继续由后续承接。

## 最小实现

1. 在同一个有界任务中核对范围身份，按捕获的完整扫描清单逐篇授权并稳定读取。允许空清单。上限为 16 篇、合计 64 KiB 原始字节。按 UTF-8 严格解码，保留 BOM 和换行。
2. 用范围键与规范相对路径生成版本化、32 个十六进制字符组成的行 ID。同一路径在新扫描确认文件身份后可复用 ID，改名产生新 ID。重复行 ID 或相对路径拒绝整批。
3. 返回前逐篇复核授权、文件身份、大小和修改时间，再核对根目录、扫描状态、取消及废纸篓隔离。文件描述符逐篇关闭，任何失败都不返回部分正文。提供重新校验凭据，供后续消费方在操作前后再次核对。逐篇检查只证明实际观察到的版本，跨文件原子快照不在本片范围。

## 最小验收

- 隔离目录验证空清单、同名不同路径、BOM、CRLF、非 BMP 字符、正文更新、替换后重扫与改名。
- 验证超限、无效 UTF-8、取消、废纸篓隔离及逐篇读取过程中先前文件被改写。确认没有部分返回、残留描述符或缓存。
- 包内复跑，真实 WK 回归原正文搜索、定位和退出。
