## 功能说明

验证文件树、主区、副区固定从左到右排列时，主副分隔线如何调整两侧宽度。主区与副区各自至少保留 160 CSS px。先在隔离实验台使用占位内容验收，等副区展开入口和文档路由接入后再用于正常窗口。

## 最小方案

1. 沿用现有分栏组件。外层为文件树和工作区，工作区内部水平划分为主区、副区。内部分隔线 1px，占据实际宽度，可拖动并支持键盘调整。
2. 实验台可切换副区可见性，隐藏时主区填满工作区。合计 321 CSS px 时两区各 160px。更窄的实验宿主使用带滚动的最小画布，单独显示宿主与画布宽度。原生窗口最小尺寸另行承接。
3. 仅沿用显式实验开关。正式副区展开入口、打开和拖入文档、纵向平铺、宽度持久化及原生尺寸联动留原功能负责。

参考[分栏组件官方文档](https://github.com/bvaughn/react-resizable-panels)，以仓库锁定的 4.12.1 实际 WK 表现为准。

## 最小验收

- 正式包实际 WK 打开实验台，检查左右顺序、拖动与键盘调整，不改变文件树宽度。分别向两侧拖到下限，确认各自最少 160px。
- 验证 321px 临界宽度、300px 实验宿主、隐藏副区及重新显示。用同一包另起普通窗口，回归普通工作区和正常退出。
