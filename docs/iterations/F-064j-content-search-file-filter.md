# F-064j 单文件夹正文搜索的文件名筛选

## 功能

在现有单文件夹正文搜索面板增加文件名筛选。筛选栏可以输入 `file:笔记` 或 `file:"会议 纪要"`，也可从本根已扫描的文件名中选择并写入同一栏。正文查询仍按原样输入。多个 `file:` 条件需同时满足，区分大小写，以文件名包含该字符串为准。

空筛选沿用已有查询。空值、引号错误、无效字符和当前切片不支持的 token 明确提示。筛选变化使在途查询和旧命中失效。有效筛选无匹配文件时显示覆盖零篇。现有每根 16 篇和纳入查询的正文合计 64 KiB 的范围继续适用。路径、根筛选、跨根和大范围增量索引继续分片实现。

## 最小实现

1. 共享模块解析文件名 token，并供界面选择生成同一语法。传输带有上限的解析值，Bun 复核数组结构和值。限制 8 条、每条 256 个 UTF-16 码元，筛选栏最多 16,384 个码元。拒绝控制字符、斜杠、未配对代理码元和重复值。
2. Bun 对已授权完整根的扫描条目按文件名缩小本次查询范围，再读取正文。Bun 核对授权和文件身份后才将被筛除的标签归为本次查询范围之外。未知配对仍按范围不完整处理。原根和扫描代校验、取消与清理维持现有边界。
3. 渲染端用相同匹配逻辑核对返回覆盖与当前扫描条目。未保存覆盖及点击定位沿用现有版本检查。文件名筛选本身不增加授权。

## 最小验收

- 两篇合成文档正文均含同一词，带空格的文件名经选择或手输可缩到一篇，命中可打开定位。无筛选时覆盖两篇，零匹配时覆盖零篇。
- 自动验证引号和上限、无效 token、文件名与父路径区分、筛掉超限或不可解析正文后仍能查合法文件、筛掉的未保存内容不会混入。真实窗口验证修改筛选后旧结果消失。

## 继承约束检查

- F-002：本地索引和筛选。离线留最终人工。
- 中文与外观：使用中文提示，沿用原有浅深主题。
- 命令与键盘：沿用现有查询入口，筛选使用带标签的输入和选择控件。
- 安全与日志：查询只覆盖已授权目录。筛选值不进日志，不用作路径或授权。

## 实际验收

- macOS arm64 unsigned canary `0.1.0-alpha.197`，包标识 `1q0mfvoruyo0q`。实际 WK 窗口在隔离数据目录中打开两篇合成文档。无筛选覆盖两篇，选择「会议 纪要.md」回填 `file:"会议 纪要.md"` 并清除旧命中。选择器条件与手输 `file:"会议 纪要"` 各覆盖一篇，结果打开正文并准确选中 `[7,11)`。
- 手输 `file:不存在` 显示覆盖零篇；未实现的 `path:` 条件出现行内提示并禁用查询。退出返回 0，测试目录字节与 SHA 不变，查询临时目录为空。
- 独立规格与规范复核无阻断。源码定向 27 项通过，包内 Bun 1.4.0 配合正式原生资源定向 14 项通过。两轮各有 4 项条件外层跳过，由隔离子进程执行，覆盖排除超限正文、父目录名不参与文件名匹配及未知授权保留未决。源码定向另核对被筛除的未保存正文不会加入结果。
- 源码全量 1840 项通过、6 项条件跳过、1 项失败，共 38,728 断言。唯一失败为既有 FINAL-ISSUE-002 长空白用例超时。类型、Lint、文档、义务登记、锁文件和差异检查通过。
- 实际窗口使用系统浅色外观和键盘、指针组合。深色、自然 IME 与断网未复验。离线留最终人工，完整 F-064 和四项延期义务继续开放。
