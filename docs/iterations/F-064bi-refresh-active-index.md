## 功能说明

增加内部更新入口。调用方明确给出范围、预期索引代数、完整目标名册和有效性证明。仅更新同范围的现有 v1 索引，成功回执包含代数、文档数及本次变更数。工作区和窗口继续沿用现有入口。

## 最小方案

1. 复核私有槽、原清单和索引布局，在同一租约内计算有界增删改。沿用 limited-v1 的名册和单批变更限制。超限或原代数不符时拒绝。
2. 有变更时以原代数打开写入会话，提交一批并确认关闭。保持索引目录身份，重新核对提交后的文件。随后只读重开，用完整目标名册核对原生代数和全部文档。无变更时仅执行只读核验。
3. 调用方磁盘证明和完整名册都通过后，才可在持有槽目录时替换已核对的原清单。同步、读回并复核后返回。无变更时保留原清单。
4. 关闭不确定时保留租约，收尾或发布不确定时返回 `UNKNOWN`。若原生更新已提交而清单未能发布，旧清单与新索引可能代数不匹配，严格入口拒绝使用。已知失败也可能留下新代数，回执中的 `accepted: false` 只表示本次请求没有待确认的成功回执。自动恢复及默认更新尚未接入。
