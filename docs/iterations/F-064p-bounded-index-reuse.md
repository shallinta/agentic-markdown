## 范围

用一个隔离私有缓存槽验证固定授权范围的索引复用。输入是调用方刚验证过的受控快照和继续有效的守卫。模块用当前正文核对内容 SHA，索引和清单只使用匿名 ID。冷启动创建索引，内容和 ID 集合未变时重开后直接查询，单篇变化时提交对应增量。

本片验证一次复用与有界变更，仍适用 16 篇、64 KiB 和单批最多 16 项变更。窗口继续走已验收的临时索引。默认缓存目录、授权撤销清理、监听驱动更新、容量策略和最终离线由后续迭代承接。

## 最小实现

1. 缓存槽由测试提供，目录私有。用排他租约串行访问索引与清单。清单记录当前 schema、`limited-v1` 配置、匿名范围键、原生代和匿名 ID 对应的 SHA。以有界读取和精确字段校验拒绝无效、超限或未来清单。清单缺失但原生索引已存在时拒绝重用。
2. 沿用 F-064d 的 `writer-existing`。原生打开代与清单不符时拒绝。根据当前快照计算删除与写入；空增量跳过写入。成功查询并关闭原生会话后，在租约内重新核对守卫，再原子替换清单。发布前失效时保留旧清单；若原生代已前进，下次重开会识别失配。发布后失效也拒绝返回命中。未知清理结果优先返回未知。
3. 限定规模内，用当前原文逐项核对命中，防止错误缓存产生漏命中或错位置。守卫在各异步边界生效。租约未释放、无效索引或清单失配时保留现场，由调用者显式重建或回到已有临时索引。原生关闭不确定时保留索引和清单，显式复试仍须通过原生写锁与代数核验。此轮不据此推断大文档性能或磁盘读取减少。

## 最小验收

- 隔离原生测试核对冷启动、同内容重开零写入、单篇更新一次写入、删除与清空后重开，验证 UTF-16 命中和提交代。
- 验证外来范围、未来 schema、损坏清单、缺失清单与原生代失配均拒绝；取消后无迟到结果；同时请求不能争用槽；正常关闭无残留工作进程或租约。
- 用正式包 Bun 和原生资源复跑有界实验，真实窗口回归现有文件夹搜索及退出。
