# F-037n 显式关闭恢复标签后清空会话记录

> 状态：alpha.335 普通窗口代验通过。

## 功能说明

重新授权后自动恢复单篇标签，随后显式关闭最后一篇标签。清空记录提交后，下一次启动并重新授权时不再恢复它。取消关闭、直接退出或在清空发出前开始退出时保留历史。已换代的记录受原字节核对保护。

## 最小方案

- 恢复授权被同一普通窗口采纳后，Bun 才能在同一会话写入队列中认领与恢复回执完全匹配的历史记录。认领本身不改磁盘，重新读取须确认原始字节、观察代际和窗口生命周期。恢复正文仍可使用，即使记录无法认领。
- 显式最后关闭沿用现有空记录发布。恢复确认尚在途时，先保留同一标签的普通记录意图，避免同字节写入抢先使认领过期。最后关闭可以替换这次记录，等待后复核关闭意图和当前空标签状态。新打开、导航、清空或退出使旧意图失效。
- 清空按原始字节核对权威记录，沿用现有备份写入。保留普通打开、退出、目录与 Markdown 的行为。

## 最小验收

- 普通 WK 恢复一篇固定源码标签，显式关闭并正常退出。原记录已成为备份，权威记录为空。重启并重新授权，同一文件可在文件树看到，主区没有自动打开它。
- 普通 WK 对照直接退出和取消丢弃未保存变更，核对旧记录保留。定向覆盖关闭先于恢复确认、历史换代、旧意图失效和未知确认。
