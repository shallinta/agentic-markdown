## 功能说明

普通主窗口可在打开独立文件后记录已保存的标签，包括同窗的目录文件。关闭标签时同步更新当前窗口已持有的记录。仅打开目录文件的工作区继续走现有目录会话保存和恢复。

## 最小方案

- 复用当前的标签激活、布局、滚动和关闭请求。Bun 根据实际文件授权决定写入类型。独立文件无需打开目录，普通窗口的空工作区也能调度会话写入。
- 本次窗口成功写入混合记录后，后续目录标签的变动也更新这份记录。纯目录请求同时维护现有目录恢复所用的记录。关闭操作分别核对当前窗口对两份记录的归属。
- 混合记录仅保存已确认的标签元数据，路径和身份核对在 Bun 内完成。混合记录的重启交付与独立文件重新授权由后续承接。
- 两份记录分别核对和写入。窗口失去混合记录归属后，只能继续更新目录记录，不能用后续纯目录状态覆盖另一实例的混合会话。
- 若权限核对仍在进行，本次保存最多在核对成功后再检查一次。不占用关闭队列。标签、编辑版本、工作区或窗口失效时丢弃旧请求。

## 最小验收

- 普通 WK 从空窗口打开独立文件，确认会话记录。加入目录并打开另一篇，核对两类标签。关闭独立文件后只保留目录标签，关闭末篇后记录为空，备份保留上次状态。
- 普通 WK 回归既有目录记录的重新授权和退出。定向覆盖路由、失效授权、工作区状态和两个记录的归属保护。
