## 功能说明

空窗口显示中文欢迎页，可打开本地 `.md` / `.markdown` 文件。成功读取后仅将该文件加入侧栏顶层叶子，不加入父目录；可累计多个独立文件，重复规范路径只保留一个叶子。点击叶子重新校验授权并读取，只保留活动正文。取消、失败保留已有列表与正文。清空操作清空整个窗口集合并返回欢迎页，不代表正式关闭标签。

本轮仍为只读原文，单文件 1 MiB 上限；不提供编辑、持久标签、会话恢复、文件夹或最近项目的占位按钮。F-009 父功能保持部分完成，文件夹欢迎入口与最近项目分别由 F-025 / F-029 承接。

F-010 / F-011 的入口依赖具体指 F-009a：本切片人工验收后即可满足，不要求等待文件夹/最近项，也不因此将完整 F-009 提前关闭。

## 最小技术方案

复用现有原生选择器、只读文档服务与统一命令。后端保存会话级轻量授权元数据，读取结束关闭文件描述符；规范路径映射为不透明位置 ID，仅用于侧栏去重，不接受渲染进程提供的任意路径。返回的已授权路径仅供文件名悬停提示，区分不同目录中的同名文件，不作为读取参数且不写日志。切换通过句柄重新打开并验证原授权。前端列表仅保存句柄、文件名、位置与文档 ID，不缓存每份正文。复用窗口现有左右布局及顶部拖动区域，不引入依赖。
