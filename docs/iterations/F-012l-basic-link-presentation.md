## 功能说明与边界

在编辑模式为单物理行链接增加基础呈现：光标或选区未触及时显示链接标签并以纯文本样式强调；触及整个链接语法范围时恢复完整原文以便编辑。只承接现有 CommonMark 解析能够确认且明确闭合的行内链接（包含空目标）和尖括号自动链接，不宣称覆盖全部CommonMark链接。源码及安全源码模式不隐藏原文。

多物理行链接整节点保持完整原文，不跨换行隐藏。所有引用式链接（完整、折叠与快捷形式，无论定义是否存在）及引用定义本片都保留原文：当前Lezer会把无定义引用也识别为Link，仅凭节点无法确认引用有效性。本片不增加独立全文扫描或引用索引，引用呈现留F-019/F-042相关后续切片。Image整子树排除，包含Image的外层Link也整节点保留原文；空标签链接如`[]()`保留原文，避免完全消失。

本片不提供点击跳转、URL加载、网络请求、图片呈现、GFM裸链接识别、新命令或链接编辑弹窗。不扩展1 MiB文件上限、后台解析选择、wait策略或既有长行保护。只局部承接OBL-068链接外观责任，其余扩展仍开放；OBL-012完整调度、OBL-020缓存预算余项、OBL-041未来命令留后续切片，父F-012未完成。

HTML边界指HTMLBlock及HTML标签自身保持原文；CommonMark允许解析的行内HTML标签之间Markdown仍按现有解析器正常呈现，不一概禁止。危险协议目标仅为文本数据，不执行、不导航；符合单行行内链接条件时仍遵守统一显隐规则，不要求危险目标始终完整显露。

## 最小技术方案

1. 复用当前语法树及即时排版装饰通道，依据解析节点与直属的明确行内目标闭合标记决定标签及隐藏范围；不能仅凭Link节点装饰引用，也不能要求URL子节点必然存在。仅接受完整位于单物理行的明确行内链接与Autolink，不用正则另造Markdown解释；非空标签加空目标如`[label]()`按明确闭合的行内语法处理，空标签、Image相关及所有引用式链接排除。
2. 使用无导航语义的span样式，不生成href或可点击链接，不把目标URL写入DOM属性或日志。尖括号自动链接只隐藏尖括号，地址正文仍显示；行内链接隐藏标签外的标记/目标/可选标题。嵌套标签样式复用既有支持范围，不引入HTML渲染。
3. 选区或光标触及链接完整源范围时恢复原文，鼠标与键盘行为一致；保留当前IME组合期间、可见范围及长行保护规则，语法未就绪时保留原文，不强制同步全文解析。源码/安全源码不装载此隐藏装饰。
4. 装饰只改变视图，正文、BOM、未触及混合行尾、复制原文、选区坐标、撤销/重做及保存不变；主题变化只更新样式，不新增解析。出现关键范围或路线变化先更新本文件并重新确认。

## 最小 happy path

- 打开含中文标签、行内链接（带/不带标题与空目标）和尖括号URL/邮箱链接的可丢弃样本；光标移出显示标签，移入或选区跨越恢复完整原文。完整/折叠/快捷引用（有效及无定义）、定义、空标签`[]()`、Image内链接`![alt [label](url)](img)`、含Image链接`[![alt](img)](url)`、多物理行Link、代码/HTML上下文作为原文保留边界对照，不误隐藏。
- 用鼠标和键盘选择、编辑目标或标签、撤销/重做，切换源码再返回；原文与历史保持。复制和保存重读核对完整Markdown、BOM及未改动行尾，不因样式丢失目标地址。
- 浅深/系统主题下检查链接可辨识与选区对比；输入中文候选、滚动和长行样本沿用既有保护，既不新增网络/跳转，也不为装饰阻塞输入。真实IME及视觉手感留人工，不用合成测试替代。
