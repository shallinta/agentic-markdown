# F-037o 同目录两篇标签的受保护读取

> 状态：alpha.336 包内 Bun 与普通窗口回归代验通过。

## 功能说明

为同一重新授权目录的两篇已保存标签准备恢复结果，保留历史顺序、模式、固定状态和活动项。两篇都必须满足当前目录和文件身份校验。任一篇失效时整组退出，保留当前会话记录。

## 最小方案

- 复用普通文件读取、目录授权与会话观察。两篇都先解析为同代授权候选，再依次读取正文，每篇读一次。保留读时文件状态，异步复核完成后同步核对两篇的文件状态及授权。相同文件身份的两个路径暂不作为两个恢复对象。两次状态检查分别完成，不能提供跨文件原子快照。
- 只管理这次读取产生的授权，按请求 ID、快照对象和当前句柄核对来源。一篇失败或操作失效时释放此前成功的授权，清理结果未知仍继续处理其他句柄。内部结果按原顺序携带两篇快照和活动索引。本片先验证读取，普通窗口继续使用已验收的单篇恢复。

## 最小验收

- 用正式包内 Bun 和隔离目录，验证跨进程原顺序、混合模式、固定与活动项、当前正文。复核第二篇读取失败、同路径文件替换、会话换代与取消时整组结果不交付，新增授权全部释放或明确未知。
- 普通 WK 回归原有单篇恢复与显式关闭，核对会话、MRU 和 Markdown 字节。

## 继承约束检查

- F-002：本地目录授权和磁盘读取，最终离线留人工。

- 命令与键盘：复用已有选择及关闭操作，本片无新增命令。
- 安全与日志：只读会话与正文。历史路径留在 Bun；失效时禁止保留未交付的可用授权。
