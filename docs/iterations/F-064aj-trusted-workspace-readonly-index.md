# F-064aj 内部工作区严格只读查询

## 范围

将单根授权快照与同名册私有索引接成内部工作区查询，只读取已经存在的索引。普通窗口继续使用直接搜索。本片无需索引冷建、正文缓存写入或其他权限来源。

## 最小实现

1. 调用者用当前根句柄、扫描代和非空白的有界字面查询进入。沿用同一工作区任务槽，完成逐篇授权读取、现有缓存预检和原生名册校验、查询、关闭、磁盘终检。
2. 原生命中只按本次快照映射到当次文件条目与 UTF-16 范围，不把内部行 ID、正文或路径交给调用者。快照不一致、缓存不符、取消或收尾不明时整次拒绝，保留 UNKNOWN。
3. 沿用现有缓存租约，只读查询不创建或更新原生索引。最终复核证明已执行发布前的文件身份核对，无法阻止其后发生的外部变化。

## 最小验收

- 合成目录先用既有测试入口建立缓存，再由新工作区真实扫描并查询。比对 BOM、非 BMP 字符和当前扫描条目的命中。
- 核对缺失、异范围、名册失配、竞争、查询期间取消及同 inode 同长度改写。检查失败无部分结果，租约和索引保留，当前快照不泄漏正文。
- 包内复跑，真实 WK 回归已有正文搜索、定位和退出。

## 继承约束检查

- F-002 沿用当前本地授权，离线留最终人工。
- 中文与外观沿用现有搜索面板。
- 命令与键盘沿用现有搜索入口。
- 安全与日志方面，只读内部查询不新增文件路径或正文日志。

## 验收结果

- macOS arm64 unsigned canary `0.1.0-alpha.222`，包标识 `68sshy98pas3`。包内 Bun 1.4.0 和正式原生资源复跑内部只读、范围、正文快照、授权连验和既有搜索，13 项通过、18 项条件跳过。只读查询隔离场景 55 条断言通过，临时夹具清空。
- 新工作区通过当前扫描条目返回 UTF-16 命中。缓存缺失不创建索引，异范围、名册失配、输入错误和入口取消不启动原生会话。暂停实际原生查询期间，其他同工作区请求返回 BUSY。取消后无命中，改写同 inode、同长度正文后终检返回 STALE。隔离注入租约收尾失败时，即使信号已取消也保留 UNKNOWN 和原现场。正常路径的索引文件和清单摘要、身份及元数据不变。
- 真实 WK 回归一篇两处命中和第二处 `[19, 23)` 定位。桌面工具一次 ScreenCaptureKit `-3811` 错误后恢复同一窗口。夹具 SHA 不变，窗口未创建索引槽，⌘Q 后启动器退出 0，临时目录为空。
- 源码全量 1907 项通过、22 项条件跳过、1 项失败，39377 条断言。唯一失败仍是既有 FINAL-ISSUE-002 长空白超时。类型、Lint、文档、锁文件及差异检查通过。
