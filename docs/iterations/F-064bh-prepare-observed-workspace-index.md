## 功能说明

可信工作区服务可以显式为已授权、已建立观察的一个根目录准备 limited-v1 索引。仅使用磁盘内容，成功返回索引代数与文档数。窗口的现有正文搜索继续沿用原入口。

## 最小方案

1. 验证根目录句柄、当前扫描代数与已建立的观察凭据。在同一个工作区后台任务槽中捕获受限的完整磁盘名册。
2. 复用 F-064bg 空槽准备入口。调用方有效性与逐文件授权、版本复核贯穿写入、只读整份名册核验和清单发布。工作区任务继续持有到完成。保留 `UNKNOWN` 优先级，拒绝已失效的迟到结果。
3. 空槽准入、租约与清单的规则沿用 F-064bg。已有索引更新、跨根、未保存正文覆盖和默认搜索接入继续承接。

## 最小验收

- 用真实扫描和合成观察事件准备一个根目录。未建立观察时拒绝，观察有效时建索引。随后用已有的严格只读入口查询，核对正确工作区条目和 UTF-16 偏移。
- 暂停真实原生名册核验，检查同工作区并发操作返回 BUSY。触发观察失效、取消或同 inode 同长度正文变更后，验证迟到结果被拒绝。
- 正式包资源复跑隔离夹具，真实 WK 回归普通搜索和定位。

## 继承约束检查

- 安全与日志方面，工作区快照、索引文档 ID 和正文留在可信服务内部。
