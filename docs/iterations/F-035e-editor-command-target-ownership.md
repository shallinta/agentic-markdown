## 功能说明

源码选区操作、列表输入、缩进和换行调度只使用当前活动文档的编辑视图。后台或旧视图登记、释放后，不能遮蔽或清除当前文档的目标。

## 最小方案

- 真实普通窗口回归列表续写、源码缩进和换行，切换标签与重读后重复主要路径。所有夹具保留原始字节。
