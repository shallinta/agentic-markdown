## 功能说明

为独立阅读窗从规范 Markdown 解析结果取得可折叠的章节范围。本片先验证范围与实际阅读块一一对应，再接标题箭头、查找自动展开和可见位置测量。

## 最小方案

- 复用当前阅读树的根块顺序与位置。只收录当前可呈现的顶层 ATX 和 Setext 标题；章节结束于后续首个同级或更高层标题，不把引用内标题、围栏文本或原始 HTML 当成章节起点。
- 范围按实际阅读块编号表示，定义、空章节及安全纯文本降级不生成折叠入口。结构保留父子关系和原始位置，不创建第二份正文或修改文档。
- 本片不隐藏正文，也不改变生产搜索、图片或复制交互。标题箭头及查找定位自动展开在下一片一起接入，防止先发布折叠、后修查找。

## 最小验收

- 真实规范解析和独立阅读块对照：跳级、同级标题、标题结尾无内容、定义、代码、HTML、引用、BOM 与 CRLF。核对范围不交叉，降级无范围。
- 用代表性长文验证按根块一次扫描、结果与渲染块编号一致。已有阅读查找、复制和图片不变。
