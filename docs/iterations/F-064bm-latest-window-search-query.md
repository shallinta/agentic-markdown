## 功能说明

用户修改查询并立即提交时，旧查询可能仍在关闭文件。窗口流式搜索只保留最新一次等待中的查询，待旧请求收尾后继续。旧结果和流式预览不会覆盖新请求。

## 最小方案

1. 在窗口的正文搜索 RPC 内复用单个工作区查询槽。仅当当前和新请求都属于窗口流式查询时，接受一个待执行请求。接收时复制查询范围及筛选条件，取消当前查询。
2. 更晚的请求替换等待请求，被替换者返回取消。只在当前查询收尾后启动最新请求。当前状态不确定时保留该回执，等待请求返回不可用。
3. 取消按请求 ID 匹配。暂停窗口或关闭服务时取消执行中和等待中的请求，并等待收尾。既有非流式查询、定位准备、文档保存和窗口界面沿用原行为。
