## 功能说明

独立阅读窗的代码围栏提供「复制代码正文」。复制的是当前已保存快照中的代码内容，保留正文空格和换行，排除 Markdown 围栏与语言标识。

## 最小方案

- 复用已验收的阅读代码组件、剪贴板实现和状态提示。复制已接受的解析节点代码值，与展示正文相同。只有正式阅读窗中通过安全检查的正文允许触发复制。
- 直接在用户手势中调用当前 WebView 的剪贴板 API，窗口关闭后不发布迟到提示。若本地运行环境拒绝写入，保留明确的失败提示和手动选择路径。
- 沿用固定沙盒、页面 CSP 和已保存快照，合成实验不启用复制。主窗现有复制、历史与文件保存不受子窗操作影响。

## 最小验收

- 在正式 WK 打开含缩进和多行代码的测试文件，复制后在另一合成文档中粘贴，核对正文与换行、无围栏和语言标识。用撤销恢复粘贴夹具，核对磁盘内容未变。
- 确认关闭与失败反馈边界，主窗现有复制与合成阅读安全诊断保持可用。未实操的平台拒绝条件以定向测试记录。

## 继承约束检查

- F-002 本机剪贴板操作，最终离线留人工。
- 中文与外观使用已有提示和阅读主题样式。
- 命令与键盘沿用代码块可聚焦按钮及标准激活键。
- 安全与日志沿用用户手势和快照审计，子窗不接 RPC 或其他文件能力。
