## 功能说明

为主区交错打开的目录和独立文档采集会话元数据。按标签原顺序保留活动项、固定状态和模式。整组文件都须能核对实际授权，同一规范路径不能重复进入会话。

## 最小方案

- 先捕获所有标签当前的文档授权和磁盘基线。按实际授权来源复用目录证明或独立文件证明，目录证明会只读核对根名册。
- 用规范路径检查跨来源重复。出现重复、失效或版本不符时拒绝整组，保留现有窗口与会话记录。只生成已核验的 v3 元数据候选，位置和正式写入由后续承接。
- 版本和摘要以 Bun 持有的已保存快照为准。正式写入时仍需核对窗口草稿状态和磁盘发布条件。

## 最小验收

- 用真实合成文件打开目录、独立文件、目录三个标签。核对原顺序、活动项、模式和固定状态，验证不同路径的同名文件各自保留。
- 验证同一文件从独立及目录入口重复打开、核验途中撤销授权及失效版本。普通 WK 回归现有目录恢复及独立打开，与后台实验分别记录。
