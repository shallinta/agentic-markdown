## 功能说明

提供内部空槽准备入口。调用方提交范围键、完整文档名册和有效性检查。一次调用可以在私有空槽建立索引，成功回执只含代数与文档数。工作区接入留到 F-064bh，窗口继续沿用现有搜索。

## 最小方案

1. 首次异步操作前复制并验证完整名册，沿用 limited-v1 的文档数量、UTF-8 字节和文档 ID 约束。在同一槽位租约内确认只有本次租约，检查调用方有效性和磁盘证明。创建 Worker 前再次复核空槽。
2. 创建新写入会话，确认初始代数为 0。非空名册一次提交到第 1 代，空名册保持第 0 代。确认写入会话自然关闭后才只读重开，核对同一代及完整名册，包含无搜索命中的文档。确认只读会话自然关闭。
3. 发布前再次验证磁盘证明，并在持有槽目录的情况下检查原生索引和控制记录布局。排他发布固定 v1 清单，同步槽目录。读回清单，复核索引、调用方有效性和磁盘证明后返回。
4. 调用方失效时拒绝迟到回执。任何会话关闭或清理不确定时，结果为 `UNKNOWN`。会话未确认关闭时保留租约。中途拒绝可能留下尚未登记的索引，发布后失效可能留下清单。后续调用依照原准入复核槽位。

## 最小验收

- 用隔离夹具运行正式包内的写入和只读会话。观察两个会话使用同一租约，核对完整名册及两种代数，检查后续严格只读入口可以使用该清单。
- 验证已有槽、异物、超限、调用方撤销、三处磁盘证明失败与关闭不确定。检查排他发布、迟到回执和租约行为。
- 实际 WK 回归正文搜索与结果定位，确认普通窗口搜索仍不创建原生缓存。离线留最终人工。
