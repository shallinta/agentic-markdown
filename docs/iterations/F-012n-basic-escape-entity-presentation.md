## 功能说明与边界

编辑模式在未触及时将CommonMark反斜杠转义和字符实体呈现为对应纯文本字符，触及源范围（含边界）恢复完整原文。继承包含它们的Link和Setext标题整块触及时恢复原文的规则。源码与安全源码不替换；复制、编辑、保存及撤销历史仍使用原Markdown，不把解码字符写回正文。

只处理现有语法树确认的文本节点。代码、HTML、链接URL/标题、引用链接及定义、图片范围排除；不通过查找字符形状扫描全文。空白、控制或换行等不宜稳定显示的实体保守保留原文，明确这是显示边界，不改CommonMark解析语义。命名及十进制/十六进制实体语义由现有可靠依赖核对，不自行维护映射表或用浏览器innerHTML解码。

用户已授权推进人工验收，一般实现细节不重复请求确认；改变纯文本安全路线、显隐或复制语义等重大边界须暂停重新确认。本片局部承接OBL-068，其他扩展与父F-012/F-042不完成；OBL-012调度、OBL-020缓存余项、OBL-041未来命令由后续切片继续承接。

## 最小技术方案

1. 复用可见语法树、现有装饰和长行/IME保护；只对明确Escape/Entity节点做局部解码，不新增全文扫描、引用索引、强制同步解析或第二套解析器。
2. 命名实体使用`character-entities`完整命名表，作为desktop直接依赖并由执行者核实精确版本，不自行维护表；Lezer可能标记未知名称，必须二次查表，未知原文保留。数值实体严格采用CommonMark：decimal为1–7位、hex为1–6位，分号必需；0、surrogate及大于U+10FFFF变为U+FFFD，不采用HTML C1 legacy映射。来源：[CommonMark 0.31.2](https://spec.commonmark.org/0.31.2/#entity-and-numeric-character-references)、[character-entities](https://github.com/wooorm/character-entities)。解码结果不当HTML或URL执行，仅用widget的textContent呈现，禁止innerHTML、href或外部加载。
3. 未触及的可安全呈现字符才替换；源范围、Link/Setext祖先触及时恢复原文。解码结果包含任一空白（包括space/NBSP）、控制、零宽或双向控制字符即整体保留原文；多码点结果也用相同判断，普通组合字符如NotEqualTilde可呈现。这是保守显示边界，不改解析语义；源码/安全源码与排除上下文保留原文，避免与已有replace装饰重叠。
4. 装饰不改变权威正文或保存链路；鼠标/键盘选择及复制验证原文，BOM和未改动混合行尾保持。解码失败沿用原文，不因呈现而丢字；真实IME和视觉保留人工验证。
