## 功能说明

重新授权目录并恢复主区标签后，在第一次显示该标签时恢复已保存的滚动位置。本轮接入源码坐标和滚动比例，内容块与邻近块留后续切片。

## 最小方案

- 复用完整检查点的授权校验，只将对应标签的有界源码坐标、偏移和比例随已验证的文档快照交给普通窗口。
- 窗口按本次打开实例保存待应用位置。编辑器首次显示时用现有视口测量恢复有效坐标。坐标超出当前原文、落在 CRLF 或代理对中间、或无法测量时，按当前滚动范围恢复比例。
- 关闭、替换或编辑会话失效时丢弃待应用位置。旧记录无位置时沿用普通打开行为。
- 只有当前编辑视图收到滚动输入并测得对应位移，才将恢复标签的新位置纳入检查点。先收到滚动输入时，取消待执行的恢复。自动布局产生的位移只更新当前运行中的视图位置。

## 最小验收

- 使用 alpha.347 实际保存位置的两篇合成文档。重启、重新授权并恢复标签后，首次激活长文即看到原位置附近。
- 用合成检查点将坐标设为越界、比例设为 0.5。重新授权后确认长文档在中段显示。
- 从自动恢复的标签切回原活动项，核对检查点原字节。再主动滚动长文档并切走，确认新位置会写入。两份正文的磁盘摘要保持一致。
- 定向验证旧记录无位置、成组交付、关闭或切换中的过期位置，以及仅位置变化时的交付竞态。
