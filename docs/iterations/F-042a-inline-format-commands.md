## 功能说明与范围

依据能力总账 E-20（快捷键/菜单、统一文本事务）、E-05（选区包裹强调/代码），在普通编辑及源码提供粗体、斜体、行内代码命令。已有 F-012c 呈现、F-006 命令、F-014 历史与 F-044b 多范围满足本片前置，不依赖 F-028c。OBL-057 仅局部承接三项命令，OBL-064 作为历史/IME 消费者协作，主承接仍为 F-014；完整父项和后续格式能力开放。

不新增浮动工具栏、GFM、自动键入补全、完整任意 Markdown 重写或复杂结构控件。菜单仅指现有命令面板的中文命令入口；本片不接原生菜单、不新增 RPC。

快捷键保留现有 ⌘B 侧栏。已发现已装 CM defaultKeymap 的 Mod-i 是 selectParentSyntax，也保留不抢改；本片候选粗体 ⌘⇧B、斜体 ⌘⇧I、行内代码 ⌘E。这是低成本交互取舍，不改旧快捷键；实施前继续核最终冲突，若系统/框架实际占用先报告调整本片新入口。

## 最小合法范围与切换规则

- 包裹：非空单物理行、可可靠识别的普通行内文本范围；强调使用星号标记，保留正文字符，不裁掉原空白来强造有效语法。边缘空白、转义分隔符、相邻 delimiter run 或已有语法边界导致不能保证合法时禁用该范围，不生成“看似包裹但未解析”的文本。行内代码可包裹普通文本及其中反引号，但不包裹已有语法的半个结构、链接目标、HTML 或围栏内容。
- 去格式：选择恰好覆盖一个同类节点的内容或整个节点，或者空光标位于其内容中，删除该节点自己的 delimiter，内容原文不变。部分选择不移除整个祖先格式、不拆分节点；已有其它格式/同类部分覆盖本片不自动整理，禁用并显示中文不可用原因。
- 去格式若会把原段落转换成新的标题、列表或多个块等，当前局部验证拒绝，保留原文不猜结构；本片不是任意 Markdown toggle，完整格式命令父责任保持开放。
- 空光标不在现有同类节点中：在合法位置统一插入带短中文占位“文本”的格式标记，并选中“文本”；不猜词，不生成空强调、水平线或空围栏。已在完整同类节点内容中的空光标按上述去格式规则，不插入占位。合法性仍按三类格式分别验证。
- 跨物理行、跨块、半个已有结构、解析未就绪/保护长行，本片不执行；菜单显示不可用，匹配快捷键不插字符。不得同步强制解析全文。三个命令的合法范围应分别判断，不能把粗体可用当作行内代码可用。
- 空文档、独立空白行即使没有 Paragraph 节点也可插入模板；需确认可靠 Document 空行且不在代码/HTML 或结构前缀中。列表、引用只允许已识别的正文位置，marker/prefix/围栏区域禁用。测试单独覆盖这些入口，不以缺少 Paragraph 一律拒绝。
- 源码多范围逐范围规划：可一处去格式、另一处加格式；任何范围不合法则整个命令不可用，避免默默只格式化部分选择。多个范围要移除同一个节点时合并同一变更并准确映射各范围；无法无歧义合并则整体不执行，不丢光标/主范围。编辑模式保持现有单范围约束。

行内代码 delimiter 选为比选中文本最长连续反引号多一个的 run，且验证不与外部相邻 run 合并。当内容首尾反引号或首尾空格触发 CommonMark code-span trimming 时，按规范加入仅为隔离 delimiter/防裁剪所需的 padding；全部空格文本单独处理。不把反斜杠当代码跨度内反引号转义。去格式只删除实际 delimiter，内部空白原样保留；不凭未持久的来源信息猜哪些 padding 是 App 插入的，也不采用规范解码去改变原正文。故先包代码再去格式可能保留新增 padding，这是原文保真优先的明确局限；要精确回原请 undo。输出须用公开解析结构及内容对照验证，不能只断字符串包含反引号。

## 技术方案

本机 `@codemirror/lang-markdown/dist/index.d.ts` 未提供粗体/斜体/代码 toggle 命令，公开导出以续写、删除 markup、语言及 pasteURL 为主。采用小型纯规划模块，复用当前 CommonMark 公开 syntaxTree/SyntaxNode、原文映射和 `EditorState.changeByRange`/ChangeSet；不新增引擎/依赖、私有字段、每范围完整 State 或第二正文模型。

语义准入需可靠覆盖本次相关行内节点及分隔边界。优先已有公开树，不以整篇重新 parse 作为每次命令前置。局部 delimiter 检查必须考虑上下文；若不能用小型范围分析保证，先对真实生产 state 做隔离公开 API 验证，报告限制，不扩大成 Markdown 重写器。最终仅一个 `state.update`，精确保存范围方向/mainIndex，进入原 rawText/history/dispatcher；BOM、CRLF/LF、emoji、未操作区域字节不变。

实施前独立核对补充：新增标记要使用同一公开 CommonMark parser 对完整相关顶层块做局部候选验证，包含必要 list/quote 祖先，不能只截光标行或 paragraph 前缀。同块多范围聚合一次，全部相关块与插入内容总量以现有 LONG_LINE_UNITS 作为临时同步计算保护，超量不可用；这不是文件限制或性能验收门槛。部分树/边界不可靠拒绝，不 ensure 全篇，不新依赖或私有字段。计划按 immutable state、当前树身份和格式种类缓存，面板渲染不重复解析；真实解析节点须精确对应包装边界。

快捷键走 CM 公开 keymap/domEventHandlers 与 view 生命周期注册，继承 F-043c：不新增 capture 抢在 CM 输入法保护之前，不读私有 pending、不自造时间阈值。统一 registry 登记严格 command 参数，执行时重验活动 documentId、current view、实时权限/只读、冻结/busy/inputBlocked、普通模式及 IME。候选事件不认领；普通被拒绝快捷键消费但不写入。safe/reading 不挂格式行为。

命令面板会转移 DOM 焦点，不能机械要求编辑器 hasFocus 而令菜单永不可用：仅从当前 editor 打开面板才捕获有效 documentId/view/selection/state 目标；来自树、设置或其它输入框不捕获、命令禁用。沿现有 historyTarget 和 onCloseAutoFocus 后 queueMicrotask 模式，执行时重新判目标仍活动、state/selection未变、权限/模式/IME仍有效；状态变动则拒绝，不使用开启时的旧事务。

本片只交付局部快捷键+现有命令面板闭环；原生菜单消费者留后续，不新增 RPC，不能把 stale enabled 当授权。面板执行时 revision 或 selection 变化即拒绝，不把命令套到新的选择；只有成功才恢复目标编辑器焦点。不得把任意失焦情况下的当前文档默认当写入目标。

原面板关闭时的 previousFocus 恢复继续保持；这里“成功才恢复”指格式命令新增的主动聚焦，不禁止既有关闭恢复。若恢复焦点自身产生 state 变化，严格目标检查拒绝本次格式化，不放宽成只核 documentId。
