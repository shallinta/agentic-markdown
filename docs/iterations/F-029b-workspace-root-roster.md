# F-029b 上次窗口根集合记录与待授权占位

> 状态：alpha.283 正式窗口和包内测试非离线范围代验通过。

## 功能说明

按 M-14 和 W-04 记录上次窗口的目录根。重启后显示待重新授权的条目，用户可重新选择或移除。通过系统选择器重新授权后，目录才进入当前工作区。

## 最小方案

- 使用版本化、限量的独立元数据文件。只记录可信根路径、展示名和记录 ID。启动读取元数据，待授权行与已授权根分开，启动时不探测或扫描历史路径。
- 系统选择器返回后由后端确认规范路径及当前授权状态。同路径成功选择可消除对应待授权行，包括已经被当前父根覆盖的选择。其他待授权子目录继续保留，用户可重新选择或移除。取消与失败保留原行。
- 在添加、父根吸收、目录移除、目录移入废纸篓和用户显式清空成功后保存完整名册。保留尚未重新授权的条目。加载、修改和保存串行执行。普通退出排空已受理的写入并拦住迟到选择，服务销毁不写空名册。
- 损坏、未知版本或超限时保护原文件并提示。保存失败保留已经成功打开的工作区。完整树展开、平台持久授权和会话恢复由后续承接。

## 最小验收

- 在隔离 WK 窗口加入两个目录，正常退出并重启。确认先显示两条待授权记录，逐条重选后进入文件树。取消、移除、父根覆盖及再次退出重启均核对名册。
- 用独立夹具核对选择成功与退出竞态、保留其他待授权项、未来版本、名册超限、显式清空和写入故障。核对启动阶段没有历史目录读取，实际窗口和受控故障证据分别记录。
