# F-034c 副区文档离开后的高度转移

> 状态：alpha.302 隔离实验代验通过，正式接入仍开放。

<!-- obligations: none -->
<!-- deferred-obligations: OBL-051 -->

## 功能说明

关闭副区中的一篇文档时，离开项的全部高度交给紧邻的下方文档。末项离开时交给紧邻上方文档。其他文档的身份、顺序和高度保持，最后一篇离开后实验副区收起。

## 最小方案

- 纯函数返回删除后高度，保留原输入。实验台给合成文档稳定编号，关闭与新增同时更新身份与高度。
- 使用实验台现有的收起与展开。关闭最后一篇时把焦点交给该控件，再展开保持空。普通窗口不接真实关闭和拖放。

## 最小验收

- 用 33/46/55 预设分别关闭首、中、末项，验证接收者、高度与其余文档不变。关闭后新增使用新编号。
- 正式 WK 验证只剩一篇占满原空间，关闭最后一篇后收起、焦点回到展开按钮，展开仍空。
