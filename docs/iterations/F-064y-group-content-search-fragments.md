# F-064y 按文件展示正文命中片段

## 范围

正文搜索按文件展示命中。每组保留文件名、目录或独立文件来源。每个片段显示命中前后的文字，点击可定位到对应位置。当前有界实现每篇展示前三处，更多命中用提示标明。仍按区分大小写的字面量搜索，保留已有文件和正文预算。

## 最小实现

1. 普通窗口请求有界片段。后台在通过授权和正文版本核对的原始字符串中，按 UTF-16 返回按顺序排列的非重叠区间，以及每侧最多 32 个代码单元的纯文本。上下文边界保持完整的 Unicode 代理对。旧单命中请求保持兼容。
2. 打开的未保存文档使用相同匹配规则，替换该文档的全部磁盘命中和上下文。没有匹配时清空原命中。沿用现有文件范围、文档基线、缓冲区和结果失效核对。
3. 面板按文件分组，每处命中有独立的键盘可达按钮。上下文按纯文本显示，命中突出显示。点击沿用现有打开、原授权重开和位置校验；定位时保持对应结果按钮焦点。

## 最小验收

- 在一篇含 BOM、CRLF、中文和 emoji 的文档查询四处匹配，核对前三处的上下文、额外命中提示和第二处定位。另有同名文件时按来源分组。
- 验证未保存内容的全部替换、无命中时移除旧磁盘结果、撤销后结果失效。原夹具摘要不变。
- 包内复跑新旧响应形状、文本边界、版本、定位和撤销用例。真实 WK 验收分组及退出。

## 继承约束检查

- F-002 沿用本地授权。离线留最终人工。
- 中文与外观沿用结果面板及现有主题。
- 命令与键盘保持查询、结果和定位可达。
- 安全与日志方面，上下文按纯文本渲染，正文与片段不新增日志。

## 验收结果

- macOS arm64 unsigned canary `0.1.0-alpha.211`，包标识 `t8yvunwqe828`。包内 Bun 1.4.0 和正式原生资源复跑范围、查询、定位、协议与合并，58 项通过、8 项条件跳过、416 条断言。实际混合子场景另复跑 45 条断言。独立规格复核及 Unicode 边界对照无阻断。
