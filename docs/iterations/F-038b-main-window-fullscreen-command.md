## 功能说明

在主窗的命令面板执行「切换全屏」。窗口菜单和 ⌘⇧F 沿用 macOS 原生切换，继续作用于当前系统窗口。

## 最小方案

注册一个无参数的主窗命令，通过现有 Bun 命令入口调用主窗的全屏接口。命令面板收起并恢复焦点后再发出命令。窗口菜单保留原生角色，阅读窗沿用系统行为。此切片承接 OBL-055 的主窗命令面板部分。

## 最小验收

- 在普通 WK 从主窗命令面板进入全屏，再用系统快捷键退出。反向用窗口菜单进入，由命令面板退出。
- 空主窗的命令可用。打开文档后核对模式、草稿和选区保持。阅读窗在前台时核对系统快捷键的既有目标。
