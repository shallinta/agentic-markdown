## 功能说明

让后台能将当前仍有授权的已保存混合标签写入正式检查点。为混合检查点保留独立文件名，旧目录记录和实验记录各自保留。普通窗口的保存触发和恢复入口留后续切片接入。

## 最小方案

- 在 App 数据目录使用 `main-tab-session-mixed-checkpoint.json`。沿用已验的 v3 格式、原字节核对、备份及容量限制，隔离实验文件名继续保留。
- 受控写入直接绑定当前文档、目录名册和独立文件授权。失效、取消、绑定失败或空输入时拒绝写入。一次写入只使用本次绑定的标签和活动项。显式清空留后续归属核对。
- 读候选沿用混合优先、缺失回退；读取目录记录不自动创建混合记录。

## 最小验收

- 用合成文件绑定目录和独立标签，写入后以另一进程读回顺序、模式与活动项。复核旧目录记录、实验记录及正文原字节。
- 验证授权或调用失效、未来格式保留，以及合法更新后的备份。真实 WK 回归原生重新授权、目录标签恢复和正常退出。

## 继承约束检查

- F-002 使用本地合成夹具，最终离线留集中验收。
- 中文与外观沿用普通窗口。

- 安全与日志使用当前授权及隔离夹具，不打印用户文档正文或路径。
