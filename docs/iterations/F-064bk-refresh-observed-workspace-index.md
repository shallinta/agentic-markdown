## 功能说明

可信工作区服务可显式更新同一授权根目录的索引，也可在原生恰好领先一代时显式补齐清单。调用方分别指定目录扫描代数与索引预期代数。两个入口都使用当前磁盘名册，普通窗口搜索沿用现有路径。

## 最小方案

1. 复用已观察单根目录的授权证明和同一个后台任务槽。捕获完整磁盘名册，在提交、核验、发布和返回各阶段复核文件及观察状态。
2. 更新和补齐分别调用 F-064bi 与 F-064bj。两个动作各自执行，失败后由调用方显式选择后续操作。保留原生状态不确定的回执优先级。
3. 结果只含索引代数、文档数和适用的变更数。既有空槽准备入口沿用原调用方式。工作区服务之外不新增调用路径。

## 最小验收
