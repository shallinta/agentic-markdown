# F-037ak 验证旧版与混合会话检查点共存

> 状态：alpha.361 的隔离验证、两版普通窗口回归和独立代码复核通过。

## 功能说明

验证旧版本更新目录检查点后，含独立文件的新会话仍能完整读回。新旧记录使用不同文件名。新会话记录缺失时可读取旧目录记录。

## 最小方案

- 在隔离目录复用两个检查点存储。候选读取优先检查混合记录，只有缺失才读旧目录记录。读完旧记录后再查一次混合记录，处理读取途中首次写入新记录的情况。
- 混合记录损坏、来自较新格式或不可读时保留错误。已有的空混合会话也具有优先级。正式恢复需要在交付前继续核对检查点和授权。

## 最小验收

- 用已打包的旧版普通窗口更新旧目录记录，核对混合记录及其备份原字节。用新代码读回混合会话，并验证仅混合文件缺失时使用旧记录。
- 自动验证空记录、较新格式、损坏和旧记录读取期间首次出现混合记录。普通新版窗口回归目录恢复和正常退出。
