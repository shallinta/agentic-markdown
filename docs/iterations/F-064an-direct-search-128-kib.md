# F-064an 直接正文搜索总量提高到 128 KiB

## 范围

普通窗口的直接搜索，将当次正文合计上限由 64 KiB 提高到 128 KiB。单文件、定位快照和原生索引总量仍为 64 KiB。覆盖、根和打开绑定沿用 alpha.224。

## 最小实现

1. 只调整直接查询正文合计限额。稳定读取仍按单文件上限与剩余总量的较小值执行。当前界面提示使用同一总量配置。
2. 文件夹与独立文件共用总量，当前未保存覆盖按有效正文计算。单文件超过 64 KiB 或总量超过 128 KiB 均整次拒绝，丢弃暂定结果。
3. 传输仍交付命中与已核对摘要，定位快照保持原有单文件边界。保留原生限额及错误。

## 最小验收

- 两篇各 64 KiB 时直接查询成功并定位第二篇。增加一个 1 字节文件后整次拒绝。单篇 65,537 字节同样拒绝。
- 复跑共享协议、混合范围、未保存覆盖和原生字节上限。用实际包资源核对旧原生路径在合计超过 64 KiB 时拒绝。
- 真实 WK 检查容量提示、边界查询、定位和超限无旧结果。记录观察到的耗时，无新增性能门槛。

## 继承约束检查

- F-002 沿用当前本地授权，离线留最终人工。
- 中文与外观更新搜索总量提示。
- 命令与键盘沿用现有搜索入口。
- 安全与日志方面，预算扩展不改变授权或新增正文日志。
