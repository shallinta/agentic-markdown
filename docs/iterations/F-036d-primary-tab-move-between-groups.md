# F-036d 主区标签跨组拖放

> 状态：alpha.286 通过实体鼠标和独立代码复核。

<!-- obligations: none -->
<!-- deferred-obligations: OBL-053 -->

## 功能说明

按 M-04，把主区常驻标签拖入另一组时，同时调整位置和固定状态。移到固定组会固定，移到普通组会取消固定。

## 最小方案

- 沿用 F-036c 的标签左右半区和插入线。目标组为空时，只在有效拖动期间显示一个放置位置，固定组在左，普通组在右。
- 在一次提交中更新固定状态和视觉顺序，保留活动标签、选区、草稿和最近使用顺序。取消或过期的拖动不提交。
- 键盘沿用「固定当前标签」「取消固定当前标签」与组内左右移动。会话恢复、预览和副区分别承接。

## 最小验收

- 正式 WK 验证跨组两个方向、目标组为空、迁出组的最后一项、拖动取消和键盘等价操作。核对活动标签、草稿、组内顺序和关闭后的邻位。
- 定向验证只发布一次最终状态、目标失效时拒绝，以及最近使用顺序和后续打开保持原有规则。

## 继承约束检查

- F-002 沿用窗口内状态，离线留最终人工。
- 中文与外观沿用标签插入线，空组放置位置有明确名称。
- 命令与键盘复用固定及排序命令。
- 安全与日志只处理本窗口的文档 ID，不读写正文或磁盘。

## 实现记录（2026-11-10）

跨组拖到目标标签前后时，按目标组一次更新固定状态及顺序。目标组为空时，拖动期间在标签条对应边缘显示「固定到此处」或「移到普通标签」。拖动失效、取消或结束后收起放置位置。命令面板沿用固定、取消固定及组内左右移。

## alpha.286 修正与复验

- 第三步是原序列中唯一会在 `drop` 处理中移动拖动源 DOM 节点的步骤。修正先记录放置意图，等待 `dragend` 后再异步提交。若平台没有发出该事件，已接受的放置有定时收尾。过期状态、取消以及焦点变化分别受原有约束与复核保护。
