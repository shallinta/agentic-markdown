# F-064u 独立文件命中定位准备

## 范围

给独立文件命中增加 Bun 内部的定位准备。顶层文件还打开着时，核对查询所用版本后复用原编辑器。标签已关闭时，通过原授权读取与命中一致的正文，返回可以重开标签的快照。普通窗口接入与视图定位由后续切片完成。

## 最小实现

1. 输入只携带目录根列表、独立文件句柄、命中所用磁盘摘要，以及可选的原打开文档版本。核对完整目录根列表、授权和当前文件身份。文件已经出现在可见的父目录时，独立文件命中失效。
2. 已打开文档的准备复用句柄及原磁盘版本，只读校验命中摘要，保留现有缓冲区、撤销历史和文档基线。
3. 标签关闭时使用原句柄读取，最多 64 KiB。建立快照前后核对原授权、当前稳定字节及摘要。确认当前意图有效后再更新版本和编辑镜像。提交前遇到取消、替换、撤权、废纸篓隔离或摘要失配时，拒绝更新基线。本操作不会额外释放原授权。提交后的迟到取消可阻止结果交付，已确认的同句柄基线不回滚。
4. 为保留快照使用单独的结果类型，供后续窗口区分原句柄与为目录搜索临时获取的新授权。

## 最小验收

- 已关闭标签能用原句柄准备正确版本。外部原地改写后，只有摘要匹配才更新基线。已打开标签按精确版本复用。
- 覆盖摘要失配、替换、取消、隔离和可见父目录吸收。确认拒绝时仍能通过原有效授权继续操作。
- 包内复跑准备与现有查询用例，真实 WK 窗口回归现有定位。

## 继承约束检查
