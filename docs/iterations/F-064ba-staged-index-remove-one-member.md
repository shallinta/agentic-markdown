# F-064ba 显式清理单个待回收索引成员

## 范围

提供内部显式清理操作，每次最多删除一个已核实的索引文件。开发验收只操作新建的隔离夹具。保留待回收目录、v3 清单和历史名册。

## 最小实现

1. 请求携带范围键、代数、v2 摘要及历史名册序号。序号从 0 起，段文件在前、固定控制文件在后，各组按名册顺序。取得合法租约后重做完整名册和现存子集核对。要删除的成员须为当前顺序中的第一个现存文件。
2. 同一序号已缺失时只复核和同步该位置，不删除下一项。实际删除前持有私有槽、待回收目录和选定文件的描述符，核对原清单、名册、文件身份和调用方。原生入口只接受已知的直接文件名，在同一描述符下调用 `unlinkat`。
3. 删除后确认原名消失及持有文件的链接数归零，同步待回收目录，并复核两份记录、租约、稳定目录身份及现存子集恰好少一个成员。回执只返回该序号是否原已缺失与剩余数量。结果无法确认时返回 `UNKNOWN`，保留现场供同序号重试。
4. 租约隔离协作调用。macOS 的 `unlinkat` 无法原子地按 inode 条件删除，前后核对可缩小竞争窗口。没有自动删除、清空目录、移除控制记录、跨重启遗留租约恢复或释放物理空间保证。

## 最小验收

- 正式原生夹具按序清理一个文件，验证原 inode 名称消失、其余文件和两份记录未变。同序号重复调用无副作用，新进程可核对并清理下一序号。
- 覆盖顺序不符、异常身份或链接、晚到租约、取消和实际删除后目录同步失败。失败后同序号复核不会删除其他文件。
- 包内定向复跑，实际 WK 回归普通搜索和定位。

## 继承约束检查

- F-002 沿用私有 App 数据边界，离线留最终人工。
- 中文与外观沿用普通搜索界面。
- 命令与键盘没有新增窗口入口。
- 安全与日志方面，调用不接收路径和文件名，回执只含计数。

## 验收结果

- macOS arm64 unsigned canary `0.1.0-alpha.238`，包标识 `mxj0uepc8svb`。包内 Bun 1.4.0 定向复跑 5 项通过、20 项条件跳过、24 条断言。隔离单文件清理另有 87 条断言通过。
- 正式原生夹具验证一个序号只删除一个成员，持有的原文件链接数归零，其他文件及两份记录保持原样。新进程重复原序号后可以显式继续下一序号。原生入口另行复跑路径穿越、未知名称、符号链接、硬链接四项拒绝用例。
- 顺序不符、身份失配、租约与取消按边界处理。实际删除后同步失败和已缺失序号复核同步失败都返回 `UNKNOWN`。随后用同一序号确认，未移除下一项。
- 真实 WK 回归普通搜索一篇两处命中、定位第二处 `[19, 23)` 和 ⌘Q 正常退出。夹具 SHA 不变，启动器退出 0，未创建索引槽，临时目录为空。
- 源码定向复跑含已有文件夹创建，22 项通过、19 项条件跳过、155 条断言。源码全量 1914 项通过、39 项条件跳过、1 项失败，39485 条断言。唯一失败仍是已登记的 FINAL-ISSUE-002 长空白超时。类型、Lint、文档、锁文件和差异检查通过。

下一片持久确认待回收目录已空，保留清单、名册和目录以支持后续收尾。正式验收仅使用隔离夹具，尚未接通自动清理。
