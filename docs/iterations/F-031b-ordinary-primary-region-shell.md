# F-031b 普通窗口接入主区布局

> 状态：alpha.324 普通主区已由 Agent 代验；正式副区入口仍开放。

<!-- obligations: none -->
<!-- deferred-obligations: OBL-048 -->

## 功能说明

普通窗口的文档区域接入已经验证过的主副布局容器。副区保持收起，只呈现填满文档区域的主区，供后续接入文档分配。文件树仍独立在左侧。

## 最小方案

在现有文件树与文档的外层分栏中，仅把文档面板放入 `MainSideLayout` 的主区，给主区稳定的无障碍名称。沿用同一个文档控制器、文档面板、侧栏宽度设置和原生拖动区；收起时没有副区节点或第二道分隔线。保持已有布局尺寸与窄窗口行为。不增加展开入口、文档移区、持久化或预览。

## 最小验收

- 普通 WK 打开两篇临时文档，确认主区只有一份，切换标签及模式，保留未保存内容。
- 侧栏收起与重新展开、键盘调整和宽度恢复正常，普通窗口不出现副区控件。
- 测试草稿时取消退出后仍在，撤销回原文后正常退出；夹具不变。用同包隔离窗口回归已展开时两区与分隔线仍在。

## 继承约束检查

- F-002：沿用本地打开和保存约束；最终离线留人工。
- 中文与外观：无障碍名称使用中文，保留已有文档和侧栏样式。
- 命令与键盘：不新增入口；继续验已有侧栏和文档焦点。
- 安全与日志：不改变授权、读写或日志。
