## 1. 功能说明

### 1.1 目标

在当前仓库完整引入 electrobun-app-starter，使 Agentic Markdown 能在当前 macOS 环境启动并显示可交互外壳。外壳尚未打开 Markdown 文档；允许保留 starter 占位界面，不在本轮设计正式欢迎页或编辑器。

### 1.2 本轮范围

- 保留 starter 现有代码、资源和附带能力；将包名、应用名称、bundle ID（应用唯一标识）、本地数据目录、应用自有环境变量前缀及浏览器持久化键隔离为 Agentic Markdown。
- 保留本仓库 Git 历史、远端、产品规格、领域术语与 Agent 工作规则；上游许可证和必要归属声明保留。
- 精确记录 starter 来源提交，锁定 Electrobun 版本及依赖，使用 macOS 系统 WebView（网页视图）启动。
- 开发模式可启动；本地未签名构建可在开发服务器停止、网络不可用时启动并操作外壳。
- starter 附带能力只记录为“继承草稿”，不作为本轮产品功能测试、验收或承诺。基础构建检查通过也不改变其状态。
- 性能只记录本轮真实可获得的启动观察、环境与包体积，不预设数值门禁，不宣称性能领先。

### 1.3 不在本轮范围

- Markdown 打开、编辑、保存、文件树、主副区域、正式欢迎页及后续功能的产品化。
- 附带功能专项测试、跨平台适配、签名、公证、发布或自动更新验收。
- 不运行发布脚本、创建 tag 或发布产物；不接入 starter 原本未接入的能力。

### 人工验收反馈：窗口连续拖动

2026-09-16：用户报告红黄绿按钮右侧及正文顶部空白区域均在每次获得焦点后只能拖动一次，本轮验收未通过。

- 代码核对发现 `hiddenInset` 窗口未声明 DOM 拖动区域。Electrobun `1.18.1` 的 preload 只对官方 drag 类或 inline app-region 标记发送原生 start/stopWindowMove；隐藏标题栏本身不替代该声明。
- 候选修复：外壳顶部加入 48px 非交互 header，使用 `electrobun-webkit-app-region-drag`。正文、更新按钮和分隔线均保留在拖区之外；不修改框架版本、焦点逻辑或窗口状态持久化。
- 单文件格式、类型与 lint 检查通过。自动化拖动未建立“首次成功、随后失败”的稳定复现，随后遇到 `noWindowsAvailable`；因此缺失拖区只是已确认的配置问题，尚不能声称已证明原症状的根因或修复效果。
- 回归步骤：启动新构建，在红黄绿按钮右侧的顶部条连续拖动至少 3 次，中途不要切换其他窗口；再切出并切回，重复连续拖动。确认正文仍可正常交互。结果待用户复测记录。
- 候选修复已通过 `AGENTIC_MARKDOWN_SKIP_SIGNING=1 bun run build:canary` 重新打包，并确认新窗口加载本地页面、顶部空条已出现；独立审核确认拖区使用方式与 DOM 边界正确。新 DMG 为 23,627,217 字节，覆盖原路径产物。自动化仍未得到窗口位移证据，连续拖动结论等待人工复测。
