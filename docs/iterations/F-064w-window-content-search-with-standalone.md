## 范围

正文搜索提供「选中的文件夹」与「当前窗口」。当前窗口覆盖已加入的目录和文件树顶层的独立 Markdown 文件。只有独立文件时，可直接查询当前窗口。显式 `root:` 仍优先限定指定目录。

目录加入后，可见的同一路径文件只作为目录结果出现一次。仍在顶层的隐藏独立文件可查询。同名结果显示来源。保留每篇首个字面量命中、最多 16 个根、筛选前合计 16 篇及正文 64 KiB 的限制。

## 最小实现

1. 复用工作区扫描和文件树投影，捕获有序目录根、可见顶层独立文件及已打开文档。文件名和路径筛选对独立文件按文件名匹配。返回前比对完整范围、候选覆盖和打开版本。
2. 当前窗口使用混合查询，选中目录或 `root:` 使用原查询。保留已打开文档未保存覆盖及版本不确定时的拒绝规则。
3. 独立结果按原授权准备。已打开标签按捕获版本激活；已关闭标签确认同一树节点和位置后重开。取消、版本改变或目标切换时废弃定位意图。目录结果继续走原路径。文件被父目录吸收且标签关闭时，按扫描条目的身份核对后重用原授权。保持结果焦点和一次性选择、滚动。

## 最小验收

- 只打开独立文件并关闭标签，查询后重开并定位，验证 BOM、CRLF 和 emoji 前的偏移。
- 加入两个同名目录，验证当前窗口混合结果、同名来源、`root:` 优先及加入父目录后的去重与定位。
- 验证独立文件的未保存覆盖和原标签复用，查询或定位过期时没有覆盖、撤销或释放原授权。对照磁盘摘要和正常退出。
