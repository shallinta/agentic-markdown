# F-037af 独立文件重新授权的会话来源

> 状态：alpha.356 的隔离实验、普通窗口回归和独立代码复核通过。

<!-- deferred-obligations: OBL-034, OBL-054 -->

## 功能说明

验证单独打开的 Markdown 文档在下次启动后，经系统选择器重新授权，能与原会话中的文件匹配。同名文件和原路径上替换的新文件都不能继承原文档的状态。

## 最小方案

- 从 Bun 当前持有的独立文件授权取得规范路径和平台文件身份信号。句柄、文档 ID、版本与摘要都须和本次打开的回执相符。跨进程比较只使用路径和文件身份信号，进程内 ID 不作跨重启依据。
- 先与已有授权匹配，再复核文件描述符与授权是否仍有效。历史路径只参与比较，正文由用户本次明确打开的正常链路提供。物理文件核验持续到描述符检查完成，交付前同步确认本进程授权仍有效。实验仅在后台及临时夹具运行，会话格式和普通窗口恢复入口留到后续。
- 来源回执的 `current()` 检查本进程的授权状态。后续接入标签恢复时，在实际交付前复核磁盘身份和检查点，防止核验后文件被替换。

## 最小验收

- 两个隔离进程分别选择同一合成独立 Markdown，确认新授权可匹配旧来源，当前正文按正常打开读取。
- 对照同名异路径、原位替换、目录派生授权及失效请求。真实 WK 回归打开独立文件、退出并重选，分别记录实际窗口与后台身份匹配证据。

## 继承约束检查

- 中文与外观沿用普通窗口的独立文件入口。

- 安全与日志只复核本次明确授权的文件，隔离回执不输出路径或正文。

## 验收记录

- 包内 Bun 1.4.0 运行工作区实验源码。四个独立子进程分别捕获来源、重选原文件、选择另一目录的同名文件及选择原位替换文件。选回原文件时匹配历史路径与文件身份信号，进程生成的文档 ID 不同。原地更新后的 BOM、CRLF、中文和 emoji 正文摘要与本次读取一致。两种身份失配均拒绝。原来源记录逐字节保留，关闭授权后回执失效。
- 定向验证目录派生、版本或摘要不符、描述符核验后晚到的取消，以及尚未匹配历史时没有核验文件。独立复核实测一次正常正文读取加一次来源描述符复核。未新增正文读取。独立定向复跑 7 个文件、53 项通过、0 失败、429 条断言。
- 普通 alpha.356 WK 由系统选择器打开合成 `same.md`，显示独立标签及磁盘正文。正常退出再启动，欢迎页保有最近项。取消重新选择后窗口仍无标签，最近记录原字节一致。再选原文件时只打开该文档，最近项仍为同一个 ID，更新时间前进。两次启动器退出码均为 0，两个合成 Markdown 文件的 SHA-256 与测试前相同。本片未生成主区会话检查点。

- 包内 Bun 全量 2407 项通过、55 项跳过、0 失败，共 47736 条断言，325 个文件。类型、Lint、文档、义务、锁文件及差异检查通过。
