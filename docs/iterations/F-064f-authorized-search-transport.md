## 本片交付

把 F-064e 单目录根的一次性字面量查询接到独立类型化 RPC。先通过隔离验收入口从渲染层走真实 IPC，验证中文命中和取消。请求携带协议版本、请求 ID、当前扫描代数、根句柄与有界非空查询。返回同一请求 ID、稳定状态码以及通过校验的条目句柄和 UTF-16 范围。双方校验请求和响应；路径、正文、索引 ID、临时缓存位置留在可信侧。结果模型保留覆盖范围和状态，超限和授权失效须显式区分于零命中。

保持单根完整扫描、16 文档及 65,536 字节正文等 F-064e 准入限制。调用和取消绑定当前窗口的工作区实例。渲染层只呈现当前请求及当前根代的数据。输入变化、关闭验收入口或切换工作区立即废弃旧结果。服务端以一个在途任务为限，并在读取、提交、查询及交付边界检查取消与根授权。原生写入已接受时仍按 F-064e 收尾，不抢断、不重放。

## 内存版本前置

Bun `documents/index.ts` 的 identity revision/hash 描述磁盘基线。buffer mirror 在打开和保存时更新，不能证明编辑器的当前未保存状态。渲染层 `client/documents.ts` 持有编辑缓冲区版本及 `getSaveStatus`。因此不得把 renderer 传入的 clean 标记或 Bun 已知镜像版本当作权威依据。

本片采用隔离夹具。单次检查 `locations()` 只能得到当前授权快照，无法证明整次操作期间的编辑器状态。正式查询需要另行实现并验证可信状态屏障，同时避免阻塞前台编辑。

## 验证

1. 使用自建小目录走真实扫描和 RPC，中文和 emoji 命中返回正确 UTF-16 区间。空结果、超限、扫描未完成及根代过期分别返回可区分状态。
2. 拒绝伪造根句柄、过长输入、错误协议版本、非本实例在途请求的取消和畸形响应。响应内容与请求及选中根匹配，日志仅记录无敏感内容的状态。
3. 查询等待期间改输入或关闭入口，晚到的成功结果不可见。正式工作区的打开、编辑和关闭交错由可信状态屏障切片承接。
4. 新包在隔离数据目录通过内部验收入口执行，记录正常退出及缓存回收。实现和包验通过后再决定正式入口切片。

正式工作区全文搜索仍需多根和独立文件、未保存内容覆盖、流式分组及可取消查询、筛选和持久增量索引。结果打开依赖 F-032，并需重新校验位置所对应的内容版本。若先交付可用的有限 UI，界面须明确标注「在此文件夹中搜索正文」、适用范围和超限状态。Quick Open 继续负责文件名与路径匹配。

## 实现与源码验证

只有 Bun 启动环境中 `AGENTIC_MARKDOWN_SEARCH_LAB=1` 才实例化实验服务。服务使用自己的文档及工作区实例，目录选择器只返回由 Bun 创建的私有固定语料目录。RPC 准备响应只传根句柄及扫描代，查询只传扫描条目句柄及 UTF-16 区间。默认 RPC 回应 `DISABLED`。

服务同一时刻只接受一个准备或查询任务。取消只针对本实例的在途请求，工作区通过 AbortSignal 将取消纳入原快照时效校验。关闭、重载和更新等待合成夹具收尾。目录回收失败时仍保留该夹具的所有权并拒绝继续查询。仅在文档和工作区都已完成关闭时才允许重试目录回收。原生 `UNKNOWN` 沿 F-064e 隔离槽策略处理。

定向运行包含实验服务、RPC 和工作区原生快照 3 文件，10 项通过、4 项外层条件跳过、0 失败。4 项内层用例均在各自子进程运行通过。检查覆盖真实扫描及中文区间、空结果、伪造根和过期代拒绝、在途取消及关闭、默认 RPC 禁用和目录回收失败后重试。目录回收故障在测试自建临时目录上注入并恢复权限。
