# F-048e 独立阅读窗代码折叠

> 状态：alpha.298 受托代验通过。

<!-- deferred-obligations: none -->

## 功能说明

独立阅读窗的顶层代码围栏可收起和展开。收起时保留语言、行数和复制入口，隐藏代码正文。折叠只影响当前窗口，不修改 Markdown。

## 最小方案

- 在现有受审计的代码块上增加原生按钮，按鼠标或键盘切换。只启用普通快照中的顶层围栏；引用、列表内的围栏继续按原样显示。
- 保留原代码 DOM 与复制行为。折叠代码不计入视口高亮额度，仍计入全文查找。用户跳到命中时，同一次更新展开目标代码及必要的标题祖先。主题位置测量仍把代码块的可见标题视为锚点。
- 复用已有可见区间、过期回执和受控 DOM 规则，不重建查找 Worker，不新增窗口权限。

## 最小验收

- 真实窗口验证按钮、语言和行数、代码复制、折叠后的全文计数及导航展开。核对同级标题、主题和文档原字节。
- 定向验证同一章节中的可见正文不受影响、代码块隐藏的密集命中不占高亮额度、旧回执不重画，以及伪造控件被审计拒绝。

## 继承约束检查

- F-002 沿用本地边界，最终离线留人工。
- 中文与外观沿用独立阅读主题和代码块控件。
- 命令与键盘沿用原生按钮与查找导航。
- 安全与日志只用合成夹具。引用和列表内围栏、跨窗状态及换行专项保持开放。
