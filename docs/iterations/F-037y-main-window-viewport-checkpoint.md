## 功能说明

普通主窗口切换或调整已保存的目录标签时，在会话检查点记录已测得的源码位置、视口偏移和滚动比例。本轮先接入视口采集和受控写入。

## 最小方案

- 使用现有编辑器视口采集，按当前标签、编辑会话和缓冲区版本核对。复用已有标签检查点的空闲调度和授权复核，在版本 2 标签行写入有界的位置数据。
- 兼容旧记录。检查点保留正常的标签顺序和固定、活动状态。已认领的位置只归属于本次打开的标签实例。剩余标签都满足保存条件时，关闭标签会从下一次检查点移除对应行。仍有未保存标签时的独立清理留后续切片。
- 首次恢复后保留尚未实测的历史位置。同一实例滚动后回到顶部可记录零位置。显式关闭后快速重开复用句柄时，新实例从空位置开始。遇到外部修改则以原始检查点字节核对写入依据。
- 内容块摘要、仅滚动时的持久化和重启后的视口应用留后续验证。

## 最小验收

- 在普通窗口打开两篇目录文档，将第一篇滚到后段并切换到第二篇。核对检查点的原顺序、活动项及第一篇的源码位置与比例，并验证正常退出。
- 验证未保存状态、错误版本或失效授权不得写入。对照旧无位置记录和关闭标签后的记录归属。
