## 范围

将已移动到待回收位置且可核实的索引继续计入同一缓存的逻辑占用。沿用内部占用统计入口和只读约束。

## 最小实现

1. 只有私有槽内出现固定的 `.reclaim-pending` 时才进入新分支。在无租约的快照中核对唯一位置、v3 准备清单、全量稳定摘要和已知原生控制名册。只打开固定控制文件，文件身份和字节数使用元数据。
2. 输出与原统计同样的文件数、清单字节、索引字节和合计，待回收结果另标记 `placement: "pending"`。统计表示文件仍在该槽内。原名布局和空槽回执保留原样。
3. 交付前复核调用方、目录、清单、文件及租约。两名并存、未知文件、链接、清单或摘要不符时拒绝统计，不能回退为零。租约出现时按占用处理。
4. 统计不取得或修改租约，不启动原生 Worker，不调用移动接口。未来删除仍需独立的许可名册及当次校验。

## 最小验收

- 用正式包形态生成、退役、准备并移动索引，核对移动前后的文件数和各项逻辑字节一致。在独立进程复跑，并比较清单和全部文件未改。
- 覆盖租约、异常位置、控制清单失配、文件改变和取消；保留普通统计结果。包内复跑，实际 WK 回归普通搜索和定位。

## 继承约束检查

- F-002 沿用私有 App 数据边界，离线留最终人工。
- 中文与外观沿用普通搜索界面。
- 命令与键盘没有新增窗口入口。
- 安全与日志方面，统计回执只含位置类型和计数，不返回路径、文件名或正文。

## 验收结果

- macOS arm64 unsigned canary `0.1.0-alpha.234`，包标识 `1e1t1zlgd3u28`。包内 Bun 1.4.0 定向复跑 5 项通过、14 项条件跳过、18 条断言。隔离移动和统计场景另有 100 条断言通过。
- 正式索引移动前后，文件数、清单字节、索引字节与合计一致。无原生移动模块的新进程仍能返回待回收占用。过程没有取得租约，原文件、清单和目录保持原样。
- 租约晚到时返回 `BUSY`。取消、异常位置、清单缺失或损坏、文件时间变化，以及摘要一致但原生名册含外来文件的情况均拒绝给出占用值。
- 真实 WK 回归普通搜索一篇两处命中、定位第二处 `[19, 23)` 和 ⌘Q 正常退出。夹具 SHA 不变，启动器退出 0，未创建索引槽，临时目录为空。
- 类型检查发现新位置标记的推断范围过窄，显式区分空槽和有文件的回执后复跑通过。源码全量 1914 项通过、33 项条件跳过、1 项失败，39478 条断言。唯一失败仍是已登记的 FINAL-ISSUE-002 长空白超时。Lint、文档、锁文件和差异检查通过。
