## 功能说明与范围

打开文件夹后立即作为窗口顶层根显示扫描状态，递归发现 `.md`/`.markdown`，渐进展示只含有效 Markdown 后代的目录分支。多个任意目录与独立文件共同作为同级根；按真实卷 canonical 路径去重，目录根按 W-25 只保留最外层，后加入父根吸收其覆盖子根，包括显式隐藏目录根。普通独立文件被父根实际发现展示后移除顶层重复项；默认隐藏过滤之外的显式普通隐藏文件保留 standalone 可见例外。不复制文件、不破坏已打开文档身份、模式、dirty 或历史。

欢迎页、侧栏及统一命令均可加入文件夹。最小树支持展开、单击选择、双击及显式键盘打开所选文档为常驻；已有文档仅激活并保留模式和状态。单击本片只选择，不沿用单击常驻打开，也不声称已实现 F-032 临时预览。

默认排除隐藏项，`.git` 目录及后代硬排除；目录 symlink 不递归，文件 symlink 仅真实目标为授权内普通文件时纳入，按 canonical 去重并优先非链接可见归属。不解释 `.gitignore`。本片不提供正式根移除 UI 或转独立文件选择（F-061）、监听（F-027）、恢复（F-029）、隐藏开关及完整树交互（F-026）。目录工作区的图片扩权留 F-022，当前仍保留单文件父目录图片授权局限，不因目录根出现扩大图片读取权限。

沿用 W-16 / 当前基础结论 324 的既有例外：用户单独显式打开的普通隐藏 Markdown 仍保留为 standalone file；默认目录扫描不发现隐藏项时，父根覆盖不能将该显式文件吸收得不可见。该例外仅适用于独立文件，不扩大到隐藏目录根；隐藏子根被父根吸收后按父根默认隐藏策略不显示，但已有文档标签及状态保留。`.git` 是例外中的硬禁止，其目录及后代不得通过单文件或目录入口加入。此处不是新增隐藏策略或提前实现显示隐藏开关。

六个主承接义务 OBL-004/007/008/015/023/039 均局部实施；无延期 ID 不代表完整责任完成，父 F-025 及全部余项开放。硬前置为既有单文件 Document Service、授权/身份、文档控制器与统一命令；不等待完整父功能，不虚构已存在的通用扫描 scheduler，不提前冻结最终 scopeId/schema。

## 最小技术方案

扫描沿用现有 Node-API 路线与 `openDirectoryAt(O_DIRECTORY | O_NOFOLLOW)`，通过固定 scan Worker 执行 descriptor-relative 有界目录枚举，必要时小扩展枚举/metadata/readlinkat primitive；不切换 Bun FFI。只扫描元数据，不批量读取正文或水合文档。接口由 executor 评估，不提前冻结完整 schema。不能以 path readdir 前后检查冒充不越权：已打开目录随后被移出根时仍可能接触其元数据，前后身份/generation 只能拒绝陈旧结果，不能冻结文件系统；本片不承诺绝无已移出目录元数据接触，也不扩大正文读取范围。

1. 后端通过系统目录选择器建立 opaque root/entry 句柄，持有规范路径与身份/代际；renderer 仅发送受控句柄、分页/展开意图，不能凭路径读取。首次扫描与派生打开均重新核验权限、根/路径身份和范围，按真实卷语义分量去重；危险或失效链接排除，局部错误不拖垮其他根。
2. 根授权成功立即返回元数据与扫描态，随后由独立最小有界队列渐进扫描。优先处理当前可见或展开分支，根内仍完成递归；任务绑定根 generation/取消状态，重新扫描、根替换/内部移除/清空后丢弃旧结果并清理句柄，不把逻辑取消说成阻塞文件系统硬取消。
3. 后端统一执行隐藏/`.git`/symlink/有效后代过滤，F-026 后续消费同一结果而非重复授权逻辑。逐批稳定合并可重建结果与最小树状态，扫描中和局部错误显式可辨；不静默截断树，不因预算限制谎称扫描完成。
4. 派生文档打开接入既有 Document Service 身份与文档状态，不新建第二套正文服务。可复用 `authorizeSingleFile` 只打开 metadata/FileHandle；任何 snapshot 正文读取前，必须复核扫描时 expected canonical path、叶子 fingerprint、完整祖先身份及 root generation，失败关闭句柄。正文仅从通过检查的已持 fd 读取，不为此新增 fd-read 包装，也不宣称打开检查前未接触外部 metadata。使用时每次 read/save/image 均复核 root ownership；扫描本身仍用上述 Node-API descriptor-relative 路线。同一文件已有标签只激活，保持模式/dirty/选区历史。父根吸收已覆盖根时迁移有效授权归属或保留必要派生授权，不能误撤销仍打开的文档。内部移除/清空的撤销和过期清理须可测试，正式用户移除策略留 F-061。
5. 根与有效文档归属属于权威运行状态，打开正文属于编辑状态，均不按派生缓存预算淘汰。对可重建扫描页/派生展示结果分类计量、限定驻留并观测；优先简单可验证保护，达到可调派生预算时暂停，中文明确“未完成”并允许重扫，不静默截树或声称完整扫描。采用可重建页缓存时可 LRU 淘汰重建，但不驱逐权威根/文档。不开新索引后端、不建设全树持久索引；并发、批次、页大小及预算由实际实现/样本测量记录，不是预设性能门禁或 RSS 上限。
6. 欢迎页、侧栏按钮、命令面板共用加入文件夹命令及冻结/IME 上下文；树项有键盘焦点、展开/选择与显式打开等价操作。单击仅选择的切片行为须在手册说明，临时预览未来接入；不混用文件路径与 capability，诊断只固定错误码和有限计数。

## 最小 happy path 与异常验证

- 临时两根含 `.md`/`.markdown`、空目录和非文档分支：根立即显示扫描态，渐进完成后仅有效分支可见；隐藏与 `.git` 排除，目录 symlink 不递归，授权内文件链接正确去重，外链/循环/失效排除。
