## 用户确认与剩余边界

1. **首项没有前兄弟**：`- A\n- B`在A上缩进没有可归属的前项。建议不改并说明“首项没有可缩进的前一项”；不默认产生代码块或凭空创建父项。
2. **顶层反缩进**：`- A`已无列表父层。建议保留标记、不改；移除标记成为段落属于另一种编辑语义，既有“变更层级”没有明确授权。

1. **准入与整组选择**：普通编辑/源码沿现有缩进入口，选区按逻辑行投影为最近ListItem，排除终点恰下一行首；选中父项时去除重复子项。每组必须同一直接列表父节点且连续；多个互不相交组可以统一计划，祖先交错/跨列表非连续/混入普通段落、引用或围栏标记则整次拒绝并给中文原因，不部分改。同一组首项无前兄弟缩进、顶层反缩进按已批准no-op；混合可动与不可动目标整次拒绝，避免只改部分选区。列表子树中的代码随父项移动，但光标直接位于代码内容时不推断为整个列表项命令，保留既有围栏消费者边界。
2. **结构计划**：连续同级组一起缩至组前兄弟的正文列；反缩进提升至父项同级，整子树保持相对层级。用户B规则严格保持物理顺序，尾随未选兄弟按新的Markdown父级归属；不额外重排原文。保留每个marker/数字与分隔符，不应用Enter的顺延算法。不能跨相邻独立列表寻找隐式前兄弟；异类marker不能形成所需归属则原子拒绝，余项仍记录开放。
3. **空白与内容**：采用CommonMark固定4列解释结构前缀，与编辑tabSize区分；通过公开countColumn计算列。首次生产支持可可靠剥离/补足的空格结构前缀；Tab穿越结构基线及无法减去所需列的lazy延续先准确拒绝整批，不用空格猜测代码内Tab语义。正常lazy段落缩进仅当完整候选树证明段落/子树语义不变才允许；反缩进不能可靠去前缀则拒绝。空行保留既有字节；有序非1起始在目标正文后需要时新增结构空行，已有空行不重复增加。不得改围栏/info、代码内容、正文字符或未触及行尾。
4. **局部公开解析验证**：使用当前公开Lezer树，要求相关完整顶层列表块及所需边界已解析且没有longLineProtection。按顶层块去重合并所有变更，用公开commonmarkLanguage.parser.parse验证局部候选，不调用canonical生产管线、不逐范围完整state、不ensure全文。聚合相关块长度沿既有LONG_LINE_UNITS作为临时同步计算保护（不是普通文档大小上限或性能SLO）；超过则明确本次结构操作暂不可用、不改正文。包含必要块间分隔及相邻边界以防合并外部块；边界不能证明安全则拒绝，不截断语义上下文。
5. **验证内容**：通过变更映射匹配原ListMark身份，核对全部原项仍存在、marker不变以及预期父子关系（选中子树/前兄弟/用户B尾随归属），不能仅数项数。核对相关段落、代码、HTML等叶块的规范内容和结构类型；除授权层级/必要空行导致的布局外，不吞项、不把文本变代码、不提前闭合围栏。多个组一次合并验证，任一失败全部拒绝；需要补空行的候选至多再验证一次，不循环猜解析。
