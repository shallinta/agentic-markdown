## 功能说明与范围

补齐当前源码及安全源码消费者与既有编辑模式共用关闭/退出保护的证据，尤其已开始保存挂起、取消确认和明确放弃的交叉状态。不改变既有“关闭主窗口等同退出 App”、不自动保存和默认不放弃规则。

- 关闭标签只处理目标；退出检查全部未保存内容。先等待已开始保存安全收尾，再依据最新基线及未保存状态决定，不因保存旧快照成功而丢弃之后输入。
- 取消保持原文、模式、选区/历史和活动文档；明确放弃才关闭目标或退出，不写未保存内容。安全源码的恢复/隔离状态不因取消重置。
- 保存失败、收尾未知等不得静默退出；clean 无确认，readonly dirty 仍确认，重复关闭仍沿用既有协调规则。
- OBL-067 仅本片当前模式；副区 F-035、恢复记录 F-066 及其放弃失效接入仍开放，父 F-017 不完成，OBL-046 已验收历史保持。

## 最小技术方案

审计并复用现有文档控制器、discard guard（放弃确认守卫）、保存屏障和 Electrobun 原生退出协调，不新增第二套 dirty 或原生补丁。通过实际当前模式状态、控制器和可控保存 Promise 联动测试覆盖挂起/失败/后续输入；真实窗口只用一次性样本完成源码/安全源码取消与明确放弃，不触碰用户工作文档。已有路径正确则仅补证据/测试；发现当前消费者缺陷再最小修正，改变行为或路线须先确认。

## 继承约束检查

- F-002：离线、关闭不启动保存，明确放弃不写盘；只等待已有保存，不提供另存为/恢复。临时样本磁盘内容前后核对。
- 中文与外观：复用中文单篇/全部确认和浅深/系统主题；不新造确认 UI，取消后内容及模式可见，不把自动测试当视觉验收。
- 命令与键盘：`⌘W`、关闭按钮和统一命令目标一致；`⌘Q`、退出菜单、红灯等同既有退出语义；取消默认安全，键盘取消不放弃。无拖放/分隔线。
- 安全与日志：前端确认不绕过后端保存屏障；收尾无法确认不退出，故障/超时只记录匿名固定信息。不执行内容、不输出正文/路径，不为测试丢弃用户文档。

## 最小 happy path 与边界验证

1. 源码/安全源码下 dirty 标签关闭，取消后完整保留；明确放弃只关闭目标，磁盘字节不变；clean 标签不弹框。
2. 当前模式保存挂起后发出关闭/退出，等待回执；保存期间后来输入仍须确认，失败或未知不能被当成已保存退出。
3. 多标签退出取消后各文档和当前模式/选区/历史仍在；明确放弃后 App 实际退出且未保存正文未写盘。真实窗口红灯/`⌘Q` 按实际覆盖记录，不虚构所有入口均亲验。
4. 自动可控延迟与真实原生退出证据分别记录；相关及全量测试、类型/Lint/格式、承接检查及独立复核完成后集中人工验收。未来副区/恢复消费者不在本片。
