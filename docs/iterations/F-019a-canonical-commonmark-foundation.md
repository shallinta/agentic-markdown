## 功能说明与边界

建立独立于 Lezer 编辑解析的 CommonMark 规范解析基础，并用同一组固定样本展示可解释的语义对照结果。通过隔离实验台进行本片人工验收，不新增正式阅读模式，不读取用户文件，不改变现有编辑、保存或解析行为。

只覆盖本片共享语料；不宣称完整 CommonMark 认证。不接 GFM、其他方言、HTML/DOM 渲染、图片加载、导航、复制导出、大纲、折叠或块级增量阅读。父 F-019 与后续 F-020/F-021/F-074 责任保留，不预先冻结完整文档结构协议。

## 已确认的最小技术方案

1. 采用 `mdast-util-from-markdown`，其内部使用 micromark，将 Markdown 解析为 mdast 语法树。本轮核实具体版本并固定依赖；不需要为此引入完整 unified 插件编排层。官方依据：[项目文档](https://github.com/syntax-tree/mdast-util-from-markdown)。本次用户已确认该最小选型，实际安装与验证结果后续记录。
2. 共享固定 CommonMark 样本与明确预期，覆盖标题、块结构、行内链接、引用定义及使用、转义/实体、硬换行与组合反例。对照规范语义摘要，不直接比较两个引擎的 AST 节点名；引用候选与有效定义解析须区分。已知差异逐条记录，不用强行修补现有编辑器消除报告。
3. 明确原文的 BOM、CRLF 与 UTF-16 范围口径；解析不回写、不重新序列化正文。只为本片产生必要的语义摘要，不将内部 mdast 或 Lezer Tree 变成上层公共协议。
4. 复用已有显式实验入口与 Worker 打包方式，另建隔离 Canonical 实验台。正常窗口不加载或运行实验；只接固定样本 ID 与配置标识，不能借入口解析任意路径或用户正文。界面以中文文本展示结果，不将解析内容注入 HTML。
5. 仅一个活动实验任务；运行、取消、重新运行与退出清理有明确状态。取消须终止工作并隔离旧结果，不以 Promise 包装同步解析冒充可取消。本片局部承接 OBL-013 的实验任务取消与代际隔离，正式阅读任务优先级、限流及文档版本消费者仍留后续 F-019 切片。
6. 不引入跨运行解析缓存；OBL-021 完整配额、淘汰与观测延期到首次缓存消费者，不以本片无缓存关闭该义务。记录实际耗时及打包变化，不设置预先数值门槛，不将固定小样本外推为大文档性能保证。

## 最小 happy path

- 显式启动实验台，运行同一份固定原文的两条解析管线，查看标题、块、链接及引用解析的结果与预期差异。
- 运行引用定义变化前后的成对样本，结果相应变化，原始语料保持不变。
- 取消运行后不发布过期结果，重新运行成功；退出不遗留活动工作。
- 正常启动仍为既有编辑窗口，无实验自动执行；既有打开、编辑、保存行为不受影响。
