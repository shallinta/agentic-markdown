## 功能说明与边界

编辑模式按现有解析器的SetextHeading1/SetextHeading2节点，将正文呈现为H1/H2。光标与选区未触及整个标题块时，仅隐藏HeaderMark下划线字符；物理换行和标记行高度保留，不折叠整行。光标或选区触及块内任意位置或边界时，恢复全部原文标记，包括标题内嵌强调、代码、链接等既有显隐标记。

多物理行标题正文按可见行呈现，不强制合并；源码与安全源码不隐藏原文。由解析节点区分水平线、引用和列表上下文，不用字符形状另造Markdown语义。沿用长行、IME、viewport保护，无新命令、加载、跳转或格式转换。用户已确认推荐方向并授权推进人工验收，本轮最小实现约束已在主任务commentary公开，不再标为待方案确认。

1. 复用现有语法树、可见范围装饰与主题变量；仅识别SetextHeading1/2和对应HeaderMark，不做全文扫描、额外解析或新依赖。正文逐可见物理行使用对应H1/H2样式，不访问整块全部行。

3. 保留源码/安全源码隔离与IME组合期间行为；不更改正文、BOM、混合行尾、选区坐标、复制、历史或保存。引用/列表中的识别与已有样式组合遵循现有解析器，不误把水平线当标题。
4. 实测并记录可见范围和长行回归，不预设性能门禁。若必须改变已确认显隐、行高或关键路线，先更新本文件并重新确认。
