## 本片交付

在正常窗口对选定的、已完成扫描的一个目录根查询正文。界面标为「在此文件夹中搜索正文」，显示覆盖范围、结果来源和查询状态。沿用现有字面量语义，区分大小写，每个文件最多显示首个命中。已打开文档的未保存正文覆盖对应磁盘命中。容量超限、扫描未完成、目录变化、内容版本不明和确实无命中分别显示。首片沿用 16 文档、65,536 字节和现有 wire 上限。

本片显示结果与位置，命中跳转由后续版本校验切片承接。多根、独立文件、筛选、持久更新和流式结果仍由 F-064 父项承接。

## Bun 授权与磁盘候选

1. 正式 RPC 绑定发起窗口的工作区和文档服务。请求只允许协议版本、请求 ID、已选目录根句柄、扫描代、字面量与有界的当前打开文档句柄候选。打开句柄最多 16 个，超限显式拒绝。句柄是配对线索，既不决定磁盘查询范围，也不能授予新的文件读取或覆盖权限。
2. 工作区按当前实例、根代、完整扫描及条目身份验证整个范围。沿用 F-064e 的目录链、隐藏策略、读取前后授权核验、有界资源、取消、正常收尾及 `UNKNOWN` 规则。Bun 在回包前重核根与条目。根、扫描代或授权变化使本次结果失效。
3. Bun 用自己的 grant、canonical path、文件指纹及文档身份，把仍获授权的打开句柄与本次扫描的文件条目配对。renderer 提交的路径、正文、clean 或 dirty 标记均不参与权限判定。匹配同时记录 grant/磁盘版本，接受与返回之间发生 grant 增删、绑定切换、保存或作用域撤销时废弃本次映射。多义配对不作推断。若沿用 F-064g 的状态代数，只复用失效机制，不要求本次无 grant。
4. 返回磁盘候选而非合并结果。结果关联请求 ID、根与扫描代，列出所有实际覆盖的条目，包括零命中的条目。每条只返回扫描条目句柄、实际读取字节的 SHA-256 和字节数，以及可选的首个 UTF-16 区间。合法配对另带打开句柄、文档 ID、Bun 已知的磁盘 revision 和 hash。文件名从同代文件树取得。路径、授权对象、磁盘正文、索引 ID 和缓存位置均留在 Bun。响应形状、容量、重复条目、错根错代、区间和版本类型在消费前核验。

SHA 标识用于建立索引的实际字节，不能由扫描时间或旧镜像代替。扫描与读取只保证各条目的授权与读取一致性，不承诺整个文件夹在同一时刻的磁盘快照。结果日后被用于打开或定位时，仍须重新打开、核权，并以新文档快照 hash 或当前缓冲区版本验证。

## Renderer 内存覆盖与交付

1. 发起时捕获当前查询、选中根及扫描代，记录当前编辑器的打开句柄、文档 ID、基线磁盘 revision/hash、缓冲区 revision 和未保存状态。使用 `client/documents.ts` 的编辑器状态与发布订阅。renderer 的数据用于本地结果一致性，磁盘权限由 Bun 决定。
2. 收到磁盘候选后复核请求、根代和捕获的文档版本。对 Bun 已配对且版本可核验的 dirty 文档，使用 `rawText` 中的原文做 `indexOf`，保留 BOM、CRLF 和 UTF-16 偏移。覆盖前移除该条目的全部磁盘命中，内存无匹配时也保持移除。无 dirty 的已覆盖条目使用磁盘候选。未保存正文不上传 Bun，不写入索引或缓存。
3. 缓冲区编辑、保存、打开或关闭改变本次捕获状态时，立即清掉已展示结果并丢弃迟到响应。根代变化、关闭查询或取消同样失效。对于有未保存、stale、保存中、结果不确定、外部变化风险、已撤销或未能可靠配对的打开文档，若无法证明与选定范围无关，保守显示查询范围不完整，不展示为已完成。dirty 配对还需核对 renderer 基线、Bun 已知磁盘版本和本次磁盘候选 hash，避免在未识别的外部改写上合并。有效内存覆盖后的语料同样受容量上限约束。

## 入口隔离

F-064e 的有界读与索引是 Bun 内部实现。F-064f 实验 RPC 仍只接受自建夹具发出的范围，启动开关只开启实验页。F-064g 的无 grant 票据继续用于原纯磁盘内部调用，不能证明 renderer 没有未保存内容。正式入口须使用独立命名的受控 RPC，携带完整授权映射及版本校验。两个入口可复用内部执行与收尾，禁止在公共请求中提供跳过票据、指定路径或借用实验授权的选项。准入与查询不锁住前台编辑或保存。

## 最小验证

- 在真实窗口向一个自建已扫描目录查询，包含 BOM、CRLF、emoji 和中文。确认区间准确、确实无命中与不可查询可区分。无 grant 的正常文件夹仍可查询。
- 打开已配对条目，未保存编辑移除磁盘命中，再产生新的内存命中，撤销编辑后回到磁盘候选。分别验证内存无命中、磁盘无命中和超过上限。检查磁盘文件未被改写，索引 wire 不含未保存正文。
- 查询在途和结果已显示时分别编辑、保存、打开或关闭文档、撤销根及更换根代。旧命中不可交付，后续新查询能恢复。覆盖撤销 grant 后 renderer 仍保留 stale 编辑器，确认不会把磁盘结果显示成完整查询。
- 从两个工作区发送伪造根、过期代、无关或已撤销句柄。验证不会得到跨范围条目配对或内容，实验入口与正式入口不可互用。验证取消后正常回收，`UNKNOWN` 时保留原生槽及明确状态。
- 新包验证正常用户窗口和独立实验窗口，核对授权、覆盖和失败状态。由独立复核确认协议及首片范围后，再标记该范围验收。

## 实施与包验记录

Bun、渲染层合并及正式窗口入口分别开发，交叉独立复核。覆盖证据包括零命中的条目，逐个句柄明确返回匹配、范围外或无法确认。渲染层捕获所有打开标签的编辑器实例和版本，未保存正文只在渲染层匹配。合成实验窗口与正式查询 RPC 互斥。关闭、重载或更新在批准后等待已接受的查询完成原生收尾。窗口转换会作废已接收的在途响应，未验证 SDK 队列中尚未交付的旧请求有独立发送方代数。

alpha.194 首包验证磁盘命中、磁盘零命中的文件在未保存编辑后产生新命中，以及撤销使结果失效。独立复核发现退出仅取消查询而未等待收尾，补上等待后递增为 alpha.195。两包均由固定 Rust 1.90.0 构建为未签名 canary。

alpha.195（hash `3s1csvdslba4j`）实测普通窗口选中合成目录并覆盖两份文档。基线仅 `disk-hit.md` 命中，显示磁盘正文 `[7, 12)`。在该文档未保存地移除匹配后，结果为零；随后在 `disk-empty.md` 未保存地加入匹配，仅显示它的未保存正文 `[20, 25)`。撤销后旧结果消失，重查恢复磁盘命中。两份文档磁盘 SHA-256 保持原值。⌘Q 后 launcher 退出 0，隔离临时目录为空。

独立包形态复跑使用 alpha.195 内的 Bun 1.4.0 和原生资源，6 项通过、3 项外层条件跳过、0 项失败，23 条断言。三个内层用例由隔离子进程执行。独立复核核对了原生清单的 10 项源码及 3 项包内产物 SHA。退出与在途查询交错由定向测试覆盖，实际窗口退出发生在查询结果已呈现后。若原生 Worker 不回执，现有正常收尾机制仍可能等待。

同包隔离实验窗复跑合成命中 `[1, 6)`，⌘Q 后 launcher 退出 0，临时目录为空。全量回归为 1819 项通过、5 项外层条件跳过、1 项失败，38,585 条断言。唯一失败是已登记的 FINAL-ISSUE-002 长空白用例超时。类型、全仓 Lint、文档、义务及锁文件检查通过。包验后的 Lint 修正只把擦除的 TypeScript 类型别名改成接口，未修改运行逻辑。
