## 功能说明与边界

让当前持久文档可以在主区域进入真实的只读阅读模式，不挂载编辑 DOM，并随时回到原有编辑状态。消费 F-019b 最新规范解析与 [F-020b](./F-020b-safe-commonmark-reading.md) 受控节点构建；三模式状态和命令由独立的 [F-030a](./F-030a-mode-lifecycle-foundation.md) 承接，两片可共享一次构建但分别记录责任与验收。

本片是 F-021/F-030 的部分交付：内置 ThemePackage 选择及独立主题完整能力（OBL-029）延期到 F-021 后续切片；文件树单击临时预览、副区、会话恢复、完整稳定锚点、块级增量 DOM 更新、大纲、查找、图片加载、链接打开和 Raw HTML 渲染仍归对应后续功能，不缩减最终 MVP。

OBL-047 由 F-030a 主承接；OBL-065/066/067/070 在其原主承接父项保持开放，本批仅提供阅读消费者关联回归证据，不改派或关闭。2026-10-02 用户明确要求暂不自动开发专项设计选项：副区展开入口、大纲呈现、Frontmatter 阅读呈现、围栏内部换行策略均保持未决，不借本片默认值替代决策。

## 本片最小技术方案

1. 消费 F-030a 的逐文档模式状态，主区只挂当前模式的视图，不提供同文档源码与阅读并排。默认打开及既有实例激活行为由该生命周期唯一负责，不在阅读组件维护第二套模式状态。
2. 编辑器权威 EditorState、原文、选区、撤销、revision、dirty、保存捕获快照和文件授权不随视图卸载丢失。阅读是当前内存正文的派生视图，包含未保存内容；不重新读磁盘替换正文，不建立富文本写回模型。阅读选区不覆盖已有编辑选区。
3. 阅读待解析、取消、失败与成功状态明确区分。仅当前 documentId/revision/配置/generation 的结果能显示；切标签、关闭、正文变化及退出清理任务。失败保留可恢复提示/原文安全降级，不以旧结果当当前内容。
4. 消费 F-030a 的右上角无文本 toggle 与键盘入口，不在标签添加模式按钮，不新增源码可见入口；阅读组件提供正确的可访问区域名称和焦点承接。
5. 模式切换只响应 F-030a 已批准的操作，不自行绕过活动文档、冻结、IME 或安全源码隔离检查。
6. 阅读模式严格只读：撤销、重做及改变正文的命令不可执行，普通文本选择/复制不改变文档；已有未保存内容仍可由统一保存链路保存，保存不强制进入编辑，也不丢后来修改。关闭与退出仍按全部未保存内容统一保护。
7. 阅读块暴露受控的原文范围和视口偏移给 F-030a 的最小位置映射，不建立完整 DocumentStructureSnapshot。映射、回退与逐文档位置归 F-030a；本片验证阅读 DOM 提供的范围与 BOM/CRLF 原文吻合。
8. 阅读正文使用本片受控基础排版，普通正文随容器换行、不撑破窗口；代码只承接已有基础纯文本/源码保真呈现，不新增围栏内部换行设置或 F-048 专项交互。若实现某代码呈现必须先决定未定策略，则保留该内容安全源码降级，不自动作产品选择、不标记完整代码块能力完成。独立主题能力不能以外壳深浅色代替。
