## 功能说明

在现有隔离布局实验新增双草稿入口，保留原只读入口。两篇合成 Markdown 同时显示，只有活动编辑器可以改正文。切换后各自保留草稿和撤销历史。草稿只在实验内存里，不保存，也不进入普通窗口或恢复列表。

## 最小方案

为合成草稿控制器显式启用活动文档写入门禁。后台视图仍可保留选区、折叠及滚动状态，所有正文变更在控制器复核。界面同步将非活动视图设为不可编辑。实验切换沿用活动文档的组合输入检查；切换成功后才聚焦目标视图。复用 F-035h 双视图和滚动快照，不接实际文件和正式副区。

## 最小验收

- 实际 WK 两视图同时存在：在 A 写入后切 B 写入，先在 B 撤销，再回 A 撤销，各只修改自己的草稿。后台视图尝试输入不得修改正文。
- 在系统中文候选期间尝试切换；核对活动文档未变，候选上屏或取消后再切。记录后台视图重挂及 A 的选区、滚动观察。
- 原只读实验仍可进入，普通窗口照常打开文件与退出。确认没有真实文件写入。

## 实施与验证记录（2026-11-11）

合成草稿使用显式活动写入门禁：正文或原文变化必须来自当前活动文档，后台仍允许选区和滚动等视图变化。普通控制器不启用此选项，文件可写授权的含义不变。实验复用真实编辑器，按实际活动状态切换输入权限；鼠标切换请求不提前移走输入焦点，中文候选结束后可重试。

### alpha.314 代验结果

- 实际 WK 同时挂载两视图。A 插入测试标记后，焦点移到被动 B；当时 B 仍显示不可写，粘贴没有改 B 或 A。激活 B 后写入成功，A 保留标记。⌘Z 先只恢复 B；切回 A 再撤销，A 才恢复。
- A → B → A 时，A 的视图 ID 为 1，选区 0 → 4，顶部仍是 A-06，距顶 15、15.31、16.13 CSS px。B 卸载再挂载由视图 2 变为 3，原选区保留，A 的视图、焦点及锚点没有变化。
