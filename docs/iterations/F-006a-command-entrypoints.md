# F-006a：现有操作的统一命令与键盘入口

> 状态：已验收；2026-09-20 用户确认方案，实现与自动验证完成后明确确认人工验收通过
> 父功能：F-006 统一命令注册表与键盘基础
> 前置：已验收 F-001；文档操作复用已验收 F-003a、F-004a

## 1. 功能说明

将现有操作接入一致的命令入口，先验收一个真实可用的切片，不提前实现后续编辑、文件树或保存能力。

| 操作 | 本轮入口与行为 |
| --- | --- |
| 选择 Markdown 文件 | 原按钮、文件菜单、命令面板及 `⌘O`；仍打开现有只读验证界面，不代表 F-009 已完成 |
| 重新读取当前文件 | 原按钮、文件菜单、命令面板；本轮不新增快捷键，避免与重新加载 App 混淆 |
| 清空当前验证内容 | 原按钮、文件菜单、命令面板；不删除磁盘文件，不新增快捷键 |
| 切换侧栏 | 复用查看菜单、命令面板及已存在的 `⌘B` |
| 打开命令面板 | 复用查看菜单与 `⌘⇧P` |

本轮命令面板支持名称搜索、展示已分配快捷键、方向键选择、Enter 执行、Escape 关闭；关闭时合理恢复焦点，执行命令产生新焦点时不强行抢回。

可用状态与现有按钮保持一致：选择及重新读取在 busy（正在选择或读取）时不可执行；没有快照时不可重新读取；清空在有快照或 busy 时可执行。所有入口执行前再次检查，不因菜单状态同步延迟绕过保护。清空不承诺关闭已经弹出的系统选择器，继续使用现有过期结果隔离行为。

仅本轮命令使用固定中文名称；starter 的设置、更新、缩放等入口保留为继承草稿，不扩展其产品验收。全 App 中文化属于 F-007；后续文档模式、选区、多区域上下文随相应功能接入。F-006 父功能不因本切片通过而直接完成。

## 2. 最小技术方案

- 复用现有共享命令定义、WebView 命令 Provider、Bun 菜单及按需加载的命令面板，不引入第二套命令框架。
- 为本轮命令集中定义稳定 ID、中文名称、固定快捷键及展示元数据。按钮、菜单和面板引用同一 ID；不各自调用一套业务逻辑。
- 文档组件注册已有 controller 操作和最新可用状态，卸载时移除；执行端统一校验状态并处理异步失败，不泄漏正文或完整路径。
- macOS 快捷键由原生菜单统一触发，不另注册相同 DOM 快捷键造成重复执行。菜单同步只发送必要的命令可用状态，不传正文；不能形成重建菜单循环。
- 保留既有 Bun/WebView 路由；新增状态协议做运行时校验，未知 ID/无效状态不改变业务授权。命令注册不授予文件访问权限，仍通过现有文档服务选择与读取。
- 命令面板只在打开后参与交互；状态变更不引发文档解析或正文复制。观察交互与菜单更新表现，不冻结性能门槛。

## 3. 最小 happy path 与验证

1. 空窗口按 `⌘O` 选择 Markdown，显示原文；按钮、菜单及命令面板打开操作结果一致，一次快捷键只触发一次选择器。
2. `⌘⇧P` 打开面板，搜索“重新读取”，用键盘执行；内容未变时身份和版本保持不变。
3. 面板搜索并执行“清空”，正文清除；重新读取在按钮、菜单、面板中都不可执行。
4. `⌘B` 和面板切换侧栏效果一致；Escape 关闭面板，焦点不丢失；不误触发页面重载或输入编辑快捷键。
5. 选择/读取期间重复触发不会重复请求；清空后旧异步结果不得恢复正文。保留现有文档只读与单文件授权边界。

实现后补充命令路由、状态变化、无效请求、键盘/菜单映射及现有文档服务回归测试，运行格式、lint、类型检查与未签名构建；真实窗口验证不能由静态测试替代。只覆盖受影响 starter 接线，不宣称其余附带功能通过验收。

## 4. 实现与验收记录

### 4.1 实际改动

- 共享命令定义增加本轮稳定 ID、中文名称和固定快捷键元数据；文档按钮、菜单、面板统一分发。
- 提取可测试的命令 registry（注册表），支持即时可用性判断、所属注册清理及通用失败提示。判断同步读取 controller 的最新状态，避免同一次 React 更新前重复触发。
- 文档组件订阅状态变化；只把选择、重新读取、清空三个布尔可用状态同步给原生菜单。状态协议校验版本、字段及类型，相同状态不重建菜单，执行端仍再次校验。
- 面板显示中文产品命令、已有快捷键及禁用状态；搜索按名称过滤。关闭时先恢复原焦点，再执行选中命令，避免抢走新弹窗焦点。
- 共享 CommandDialog 增加内容事件透传，并把可访问标题与描述放入弹窗内容中；没有新增依赖或重复 DOM 快捷键。
- 验证正文区继续显示 F-004a 的单文件授权说明，本轮新增的是命令入口，不改变只读正文与 1 MiB 等边界。其他 starter 命令仍为继承草稿。
