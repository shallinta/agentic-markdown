## 1. 功能说明

1. 关闭标签只检查目标文档：无未保存变更直接关闭；有变更只询问该篇，取消保留，明确放弃才关闭；其他文档不受影响。
2. 红灯关闭主窗口视为退出 App。退出菜单与 `⌘Q` 同样一次确认全部未保存变更；全 clean 不弹确认。确认只提供放弃与取消，不提供保存或自动保存。
3. 已在执行的保存先安全完成或失败，再按当前版本判断；旧版本保存成功不能清掉新修改。无法确认收尾时拒绝退出并保留内容。只读但仍有未保存内容的文档仍须确认。
4. 同时或重复发起关闭/退出不叠加确认，不复用过期许可；取消后解除本次冻结，恢复原有交互。沿用中文候选期间的现有保护规则。
5. 不引入副窗口、正式模式、自动保存、崩溃恢复或完整外部 missing 流程。父 F-017 后续仍需对这些消费者及副区域接入复验，不以本片完成替代。
