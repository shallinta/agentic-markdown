## 范围

给固定私有索引槽增加显式逻辑退役。退役后既有查询与增量入口停止重开该槽。原生索引文件仍保留，继续计入逻辑占用。本片不接自动撤权、淘汰或缓存重建。

## 最小实现

1. 调用方提供确切范围键和代数。只访问已存在的私有槽，复用排他租约。当前有效清单与请求不匹配、缺失、损坏或忙碌时保留现场。异范围返回 SCHEMA，代数失配返回 MISMATCH。
2. 使用既有有界清单暂存和原子替换机制，把匹配的活动清单改为版本化退役标记。发布前再核对原清单、原生目录、租约和调用方状态。相同退役标记可幂等确认。已确认发布和释放租约后，晚到的取消不改变成功回执。
3. 标记与活动清单区分，查询与增量路径在启动原生会话前拒绝退役槽。保留清理不明确的 UNKNOWN。文件数据仍在，本片验证进程重开状态，不证明断电持久或正文擦除。

## 最小验收

- 用正式原生资源在隔离槽冷建，退役后由新进程打开并拒绝。原生文件摘要和元数据不变，退役槽仍可统计。
- 验证相同请求重试、错范围、错代、忙碌、发布前取消和目录变化。收尾不明时保持状态可核对，不自动回滚或删除。
- 包内复跑，真实 WK 回归直接搜索、定位和退出。

## 继承约束检查

- F-002 沿用当前本地授权，离线留最终人工。
- 中文与外观沿用现有搜索面板。
- 命令与键盘沿用现有搜索入口。
- 安全与日志方面，退役只更新固定私有清单，不新增正文或真实路径日志。
