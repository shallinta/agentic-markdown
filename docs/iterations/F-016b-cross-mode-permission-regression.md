## 功能说明与范围

复验当前编辑、源码及安全源码状态在运行时权限变化后，同一只读能力对输入、历史、保存和命令上下文持续生效，同时保留内存正文、未保存状态、选区与历史。不是新增权限系统，也不新增目录工作区、阅读模式或副区。

- writable 转 readonly / unavailable / invalid 后保守禁写；恢复 writable 后允许既有编辑操作。模式切换不得重置权限或解除安全源码隔离。
- 只读仍可选择、复制与滚动；只读但有未保存内容仍受关闭/退出确认保护。
- OBL-066 仅承接当前模式消费者；目录工作区、F-025 / F-030 / F-035 及未来写交互接入仍开放，父 F-016 不完成。OBL-045 已验收范围不重复认领。

## 最小技术方案

复用既有能力响应、控制器写事务 guard（守卫）、编辑器配置和统一命令。以实际状态与控制器联动测试模拟绑定正确文档的运行时能力变化，核对状态保留与命令行为；拒绝过期或错文档响应继续沿用既有约束。真实权限检查使用一次性文件/目录并恢复其权限，不新增平台原生接口。已有实现正确时仅补测试/证据；发现缺口才在当前路径做最小修复，不为验证制造生产改动。

## 继承约束检查

- F-002：只处理本地已授权一次性样本，离线、1 MiB 与磁盘唯一真源保持；不得对用户真实文件更改权限。
- 中文与外观：复用中文只读/检查失败状态和浅深/系统主题，不只凭颜色传递权限；保持选区可辨，不造视觉验收。
- 命令与键盘：输入/粘贴/删除/撤销重做与 `⌘S` 均服从同一权限上下文；选择复制仍可用。模式切换不绕过写保护；无新增拖放/分隔线入口。
- 安全与日志：保存仍实际复核权限，前端状态不替代后端检查；未知/过期结果不能解除保护，不执行 Markdown 或记录原文/路径。安全源码不因权限恢复退出隔离。

## 最小 happy path 与边界验证

1. 各当前模式下产生未保存修改和选区后让能力变只读；键入、粘贴、删除、历史写操作及保存均被拦截，原文/dirty/选区/历史保留。
2. 只读时切换可用模式或进入安全源码，仍无法写入；恢复可写后继续编辑、撤销及保存正常，不清空原有状态。
3. 过期/错文档能力响应不影响当前文档；一次性样本真实权限变化与恢复另记录结果，不能把模拟能力响应称为原生权限实测。
4. 实际窗口普通成功路径、相关及全量测试、类型/Lint/格式、文档/承接检查与独立复核后进入集中人工验收。真实 IME 仍与合成事务证据分开。
