## 范围

目录文档从搜索命中首次打开后，关闭标签仍可能保留目录派生句柄。再次查询并点击命中时，通过原句柄重开并定位。继续保留首次打开、已打开标签复用，以及独立文件和父目录吸收后的定位行为。

## 最小实现

1. 目录命中没有打开的文档版本时，查找同一位置的保留条目。已有条目沿用 F-064w 的目录锚点和原句柄，首次打开仍走原新建授权路径。
2. 目录派生句柄只可在确有同一可见目录条目时准备重开。验证当前目录、扫描条目和原文件授权的身份、路径链和命中摘要。读取沿用 64 KiB 上限。取消或替换时保持原授权，禁止用迟到回执覆盖现有标签。
3. 渲染器核对同一树条目、句柄、位置和授权类型，复用已有的定位与焦点流程。普通目录结果不进入独立文件范围。

## 最小验收

- 从真实目录结果打开一篇文档、关闭标签、重新查询并打开同一命中，确认只重开一个标签并定位。
- 覆盖摘要不匹配、旧条目、错误目录、活动标签、取消和废纸篓隔离。验证独立文件仍可搜索和重开。
- 包内复跑，并确认夹具摘要不变、应用正常退出。

## 继承约束检查

- 安全与日志方面，原目录授权和命中摘要共同约束读取，不新增正文或路径日志。
