## 1. 功能说明

- 当前活动文档使用 `⌘⇧M` 在编辑模式与源码模式间切换。只提供快捷键，不在按钮、菜单或命令面板增加源码入口；内部命令仍统一注册及校验上下文。
- 新打开文档默认编辑模式；每篇文档独立记录本次打开期间的模式，再次激活已有文档不重置。源码显示完整 Markdown 标记，提供当前 CommonMark 基础高亮，不渲染内容或执行 HTML。
- 2026-09-26 用户确认：源码为纯 Markdown 代码编辑器，统一等宽字体、字号与常规字重；仅颜色区分语法，取消标题/粗体加粗、斜体、链接下划线及行内代码背景。编辑模式排版不变；只调整源码 HighlightStyle，不改变解析、原文、选区、历史与保存。回归高亮规则仅含颜色属性，并复验模式切换后编辑排版仍正常。
- 两种模式使用同一正文、选区和撤销历史，切换不产生修改、不保存、不改变内容 revision；保存、只读、关闭保护复用原路径。
- 中文组合输入、关闭确认及不允许交互期间禁止切换；其他输入框或弹窗输入不触发文档模式命令。只读文档允许切换但不能编辑。
- 本片不实现阅读模式、阅读前置模式返回、跨重启模式恢复、稳定内容块锚点、完整源码语法高亮、源码行号/多光标，亦不声称完成自动异常降级。这些分别由 F-030 / F-037 / F-040 / F-042 / F-044 与 F-013 后续切片承接。父 F-013 未完成，普通 1 MiB 边界不变。

## 2. 最小技术方案

- 用 CM6 Compartment 切换表现层扩展，保留同一语言及原文/历史字段；源码不挂载即时排版隐藏装饰。主题仅使用固定 token，不因外观变更重解析。
- 文档模式归当前 documentId 的编辑状态；复用当前活动视图事务分发，切换不销毁编辑器或重建 EditorState。当前源码只能从编辑进入，因此再次切换返回编辑，不提前伪造阅读模式。
- 复用 CM6 当前视口/源码位置机制尽量保持对应内容位置；不同字号使像素位置可能变化，不代替 F-030 稳定块锚点验收。
- 复用统一命令和最新可用性检查，快捷键与 composition/只读/保存及关闭生命周期协调，不新增 RPC 正文通道。
- OBL-028 / OBL-042 在当前源码基础范围承接；未来高亮扩展或其他消费者接入另行显式追踪，不能以本片验收完成全产品。OBL-064～067 仅回归当前新增模式消费者，不关闭其完整责任。

## 3. 继承约束检查

- F-002：离线直接编辑原文，模式切换不写盘；回归 BOM/混合换行、复制和保存。
- 中文与外观：中文模式提示/可访问标签；浅深/系统外观高亮与选区可读；真实 IME 交人工，自动验证只证明状态保护。
- 命令与键盘：内部统一注册，源码仅快捷键；无文档、其他输入框、弹窗及组合输入不误触，读写能力与模式切换能力分离。
- 安全与日志：源码文字不成为 HTML、链接或资源，不引入外部请求或正文日志；既有授权、只读、保存及关闭流程保持。

## 4. 最小 happy path

1. 打开样本，在编辑模式有选区时按 `⌘⇧M`，完整标记可见且选区保留；再次触发返回编辑。
2. 两篇文档分别保持不同模式；切换标签后各自恢复。编辑后跨模式撤销/重做，保存仍正确；纯模式切换不产生 dirty/revision 变化。
3. 源码和编辑切换时 BOM、混合换行不变；只读文档能切换不能修改，中文候选期间不能切换；关闭未保存确认不回退。
4. 浅深外观、完整原文复制及视口位置人工检查。按钮/菜单/命令面板不存在源码切换入口。
5. 定向与全量测试、类型/Lint/格式、承接文档检查与独立复核；递增 alpha 构建并核对真实产物。实现完成只进入人工验收。
