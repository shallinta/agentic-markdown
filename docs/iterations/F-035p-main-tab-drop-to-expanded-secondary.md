## 功能说明

在隔离真实文件窗口，可把主区标签拖到已展开的副区。文档从主区标签组移除，追加到副区底部，并成为活动文档。副区空间不足时，拖动过程中提示「空间不足」，松开保留原布局。副区收起时不能拖入。

## 最小方案

复用已授权文档、现有跨区拖动票据与副区容量分配；先算容量，再激活并提交显示归属。只接受副区实际内容区域，现有分隔线、关闭与区内排序不变。标题点击仍正常；可先激活主区标签，再用既有按钮完成键盘等价操作。本片不接文件树拖入、双击自动路由或正式展开方式。
