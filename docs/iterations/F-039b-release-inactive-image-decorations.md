# F-039b 释放非活动标签的图片呈现

> 状态：alpha.293 受托代验通过。

<!-- obligations: none -->
<!-- deferred-obligations: OBL-024 -->

## 功能说明

主区切走一个标签时，清掉留在其编辑状态里的图片呈现对象。返回标签时由当前编辑视图重新生成，正文、撤销、模式、选区、折叠、位置和 revision 保持。

## 最小方案

- 在现有切走标签的派生状态清理中复用图片装饰重置。字段不含图片时不增加重置操作；活动视图、普通输入和源码模式的行为沿用现状。
- 图片装饰可能保留旧视图的闭包。只切断这条已定位的引用，沿用原图片授权、视图销毁和重新生成路径，不新增缓存策略或资源额度。

## 最小验收

- 用实际文档控制器核对切走后图片装饰集合为空，旧视图不能迟到回写，恢复及撤销不丢正文、位置、选区和模式。原有图片及折叠定向回归继续通过。
- 打包后在真实主窗用授权目录内的合成 PNG 打开两篇文档。核对离开后返回时图片重新显示，其他文档不受影响，夹具字节不变并正常退出。
