# F-022e 在独立阅读窗口显示前两处已授权图片

> 状态：alpha.276 已由 Agent 受托验收。

<!-- obligations: none -->
<!-- deferred-obligations: OBL-010, OBL-031 -->

## 功能说明

打开已保存阅读快照后，独立阅读窗口可显示正文中前两处符合本地 PNG/JPEG 引用语法的图片。第一处不可用时仍尝试第二处。重复引用分别显示，第三处及后续图片保留占位。

## 最小方案

- Bun 和子窗从同一次已保存正文按同一 AST 规则选择前两处，按正文顺序分配槽位 0、1。子窗按 AST 节点身份挂载，文件名和引用地址不进入投递载荷。重复引用各有自己的显示位置，本片仍逐槽核验及读取。
- 正文先提交。已有后台候选 Worker 给出至多两个引用，Bun 一次只读取一张，在同一快照和子窗票据下依次投递。每个槽只接收一份终态。单张读取失败保留其占位，其余槽仍可继续。窗口关闭、导航、退出或超时后丢弃迟到结果。
- 沿用每张 1 MiB、原像素上限、整个子窗合计 24 MiB 的图片资源计账。已接收编码数据和呈现所需像素计入预算，超出时保留该槽占位。沿用 PNG/JPEG 格式校验、现有路径授权和只允许固定数据图片的 CSP。未保存快照仍只提供正文。

## 最小验收

- 定向测试覆盖两槽顺序、非法槽、重复与迟到回执、单张失败和聚合预算。核对节点身份，确保第二处同路径引用按自己的槽位显示，第三处仍占位。
- 在实际打包 WK 打开含两处不同有效图片的保存快照，核对 PNG/JPEG 两张都显示。另测首图不可读而次图显示、重复引用两处显示且额外引用仍占位、未保存快照和合成页无图。验证子窗关闭再开后旧结果无法进入新子窗，若受控竞态只能在包内测试触发则分别记录证据。
- 核对只读、原始夹具字节、原单图容量、安全策略及独立窗口退出。单图超限和两槽聚合超限的证据分开记录。
