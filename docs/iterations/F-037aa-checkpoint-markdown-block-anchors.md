## 功能说明

在主区已保存的目录文档中主动滚动，再切换标签时，随会话检查点记录当前 Markdown 内容块的摘要。后续重启定位原段落将使用这份记录，本轮先验证采集和写入。

## 最小方案

- 沿用 F-037y 的视口和目录授权，按句柄、文档身份、版本和摘要验证已保存正文。独立 Bun Worker（后台线程）复用 F-037v 的规范解析与摘要规则，只接收正文和视口位置。检查点保留摘要、匹配所需的出现序号及有据可测的偏移。
- 沿用现有检查点版本。每次写入最多为一篇新测量文档计算块摘要，进程同时只允许一次计算。几何相同且仍由本次会话持有的记录直接沿用。无可靠块时仍保存源码坐标和比例。恢复逻辑由下一片接入。

## 最小验收

- 在真实普通窗口打开两份合成目录文档，滚到第一篇后段再切走。检查点包含可从该篇已保存正文复算的摘要，第二篇保持原有状态。
- 重启并重新授权目录，核对上轮的视口恢复、检查点原字节及正常退出。定向覆盖正文或授权不匹配、无块回退、重复记录的计算次数和途中失效。

## 继承约束检查

- F-002 使用本地合成文档，离线留集中验收。
- 中文与外观沿用普通窗口。

- 安全与日志验证已授权的只读路径、检查点定位数据和正文原字节。
