## 功能说明

在当前窗口内调整主区常驻标签在固定组或普通组中的视觉顺序。两组仍按固定在前显示。提供拖动和等价的键盘命令。排序不改变活动文档、最近使用顺序、文件树、正文或磁盘内容。

## 最小方案

- 在窗口内单独保存标签视觉顺序，用文档 ID 协调新增、关闭、同文档刷新和身份替换。拖放与键盘共用一次提交，当前活动标签仍使用原有焦点与编辑状态。
- 复用已有内部拖动的放置反馈。只接受同组的有效位置，取消或无效放置保持原顺序。键盘通过命令面板移动当前标签，碰到组边界时停下。
- 本轮限当前普通主区的常驻标签。跨组改变固定状态、预览、副区和会话持久化由对应后续切片承接。

## 最小验收

- 用至少四个标签组成固定组和普通组，验证组内双向排序、跨组无效、末端移动限制及取消。核对活动文档、草稿、固定状态、文件树与最近使用顺序。
- 验证排序后新开、同文档刷新、显式关闭及可见顺序中的相邻标签。普通 WK 的拖动和键盘分别留证。
- 最终离线留统一人工，完整排序与恢复义务继续登记。

## 继承约束检查

- F-002 沿用本地会话，离线留最终人工。
- 中文与外观沿用固定分组及现有拖动反馈。
- 命令与键盘共用组内移动规则，局部承接 OBL-053。
- 安全与日志不读写文件，不记录正文或绝对路径。

## 实现记录（2026-11-10）

- 拖动文件名到同组标签的左半或右半，插入线标示松手后的放置位置。命令面板提供「在组内左移当前标签」「在组内右移当前标签」。
- 顺序按窗口内的文档 ID 记录。同一身份刷新保位，新身份追加。显式关闭活动标签时按当前可见顺序选相邻标签。
