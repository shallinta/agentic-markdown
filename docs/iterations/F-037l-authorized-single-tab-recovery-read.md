## 功能说明

在内部验证单篇主区标签的恢复读取。只接受权威会话记录恰有一篇、持久根身份与本次授权一致、当前扫描已完成且文件身份仍匹配的情形。读取的是当前磁盘正文，历史记录只提供文件身份、模式和固定状态。

## 最小方案

- 读取权威会话文件，不回退到备份。使用本次目录回执的根及代际和预期持久根 ID。历史相对路径只用于在现有扫描中定位，文件读取仍经现有目录授权。
- 复用受保护的工作区打开路径，在准备、正文读取及授权提交前检查请求和来源。提交前再核对会话记录、目录和物理文件身份。原位编辑仍是同一文件；不把历史文件身份当作历史内容摘要。
- 返回内部已授权读取回执；若结果晚到且失效，释放这次新建的授权，清理未确认则只报告未知。已有授权同路径暂不复用，绝不误释放既有授权。本片不挂 UI 或正式恢复入口，不改 MRU、不写会话或 Markdown。

## 最小验收

- 核对多条、空、未来格式、根 ID 不匹配、同路径换文件、目录换代、过期和晚到释放。普通 WK 同包验证目录文件照常打开及正常退出。
