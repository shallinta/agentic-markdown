# F-064k 单文件夹正文搜索的路径筛选

> 状态：alpha.198 已通过本片非离线受托代验和独立复核。

## 功能

现有筛选栏增加 `path:` 和 `-path:`。例如 `path:"项目 甲/" -path:草稿 file:纪要`。路径以当前选中根为起点，包含文件名，按区分大小写的字面量匹配。所有包含条件和文件名条件须同时满足，匹配任一排除条件的文件不进入查询。选择器按文件名、包含路径和排除路径分组，仍把 token 写入同一个可编辑栏。根内有同名文件时，结果附相对路径，方便区分。

拒绝绝对路径、空值、不规范的分隔和 `.`、`..` 路径段。结尾斜杠可用于指定目录片段。含空格的值继续支持双引号，路径筛选和文件名筛选合计最多八条。保持当前单根 16 篇与正文 64 KiB 边界。根筛选、跨根和持久增量仍由后续切片承接。

## 最小实现

1. 在共享解析器扩展语法和精确值校验。沿用文件名字段，新增有界的路径筛选数组。RPC 只传匹配字符串和类型，接收端独立校验。
2. 共享函数从已核对的根和文件路径提取相对路径。Bun 使用已授权扫描记录，在读取正文前过滤；渲染端只用同代扫描的显示路径复算覆盖和生成选择项。相对路径计算失败时拒绝本次结果。筛选值和显示路径均不作为打开授权。
3. 沿用已验证的全根快照守卫、被排除打开文档的身份复核、未保存覆盖、取消和命中定位。筛选改变立即淘汰旧结果。

## 最小验收

- 两个子目录各有同名 Markdown，正文同词。包含路径与文件名组合只返回正确目录中的文件，排除路径移除对应命中。带空格路径手输和选择器结果一致，命中可准确打开定位。
- 自动覆盖绝对与越级路径拒绝、空筛选、路径和文件名混合上限、被筛除的超限正文及未保存映射。实际窗口核对筛选变化、错误提示和正常退出。

## 继承约束检查

- F-002 沿用本地授权与本地筛选，离线留最终人工。
- 中文与外观沿用原有主题和中文行内提示。
- 命令与键盘沿用筛选表单、语义选择控件和查询命令。
- 安全与日志方面，筛选条件仅用于匹配。扫描、授权和打开沿用受控句柄，日志不记录筛选正文或真实路径。

## 实际验收

- macOS arm64 unsigned canary `0.1.0-alpha.198`，包标识 `1mts00s32bdhg`。真实 WK 窗口无筛选覆盖三篇同名 `纪要.md`，结果各有相对路径。输入 `-path:草稿 file:纪要` 覆盖两个项目。选择包含路径会回填 `path:"项目 甲/纪要.md"` 并清除旧结果；手输 `path:"项目 甲/" -path:草稿 file:纪要` 也得到同一篇。点击结果打开甲目录文件并选中 `[6,10)`。
- 从排除路径分组选择 `草稿/纪要.md`，同一栏回填排除条件，结果只保留两篇项目文档。`path:../项目` 触发行内错误并禁用查询。三个测试文件 SHA 不变，窗口正常退出，查询临时目录为空。
- 规格与规范独立复核无阻断。源码定向 23 项通过，包内 Bun 1.4.0 配合原生资源定向 18 项通过，均有 5 项条件外层跳过，由隔离子进程执行。覆盖路径语法、超限正文筛除、同名文件、窗口根范围、混合上限和迟到结果隔离。
- 源码全量 1844 项通过、7 项条件跳过、1 项失败，共 38,793 断言。唯一失败为既有 FINAL-ISSUE-002 长空白用例超时。类型、Lint、文档、义务登记、锁文件和差异检查通过。
- 实际窗口使用系统浅色外观，深色、自然 IME 和最终离线未复验。根筛选、跨根搜索、完整持久索引及四项延期义务继续承接。
