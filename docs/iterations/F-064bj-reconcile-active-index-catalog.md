## 功能说明

显式修复同一授权范围内的代数不一致。若现有清单为第 g 代，原生索引恰好为第 g+1 代，且其整份名册与调用方当前授权内容一致，则补写 v1 清单。回执表示当前内容已重新核对。

## 最小方案

1. 在同一私有槽租约下复核旧 v1 的范围、预期代数、字节与身份。原生文件布局须属于预期的下一代。原生仍与清单同代、领先多代、旧清单已变化或超过代数范围时拒绝。
2. 仅打开只读会话。核对原生代数及完整授权名册，确认会话关闭。原生索引文件保持不变。
3. 复用固定清单替换、同步和读回。替换前后复核调用方的物理证明。关闭或收尾不确定时保留既有故障处理规则。本片不接入自动重试、自动恢复、窗口或工作区入口。
