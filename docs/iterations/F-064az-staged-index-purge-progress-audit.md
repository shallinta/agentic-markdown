## 范围

只读核对待回收目录中仍在的成员。保留完整历史名册，报告应有、现存和缺失的文件数，以及现存索引文件的逻辑字节数。

## 最小实现

1. 接收内部显式请求的范围键、代数与 v2 摘要。核对私有槽中唯一的待回收目录、v3 清单及固定旁车，遇到租约按占用处理。目录与两份记录须都存在。
2. 在 64 KiB 和 128 文件边界内严格解码名册。规范字节绑定 v3 原始清单 SHA、目录稳定身份及完整历史文件身份。要求名册包含原生固定控制名和已知段文件名。以记录的全量名册复算 v3 稳定摘要。
3. 枚举当前直接文件，逐个核对名称和完整元数据。只接受历史名册的精确子集。拒绝外来成员、链接、身份变化或越界，交付前复核当前状态、整个目录和两份记录。未找到的成员只记为缺失。
4. 目录为空仍可报告全部预期文件缺失，前提是两份记录和目录身份可核实。旧占用入口继续拒绝不完整布局。审计回执不含路径或文件名，也不作为删除或恢复凭据。

## 最小验收

- 正式原生夹具先完成移动和名册发布。在隔离测试副本中分别模拟无缺失、部分缺失、全部缺失。新进程只读复核并返回准确数量与字节。
- 覆盖替换或改时的现存文件、外来文件、伪造记录、非规范或超限名册、两处并存、晚到租约和取消。原清单、名册和余下的文件保持原样。
- 包内定向复跑，实际 WK 回归普通搜索和定位。
