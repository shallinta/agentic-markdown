# F-005a：现有文档读取任务的取消与有界调度

> 状态：已验收；2026-09-21 用户明确确认“验收通过”
> 父功能：F-005 异步任务取消、背压与缓存底座
> 前置：已验收 F-001、F-003a；回归 F-004a、F-006a、F-007a

## 1. 本轮功能说明

- 范围只覆盖当前单文档选择、读取和重新读取入口。清空立即清除界面，并通知后台取消尚未完成的对应请求；旧任务不能恢复内容或提交过期状态。
- 文档读取采用有界调度；同类连续读取采用 latest-wins（只保留最新任务），未开始的过期任务不执行，运行中任务在可取消边界停止。
- 原生文件选择器最多一个。取消请求不强行关闭 macOS 选择器，也不承诺中断不可取消的系统调用；选择器返回后，已取消的选择不再授权或读取文件。
- 保持单文件只读授权、文档身份与 revision 规则、1 MiB 临时限制、中文命令和主题行为。不新增编辑、保存、目录扫描、索引或大文本传输。
- 不建立空壳任务平台或新缓存：现有文档身份与权威状态不作为 LRU（最近最少使用）缓存清理；缓存、优先级和其他任务消费者随后续切片落实，父 F-005 本轮不能完成。

## 2. 最小技术方案

- 在现有 typed RPC（类型化远程过程调用）上增加按请求 ID 取消的受控入口，严格校验输入；取消不能被无界读取队列阻塞，也不接受磁盘路径。
- 后台为现有读取工作维护有界运行/待执行状态与取消标记；最多一个运行中的文件操作和一个最新待执行读取。原生选择器占用独立单例槽位，释放授权和退出清理不得因读取积压而失效。
- 在授权前后、分段读取间、结果提交前检查取消及文档代际；资源清理和正文状态提交区分处理。客户端继续使用 generation（代际）检查作为最后防线，清空、替换和卸载时通知取消。
- 参数为本轮可调整实现细节，不是固定产品性能门槛。不引入外部调度依赖，不改变已确认的产品语义。

## 3. 最小 happy path

1. 选择有效 Markdown，成功显示只读原文；重新读取保持身份并按内容变化更新 revision。
2. 待读取完成前清空，界面立即为空，晚到结果不再出现；取消后新的读取仍可成功。
3. 自动测试用确定性延迟控制覆盖取消、最新任务替换、队列容量、提交前检查和资源释放，不依赖手速或大文件碰运气。
4. 验证原生选择器返回后不会执行已取消请求；它仍需用户自行取消/关闭，不宣称支持远程关闭。
5. 回归授权、错误提示、命令可用状态及主题。执行定向测试、全量测试、类型、Lint、格式和未签名构建。

## 4. 实现与验证记录

### 4.1 实际改动

- 用一个运行槽位和一个最新待执行槽位替换原来可持续增长的 Promise 串行队列；新读取淘汰尚未执行的旧任务，并协作取消未提交的运行任务。
- 新增 `cancelDocument` RPC，只接受协议版本和请求 ID；只匹配活动请求，未知或已完成请求幂等返回，不保留无界历史取消列表。客户端先发送请求，再通过同一通信通道发送取消；generation 检查与迟到选择结果的授权释放继续兜底。
- 原生选择器保持独立单例；取消立即结束逻辑请求，但不释放尚未关闭的原生选择器槽位，晚到选择结果不授权、不读取。
- 在授权、读取前后校验及每段至多 64 KiB 读取之间检查取消。快照准备不再修改身份表；提交时同步复核并更新身份/revision，已提交任务不被晚到取消吞掉成功响应。64 KiB 是本轮实现参数，不是冻结门槛。
- 清空、替换、卸载以及通信失败时尝试后台取消，释放授权与退出不排入读取队列。未提交的候选授权在异步操作收尾时关闭；无法强制中断系统调用，取消响应不代表底层调用已物理停止。
- 验证面板标识更新为 F-005a，其余操作入口和只读边界不变。未新增可重建缓存，未改变单文件授权或 Markdown 正文。
