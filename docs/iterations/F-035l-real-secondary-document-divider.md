## 功能说明

真实副区实验的相邻文档可通过分隔线调整高度。线宽 1 CSS px，垂直命中区 3 CSS px。上下方向键可等价调整；每次 8 px，触底时以 33 px 为下限。总高度、文档归属和草稿不因调整改变。

## 最小方案

在已有固定副区宿主中复用 F-034 相邻高度算法。鼠标拖动以按下时的有序文档与高度为基准，行归属变化、取消或失去捕获时结束。开始与提交调整时检查活动文档和组合输入。缩到最小时标题保留；展开后仍使用原文档的编辑状态。只接隔离真实副区，不引入原生动态窗口、正式展开或自动路由。

## 最小验收

- 用三篇临时 Markdown 验证 320 px 中两篇副区文档。真实 WK 读到 1 px 分隔线、3 px 命中区，键盘上/下移动后模型与实际高度一致。
- 在真实 WK 尝试鼠标拖动，核对只有相邻两篇高度变化。压至 33 px 时标题仍可聚焦，展开后原草稿可继续编辑和撤销。
- 关闭相邻文档后分隔线消失，剩余文档得到全部高度。普通窗口打开与退出回归；临时夹具字节不变。
