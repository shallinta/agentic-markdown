## 功能说明

验证重新选择同一个目录后，历史标签元数据能否定位该目录内仍为同一文件的当前条目。先验证目录来源和文件身份，再接入正式恢复流程。

## 最小方案

- 后端只接收本次已授权的根句柄及扫描代际。用持久名册证明当前根 ID，逐项核对实验记录中的对应根和当前可见扫描。历史路径只作为当前扫描的查找键。磁盘复核使用扫描已有的文件及目录证明，临时描述符立即关闭。
- 保留候选在原标签数组中的位置和当前目录条目句柄。移除、代际变化或中止会让旧候选失效。同路径已换文件、已隐藏或缺失的记录无法生成候选。保留尚未授权的记录，便于后续逐根核对。
- 本片仅验证内部候选。正式打开、标签模式和位置恢复、草稿处理、独立文件恢复及副区留后续。

## 最小验收

- 用两个同名根和合成文件验证退出重开后，只有明确重选的当前根及同身份文件可形成候选。测试覆盖部分授权、文件同路径替换、隐藏、移除和代际变化。
- 用正式包内 Bun 验证内部授权与候选链路，真实普通主窗回归打开目录中的 Markdown 和正常退出。
