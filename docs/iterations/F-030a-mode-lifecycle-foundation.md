## 本片最小技术方案

1. 控制器按 documentId 维护 `editing` / `reading` / `source` 和进入源码前的模式。新持久实例默认编辑；已有实例仅激活、保持模式；不引入窗口级统一模式或同文档双视图。
2. EditorState、原文、选区、撤销、revision、dirty 和保存快照属于文档，不随阅读视图卸载而丢失。阅读选择不覆盖编辑选区；切标签与模式分别管理视图生命周期，错误恢复不能清空原文或历史。
3. 右上角只有一个无文本图标 toggle，tooltip/可访问名称按目标为“切换为阅读模式”或“切换为编辑模式”；Tab 与回车/空格可操作，按钮与快捷键复用统一命令。源码状态隐藏 toggle，源码只保留 `⌘⇧M`；再次触发返回进入源码前的阅读/编辑，不新增菜单或命令面板入口。主区标签不添加模式文字。
4. 命令实时读取活动文档、IME composition、关闭/退出冻结及安全源码状态；候选期间不卸载编辑器。不能通过阅读中转绕过已隔离的编辑故障保护。
5. 当前可见块的原文范围与相对视口偏移作为本片最小锚点；编辑 LF 位置与原文 BOM/CRLF 坐标显式换算。同 revision 往返优先定位同块，失效再按邻近块、源码位置、比例降级。不将源码 offset 称为跨内容修改稳定身份，不宣称重启恢复；真正稳定块协议留 F-030/F-040 后续。
6. 阅读无修改正文命令，撤销/重做不生效；已有 dirty 内容仍可经既有保存链路保存，关闭/退出继续统一确认。回编辑后原有历史和选区仍可用，不因只读视图清 dirty。工具栏基础透明与焦点样式可接入，完整材质精修保留 F-068。
