# 产品功能手册

本手册用于记录 Agentic Markdown 当前实际可用的功能与操作方式，随每轮迭代维护；不把产品规划或已有草稿当作已交付能力。

范围与优先级见 [MVP 产品规格](mvp-product-spec.md)，实现、验证与人工验收证据见[迭代记录](iterations/README.md)。本手册不替代上述文档，也不另行定义产品需求。

### F-001：应用启动与窗口基本操作

| 操作 | 当前行为 |
| --- | --- |
| 启动应用 | 在已验证的 macOS 环境中打开本地构建的 Agentic Markdown，显示侧栏和正文区域；正文现由下述 F-003a 验证入口替代占位内容。 |
| 移动窗口 | 拖动窗口红黄绿按钮右侧或正文顶部的空白区域，可连续移动窗口，无需反复切换焦点。 |
| 调整布局 | 可调整窗口大小、拖动左右面板之间的分隔线；面板与分隔线延伸至窗口顶部。 |
| 显示或隐藏侧栏 | 按 `⌘B` 切换侧栏，再按一次恢复显示。 |
| 离线启动 | 已准备好的本地构建无需开发服务器，断网后退出并重新打开仍可显示外壳、使用 `⌘B` 切换侧栏。 |

- 面板布局不代表文件树或正式主副文档区域已经实现。
- 下述 F-003a 仅提供只读验证入口，尚未提供正式 Markdown 打开、阅读模式、编辑或保存流程；不能据外壳离线启动推断这些后续流程已离线可用。
- 当前保留临时图标；固定中文界面与 App 外观的本轮变更见下方已验收 F-007a。测试渠道的系统应用名称可能带 `-canary` 后缀。
- 本轮使用本地未签名构建，不包含正式分发、签名、公证或自动更新验收。

人工验收日期：2026-09-19。详细环境、验证结果与交互修复见 [F-001 迭代记录](iterations/F-001-app-shell.md)。

### F-003a：只读文档服务验证入口

已于 2026-09-20 通过人工验收。正文区显示“文档服务验证”；这不是正式阅读/编辑模式，F-003 整体也未完成。

| 操作 | 当前行为 |
| --- | --- |
| 选择 Markdown 文件 | 通过系统选择器选一个本地 `.md` 或 `.markdown` 文件，只读显示原文；Markdown 与 HTML 不渲染、不执行。取消或选择失败保留原显示。 |
| 核对身份与版本 | 文件名、`documentId` 与 `revision` 显示在原文上方。同一文件对象未变时重复读取保留身份；发现原地内容变化时版本增加。 |
| 重新读取 | 主动读取当前文件，不自动监听外部变化；文件被替换、删除或读取失败时提示，并保留明确标为旧快照的原内容。 |
| 清空 | 清除显示并释放只读授权；重新选择仍可恢复本次运行内已知文件对象的身份。 |

当前限制：

- 本轮验证入口仅接受有效 UTF-8、至多 1 MiB 的普通 Markdown 文件；超限失败，不截断。这不是最终产品容量承诺。
- 身份仅在本次运行内维护；不保证重命名、移动或重启后延续。编辑器若采用原子替换保存，需要重新选择文件。
- 受 Electrobun 1.18.1 选择器路径编码限制，含逗号的路径暂时安全拒绝，不把拆分出的路径片段用于读取。
- 页面耗时为本次请求等待时间，选择操作包含人在对话框中的停留时间，不作为性能基准。
- 2026-09-20 用户已确认基础交互、断网读取及外部修改后文件替换分支通过；原地修改递增版本分支有自动测试覆盖，未另记为人工操作通过。自动 UI 锁屏记录不追改为自动通过。

验收样本见 [F-003a-sample.md](iterations/fixtures/F-003a-sample.md)，方案、自动检查与人工验收步骤见 [F-003a 迭代记录](iterations/F-003a-document-read-service.md)。

### F-004a：单文件路径识别与只读授权

已于 2026-09-20 通过人工验收。本轮沿用 F-003a 的选择、重新读取和清空入口；只读原文、1 MiB、UTF-8、含逗号路径安全拒绝等限制不变。界面标识更新为 F-004a，新增“仅当前文件只读，不授权父目录或相邻文件”的权限说明。

| 操作或场景 | 本轮新增或强化行为 |
| --- | --- |
| 不同路径写法选择同一文件 | 按真实磁盘规则识别大小写和 Unicode 写法，实际指向同一文件时复用会话身份；真实不同的文件不合并，不修改磁盘文件名。 |
| 明确选择文件符号链接 | 只授权其解析到的单个 Markdown 文件，显示真实目标文件名；不会因此扫描或授权父目录、相邻文件。系统选择器可能先自行解析链接，实际校验以其返回入口为准。 |
| 入口或目标发生变化后重新读取 | 选择入口链接改向、目标或已记录的父目录被替换时拒绝旧授权，提示重新选择并保留明确标为旧快照的原文。 |
| 同目录新增或修改其他文件 | 不因此撤销当前文件授权，也不会自动获得其他文件的读取权限。 |
| 清空、切换文件或退出 | 延续上轮行为：清空、成功切换及退出撤销对应读取授权；取消或选择失败不丢弃原显示。 |

本轮仍不支持目录根授权、资产读取、写入、重命名移动跟踪或跨重启身份恢复。不同规范路径的硬链接暂不合并；只读描述符与前后检查不构成抵御所有瞬时文件替换竞态的保证。

自动验证已通过，用户已明确确认本轮验收通过。窗口内符号链接选择未完成自动验证的历史记录保持不变；自动操作中曾出现选择器长时间停留后取消导致通信失败的现象，原因尚未确认，不因人工验收通过而宣称已修复。完整方案、测试结果与验收记录见 [F-004a 迭代记录](iterations/F-004a-single-file-authorization.md)。

### F-006a：现有操作的统一命令与键盘入口

已于 2026-09-20 通过人工验收。正文只读验证区仍显示 F-004a 标识；本轮新增或统一其命令入口，不新增阅读、编辑或保存模式。

| 操作 | 入口与使用方式 |
| --- | --- |
| 选择 Markdown 文件 | 按 `⌘O`，或使用原按钮、文件菜单、命令面板，进入系统选择器；仍只读打开单个文件。 |
| 重新读取当前文件 | 使用原按钮、文件菜单或命令面板；本轮无独立快捷键。 |
| 清空当前验证内容 | 使用原按钮、文件菜单或命令面板；仅清除验证内容，不删除磁盘文件，本轮无独立快捷键。 |
| 切换侧栏 | 按 `⌘B`，或使用查看菜单、命令面板。 |
| 打开命令面板 | 按 `⌘⇧P`，或使用查看菜单；搜索命令名称，方向键选择，Enter 执行，Escape 关闭并合理恢复焦点。 |

按钮、菜单和命令面板共享可用状态，执行前也会校验：正在选择或读取时不能重复打开或重新读取；无快照时不能重新读取；有快照或忙碌时可以清空。禁用命令不会执行。清空不承诺关闭已弹出的系统选择器，过期结果不会恢复正文。

本轮产品命令使用中文名称；设置中的强调色、更新、缩放等其他业务仍保留为继承草稿，不代表完整 F-006 已验收。当前界面中文化与 App 外观已由下述 F-007a 单独验收。`⌘O`、`⌘B`、`⌘⇧P` 由 macOS 原生菜单触发，避免重复执行。

使用示例：用 `⌘O` 打开文件 → `⌘⇧P` 搜索“重新读取”并 Enter → 执行“清空”并核对重新读取不可用 → 用 `⌘B` 切换侧栏 → Escape 关闭面板并确认焦点。用户已明确确认本轮验收通过。此前真实窗口自动验证覆盖部分键盘、菜单和面板路径；搜索自动操作使用设置输入值，不作为中文输入法组合输入验证。完整方案与证据见 [F-006a 迭代记录](iterations/F-006a-command-entrypoints.md)。

### F-007a：现有界面简体中文与 App 外观

已于 2026-09-21 通过人工验收；沿用现有只读文档验证入口，不新增正式阅读、编辑或源码模式。

| 操作 | 当前实现与使用方式 |
| --- | --- |
| 查看当前界面 | App 自有菜单、侧栏、设置及命令面板固定简体中文；移除语言选择，历史英文偏好不再使界面回退英文。macOS 文件选择器仍遵循系统语言。 |
| 更改外观 | 在设置中选择浅色、深色或跟随系统；有效已有偏好保留，无偏好或无效值默认跟随系统。 |
| 退出再打开 | 外观偏好在本机保存，重启后继续应用；不保存或改写 Markdown 正文。 |
| 文档打开时切换外观 | 只改变外观，不重新读取文档；内容、身份、版本与滚动位置保持。 |
| 跟随系统 | 启动前解析外观，运行中跟随系统变化；系统读取或通知失败时保留最近有效外观。 |

开发阶段已完成真实窗口中文界面、浅深色截图、文档身份保持，以及退出重启后深色保留的检查；检查结束已恢复原来的跟随系统设置。该阶段未测量首帧闪烁和滚动保持的证据边界不变；随后用户对包含这些项目的人工验收清单明确确认通过，不追加虚构的自动测量结果。

本轮人工验收清单：核对中文界面与无语言选择 → 切换浅色、深色、跟随系统 → 打开较长文档并滚动后切换外观 → 退出重启核对偏好 → 切换 macOS 外观验证跟随系统，并观察启动是否闪烁。用户已回复“验收通过”。

强调色、更新等附带功能仍为继承草稿；第三方颜色选择器的英文辅助功能标签保留，不宣称完整 VoiceOver 验收。未来编辑/源码高亮及独立阅读主题尚未接入，父 F-007 未完成。完整方案和验证证据见 [F-007a 迭代记录](iterations/F-007a-chinese-shell-theme.md)。

## 维护规则

- 每轮涉及功能新增或变更时，同步更新本手册的操作方式、可观察行为和限制，并链接对应迭代记录。
- 已实现但尚未人工验收的行为放在“待验收功能”中；变更已有功能时，明确指出受影响的已验收行为与待验收差异，不提前覆盖为已交付结论。
- 用户确认通过后，将本轮行为更新到“已验收功能”，补充验收日期，并清理对应待验收条目。继承草稿不得因入口可见而自动转为已验收。
- 行为调整或功能移除时，更新当前说明，并在下方保留简短变更记录；实现方案、命令输出和测试细节仍留在原迭代文档中。
