## 1. 功能说明

- 编辑模式支持 CommonMark 有序、无序列表及嵌套层级的基础呈现。无序标记非激活时显示圆点，光标或选区进入该行时恢复原始 `-` / `+` / `*`，便于精确编辑；有序列表保留原编号和分隔符，不自动重排编号。
- 列表行按原文缩进呈现层级，长行软换行尽量与列表正文对齐；不改写用户原有空格、Tab、换行或编号。语法树未识别为列表的内容保留原样。
- 挂起缩进只改善当前源码行的视觉折行；物理续行保留各自原有缩进，无缩进的 lazy continuation（省略缩进的续行）不自动补齐。复杂引用/多段落不在本片统一重排。
- 源码模式继续为纯代码编辑器，不出现圆点替换或列表排版；原文、选区、撤销历史与保存仍共享。
- 不提供回车续写/退出列表、Tab 结构化缩进、任务复选框、GFM 扩展、自动编号修正、代码围栏样式或折叠。它们由 F-043 / F-045 / F-048 等后续功能承接，父 F-012 / F-042 不因此完成。

## 2. 最小技术方案

- 复用现有 CommonMark/Lezer 列表节点和视口装饰，使用固定文本/CSS 的无序标记呈现，不解释 Markdown HTML、不引入网络资源或第二份可编辑正文。
- 复用既有光标/选区显隐及 IME 冻结/映射；列表装饰只在编辑呈现扩展中注册。按视口构建，不在光标移动时主动全量解析或遍历全部列表内容。
- 保留原文缩进，行级样式辅助软换行对齐；代码/HTML 区域不误套列表装饰，新增装饰不得改变正常保存和原文复制语义。
- OBL-068 本片仅落实列表外观，后续其他编辑扩展外观仍保留在同一开放责任中，不凭单个列表切片关闭全部外观任务。OBL-012 完整调度/版本隔离、OBL-020 全局缓存预算、OBL-041 完整格式命令继续由 F-012 后续切片承接；当前视口有界性与基本键盘仍需验证。

## 3. 继承约束检查

- F-002：显示装饰不回写；原编号、缩进、BOM 和混合换行保真，直接复制原始 Markdown，核心离线。
- 中文与外观：中文正文及 emoji 不损坏；浅深/系统主题使用应用 token，主题切换不重解析；真实中文候选及排版感受交人工。
- 命令与键盘：不新增格式命令；现有编辑/源码快捷键、保存、撤销及选区行为继续有效，方向键可进入原标记；不做鼠标专用写操作。
- 安全与日志：标记只使用固定文本/CSS，不创建可执行 HTML/链接/远程资源，不输出正文或路径日志；只读、保存及关闭确认保持。

## 4. 最小 happy path

1. 打开混合 `-` / `+` / `*`、有序列表及嵌套样本，非激活显示圆点和正确层级，有序保留原数字/分隔符；原文件不变。
2. 光标/选区进入退出列表行，原标记可编辑；复制跨行选区仍为原始 Markdown；切到源码不再替换或列表排版。
3. 编辑中文及 emoji，撤销/重做/保存；候选期间稳定；只读不能写入，原文缩进与未触及 BOM/混合换行保真。
4. 围栏/缩进代码、HTML、转义和非列表伪语法保持原样；浅深主题及长行软换行、视口滚动人工检查。
5. 定向/全量测试、类型/Lint/格式、文档承接检查与独立复核；递增 alpha 打包核对产物。实现与自动验证不代替人工验收。
