## 功能说明

为会话恢复补一份目录选择回执。原生选择器确实加入新目录后，窗口能核对本次新增的根句柄及扫描代际。取消选择、选中已覆盖目录或请求失效时，不产生新增回执。

## 最小方案

- 在现有本地目录服务的提交点返回本次新增根的句柄和代际。已被覆盖、取消及其他操作沿用原结果。不通过路径或比较前后目录列表猜测选择结果。
- 窗口端复用已有的目录操作队列与扫描刷新，只接受请求、结果和最新根身份一致的回执。普通加入目录的可见行为不变。回执不等同于某条历史根已匹配，也不允许读取文件；下一片仍须核对持久根 ID 和真实文件身份。
- 不恢复任何标签，不改目录授权、扫描、已授权目录状态或既有存储。

## 最小验收

- 包内使用真实工作区及合成目录核对新增、取消、已覆盖和代际失效，并确认只有目录选择可返回新增回执。
- 同包普通 WK 通过真实原生选择器取消、加入及再次选择已加入目录，文件树及正常打开行为保持，不自动恢复标签。夹具字节不变。
