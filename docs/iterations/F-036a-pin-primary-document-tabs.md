# F-036a 固定主区持久标签

> 状态：alpha.270 非离线范围经受托代验通过，独立最终复核完成。基于 F-011 的现有主区持久标签。

## 功能说明

主区当前文档可固定或取消固定。固定标签在左侧分组，组内按原标签相对顺序显示。标签仍可激活和显式关闭。当前窗口内生效，排序、临时预览、副区及重启恢复按对应功能承接。

## 最小方案

- 用现有文档身份记录固定状态。仅调整标签条显示顺序，保留文件树、底层标签顺序、文档内容和激活记录。关闭或替换标签后移除已失效的固定状态。
- 在文档操作区提供当前标签的固定或取消固定按钮，通过统一命令执行。命令面板可键盘操作，使用既有忙碌、冻结和组合输入边界。标签本身仍显示文件名和关闭按钮。
- 显式关闭活跃标签继续按可见标签顺序选后继或前一项，未保存确认照旧。本片没有新增批量关闭，显式清空工作区仍沿用已有语义。

## 最小验收

- 打开三个合成文件，固定后两个中的任一个，确认它进入左侧组，原标签与文件树顺序可区分。切换并取消固定，选区、未保存与模式保持。
- 通过命令面板操作一次，显式关闭固定标签，包括未保存时取消关闭及恢复后关闭。重新打开原文件时视为新标签。

## 继承约束检查

- F-002 固定状态只存在当前本地窗口，最终离线留人工。
- 中文与外观沿用现有按钮和标签主题，固定分组在两种外观可辨。
- 命令与键盘接统一命令及命令面板，按活动标签判断可用性。
- 安全与日志不访问文件、授权或个人路径，关闭保护照旧。
