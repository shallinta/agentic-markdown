## 1. 功能说明

在当前编辑、正常源码和安全源码消费者中，复核日文、韩文组合输入的正文保真、候选期间命令保护及文档级撤销历史。沿用原输入机制，优先增加针对性验证；仅在发现本片问题时修复，不引入自动补全、列表续写、系统输入法设置或第三方输入法。

自动测试使用明确标注的合成事务，覆盖日文假名到汉字、韩文组合到音节、取消输入、中文与 emoji、BOM/混合换行及模式往返。它不能证明 macOS 真实 IME 候选窗口或组合事件次序；真实日/韩候选、确认/取消与连续输入必须留人工验收，不假定系统已安装或擅自启用输入法。

OBL-064 本片只覆盖当前三种编辑呈现状态的回归；后续补全、格式操作、新装饰消费者仍随对应切片验证，整项保持开放。
