# F-037ad 停止滚动后保存主区位置

> 状态：alpha.354 普通窗口代验、包内全量及独立复核通过。

## 功能说明

在主区已保存的目录文档中主动滚动并停下后，当前位置可写入会话检查点。用户无需切换标签即可在下次重新授权时回到该处。

## 最小方案

- 复用普通编辑视图的滚轮、键盘滚动意图和已有视口测量。确认用户输入产生位移后，等连续滚动安静约 250 毫秒再测量，复用已有检查点调度和授权校验。
- 只有当前文档实例、有效视图及合格的已保存标签组能写入。自动恢复与布局移动不触发新的写入。切换或关闭视图时，已有的标签切换与关闭流程仍负责各自的检查点。

## 最小验收

- 普通窗口只打开一篇已授权长文，滚动到后段后等待写入，不切换标签。正常退出、重启并重新授权，核对原位置及正文原字节。
- 定向验证连续滚动合并、零位移、自动恢复、视图失效和未保存状态。滚动条实体拖动及辅助技术沿用集中验收清单。
