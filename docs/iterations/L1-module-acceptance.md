## 数据与安全边界

- 默认 App 数据目录为 `~/.agentic-markdown`，也可由 `AGENTIC_MARKDOWN_HOME` 指定。日志为 `logs/app.log` / `app.previous.log`，各最多 256 KiB，只保留固定事件和允许的匿名数字；末尾事件 best-effort，不上传。renderer 固定事件只到 console，框架/系统内部输出另计。
- `settings` 内 locale/window/updates 文件分别存 `{version:1,data}`，`.bak` 是上一版精确原字节。损坏或未来版本读取默认且拒绝覆盖，保留源与备份；目前不提供自动修复/降级 UI。如需故障演练，使用独立临时 App 数据目录，而非直接改个人配置。
- 当前只读面板不存在不可信 HTML 执行入口。Electrobun 1.18.1 原生下载绕过导航规则的已知路径，必须由 F-020 在富内容接入前解决；本次不将其隐藏或转为“已完成”。
