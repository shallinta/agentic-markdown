# F-004a：单文件路径识别与只读授权

> 状态：已验收；2026-09-20 用户确认范围，实现与自动验证完成后明确确认人工验收通过
> 父功能：F-004 路径规范化、授权与文件系统语义
> 本轮前置依赖：已验收的 F-003a；遵守 F-002

## 1. 功能说明

### 1.1 目标与范围

继续使用文档服务验证界面，让用户明确选择的单个 Markdown 文件得到准确识别和受限读取授权。

- 使用真实文件系统的规范路径识别同一文件；不同大小写或 Unicode 写法实际指向同一文件时复用会话文档身份，真实不同的文件不合并。不对文件名做统一小写或 Unicode 改名，显示真实目标文件名。
- 系统选择器明确选中的文件（包括明确选中的文件符号链接目标）只获得单文件只读授权；不自动授权父目录、相邻文件、目录扫描或写入。不存在从文档内容自动取得新授权的入口。
- 保存选择入口与真实目标的关联。选择成功后，若链接转向其他目标、目标或父目录被替换、路径失效，旧凭据拒绝继续读取，显示旧快照并要求重新选择；绝不自动跟随新目标。
- 失效、循环链接和非普通 Markdown 文件安全失败。清空、成功切换文件和退出仍撤销对应授权。
- 不仅靠文件 ID 合并文档；本轮保持现有硬链接不同规范路径分别管理的边界，不由本切片定义未来完整硬链接产品策略。

### 1.2 非本轮范围

不实现目录扫描/递归、文件树、目录根授权、资产读取、写入、重命名移动跟踪、跨重启身份恢复、平台沙箱持久授权或通用文件系统抽象。F-003a 的 1 MiB、严格 UTF-8 和含逗号路径安全拒绝等临时边界保持不变。父目录链的内部校验不构成目录内容列举权限。

F-004a 通过后仅记为一个已验收切片，F-004 父功能仍待后续目录等范围，不能视为完整功能完成。

## 2. 本轮最小技术方案

- 从现有 Bun 文档服务抽出单文件路径/授权校验模块；RPC 仍只接收不透明凭据，不新增任意路径读取接口，也不改变正文格式。
- 逐路径分量调用原生 `realpath` 处理真实卷语义，在解析链接之后处理 `..`；不硬编码卷是否大小写敏感，不扫描整个目录或在用户目录写探针。仅检查本次选择的入口、目标与父目录链。
- 在打开描述符前采集目标与父目录身份；打开后及每次读取前后再次复核。使用设备号、文件 ID、出生时间等精确信号检测对象替换，描述符只读且最终分量禁止跟随符号链接；目录链按路径分量检查，不能用字符串前缀代替权限判断。
- 保留原始选择路径以重新解析入口，不提前以纯字符串方式折叠 symlink 与 `..`。真实目标和原入口的规范父目录链均校验类型与身份；不比较目录修改时间，防止同目录其他文件变动导致误撤销。
- 规范路径与文件对象信号共同定位会话身份；相同内容不等于同一文件。目录校验失败只撤销本次授权，不执行任何文件修复或写入。
- 与上轮相同，检查不能保证抵御所有敌对进程的瞬时 ABA 替换；只读描述符固定实际读取对象，前后校验拒绝可观察的不一致。不宣传为所有平台通用的无竞态安全证明。

### 2.1 选型依据

2026-09-20 在默认 APFS 和专门新建的 64 MiB 大小写敏感 APFS 临时镜像中实测 Bun `realpath`：默认卷将 `case.md` 解析为已有的 `Case.md`；敏感卷上二者可分别存在且文件 ID 不同；两种卷都将 NFC/NFD 写法解析到同一目标；符号链接解析为目标路径，硬链接保留各自规范路径。由此采用原生解析而非字符串归一化。临时镜像已卸载并清理，不修改用户卷。

## 3. 最小 happy path 与边界验证

1. 选取名称含大小写与 Unicode 字符的测试 Markdown，确认原文、真实文件名正常显示。
2. 在卷允许的情况下，通过不同大小写、NFC/NFD 或明确选择的符号链接入口再次选取同一文件，确认 `documentId` 和未变化的 `revision` 相同；不修改磁盘名称。
3. 选择另一真实文件，确认身份不同；在大小写敏感 APFS 样本中验证 `Case.md` 与 `case.md` 不合并。
4. 授权后将选择入口的链接改向另一文件，重新读取应失败并保留明确标注的旧快照；重新选择才取得新目标授权。系统选择器若自行解析链接为目标路径，界面用例只覆盖它实际返回的入口，链接改向由后台定向测试覆盖。
5. 使用临时样本覆盖父目录被替换/变为 symlink、链接循环/失效、无效/撤销凭据，以及同目录新增文件不应误撤销。回归 F-003a 的取消、原地编辑、替换、清空、只读不回写及离线读取。

相关自动检查包括针对性测试、格式、类型、lint 和未签名构建。记录校验增量开销，不设置性能数值门禁；不跑或验收无关 starter 功能。

## 4. 实现与验收记录

### 4.1 实际改动

- 抽出 `path-authorization.ts`，保存原始入口、规范目标、经过的目录对象与只读描述符；读取前后复核，失败撤销凭据。
- 使用 BigInt 文件系统信号，避免时间及文件对象标识精度丢失；保留既有串行读取、会话身份和内容版本机制。
