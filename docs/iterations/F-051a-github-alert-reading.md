### 原子CalloutExtension的候选契约

1. 单一第一方模块同时拥有五型字面量集合、公开Root适配与元数据读取校验；本片固定canonical profile加版本，Lezer profile不动。这是整体扩展的canonical/阅读消费者，不是用户可配置插件系统或完整三模式实现。
2. 仅检查root直接blockquote；其首child必须为paragraph，首inline必须为有可靠position的text；quote起始行、paragraph起始行、首text起始行相同，paragraph与首text起始offset相同。链接定义若在前，首child为definition或首段行号后移，均不认Alert；不跳过定义、空前置段、HTML或其他结构去找标记。
3. raw从首text的真实start开始，必须精确为五个大写`[!TYPE]`之一；紧邻后一个字符只能为LF、CR、CRLF的首字符，或文档结束。候选本片不接受标记后空白/同线正文/自定义标题/`+`/`-`，不忽略大小写。开括号转义、实体生成、inline code、链接/图片/reference节点均不升级。只核固定最长marker长度加至多两个换行字符，不为判别扫描或复制整条长行。
4. 同时核首text.value精确以marker后接规范化换行开头，或恰好等于marker。候选预期mdast规范化EOL为`\n`，**必须由隔离矩阵验证**，不由raw偏移推算value索引。raw/value任一不符合即保留普通引用；有`[!NOTE]: url`定义并把marker解析为链接等情况不强改AST。
5. 元数据最小字段为固定type、marker原raw起止与已验证首text前缀字符数；保留原type/children/value/position。marker范围只包`[!TYPE]`，不含`>`/EOL。不存在的position不补造。metadata读取时核shape、整数、范围及对应首text前缀，不把任意`node.data`当可信样式或HTML；canonical配置fencing仍是必要条件。
6. 阅读projection只对这一个首text输出`value.slice(已核前缀长度)`，其余inline/后续块按原顺序走现有render。若首paragraph在移除marker后无内容则仅不输出这个空展示段；不删除canonical节点或改其他range。正文在下一个paragraph、table、list或代码块时照旧消费。若移除marker后整个quote无可见正文，本候选退为普通引用，保留空Alert字面量；是否可见以明确子节点存在/非空文字规则在实验中列出，不能扫描定义URL当正文。
7. lazy续行只要公开AST仍归同quote且满足首行条件，正文按原AST保留，不额外把quote外段吸入。Alert正文中的普通嵌套quote仍普通quote，其`[!TYPE]`不升级；不出现嵌套Callout。
8. 适配仅线性检查root直接块，并对工作数设与现有呈现一致的有界保护；不递归逐字全文扫描、不复制整树、不在React中重复parse。超过预算时沿既有canonical失败/安全回退通道，不发布部分已标注的结果。整体性能仍须验证，不以有限样本证明无上限复杂度。
