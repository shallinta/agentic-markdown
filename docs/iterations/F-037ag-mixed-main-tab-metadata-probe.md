## 功能说明

验证一份会话记录能保留交错打开的目录和独立文件标签，包括原顺序、活动项、固定状态、模式和已记录的位置。旧目录记录可原样读取，也可在明确写入新版时转换。

## 最小方案

- 在隔离槽验证带来源类型的 v3。目录行沿用根 ID 与相对路径，独立行保存本次来源证明提供的规范路径和文件身份信号。两类行复用现有位置字段和原顺序。跨来源是否指向同一文档由后续接入时按实际授权核对。
- 复用已有会话格式和设置存储。读取 v1、v2 时在内存中转换，单纯读取不写盘。显式写入 v3 时先核对已有格式，再保留旧文件备份。实验只用临时目录和单独文件名，正式会话检查点仍由现有入口管理。
- 实验采用单写进程和顺序交接。已存在的异常或较新记录拒绝覆盖。接入正式检查点前需要验证原字节终检及旧写入方的保护。

## 最小验收

- 隔离进程读取旧目录记录，确认模式、位置与活动项，读取前后原字节一致。另一个进程写入混合记录，重开读回精确结构，核对原字节备份。
- 验证较新版本、坏记录、无效来源、重复条目和失效写入。真实 WK 回归普通目录会话及独立打开，分别记录后台实验和窗口行为。
