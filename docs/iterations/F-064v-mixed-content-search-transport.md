## 范围

把有界混合查询和独立文件定位准备接入现有窗口 RPC。普通窗口控件在下一片接入。原单目录、多目录查询及目录定位请求保持兼容。

## 最小实现

1. 混合查询发送有序的目录根与代数、独立文件句柄、已打开句柄、查询和筛选。响应回传相同的两个范围列表，正文证据与打开文档映射仍受 16 篇、64 KiB 等限额。无目录时需有独立文件。
2. 独立定位准备通过明确的请求标签区分。响应只允许按精确版本复用，或返回摘要和句柄都吻合的保留快照。后者仍使用原文件授权。
3. 新旧操作共用一条活动请求通道及取消、窗口停用和收尾。释放未采用快照的逻辑只适用于目录定位临时取得的新授权。

## 最小验收

- 验证混合查询回传范围与请求一致，畸形、超限和跨类型结果拒绝。
- 验证两类定位、取消、等待收尾和迟到回执。取消或错误形状的独立定位结果不释放原授权。
- 使用实际工作区经传输复跑混合查询和保留定位。真实 WK 窗口回归原查询与定位。

## 继承约束检查

- F-002 沿用本地授权。离线留最终人工。
- 中文与外观沿用已验收界面。
- 命令与键盘沿用现有窗口入口。
- 安全与日志方面，传输使用句柄与代数核对，查询不新增路径和正文日志。

- macOS arm64 unsigned canary `0.1.0-alpha.208`，包标识 `2yvur7psf7dnx`。包内 Bun 1.4.0 和正式原生资源复跑协议、分发与快照，26 项通过、8 项条件跳过、200 条断言。实际工作区混合传输单独复跑，39 条断言，覆盖目录、保留独立文件和定位回执。
