# F-064o 窗口内多文件夹正文搜索

## 功能

在现有正文搜索面板增加「选中的文件夹」和「所有已加入的文件夹」两种范围，默认使用选中的文件夹。显式 `root:` 优先指定一个根，清空后回到当前范围选项。无效或歧义根给出提示。多根范围覆盖当前窗口已加入的顶层文件夹，顶层独立文件另行承接。

整次查询最多 16 个根，筛选前合计最多 16 篇，筛选后的正文合计最多 64 KiB。任一根扫描未完成、文件页未齐、超限或在查询中失效，都不会显示部分结果。路径条件相对每篇文件所属的根。结果附所属文件夹及相对路径，同名根用完整显示路径区分。

## 最小实现

1. 一次捕获有序根集合和对应的文件页。按完整集合核对边界，然后计算筛选后的预期条目，记录每篇所属根和扫描代。文件名和路径选择器从有效范围生成；根选择器仍可缩到一个目录。
2. 多根范围走 `query-roots`，显式或隐式单根沿用 `query`。回包须匹配本次预期覆盖和打开文档配对。查询和定位期间持续核对根集合、扫描代、文件页及缓冲区版本。切换范围或筛选立即废弃旧结果。
3. 点击命中时使用该条目的根句柄和扫描代准备打开，沿用已有版本核对、未保存正文保留、选区和焦点规则。

## 最小验收

- 在真实窗口加入两个同名根，正文查询覆盖两边，结果标签可区分路径，分别点击打开正确文档。添加 `root:` 后缩到一个根，清空后恢复多根。
- 验证其中一篇的未保存正文覆盖、切换范围淘汰旧结果以及正常退出。自动测试另核对根集合变化、未完成扫描、重复路径和筛选前上限。

## 继承约束检查

- F-002 沿用本地授权和搜索。离线留最终人工。
- 中文与外观沿用中文状态和原有主题。
- 命令与键盘沿用正文搜索入口和结果按钮。
- 安全与日志方面，显示路径仅用于匹配、校验预期覆盖和区分结果。授权由 Bun 核对根句柄、扫描代和条目，日志不记录正文或路径。

## 实际验收

- macOS arm64 unsigned canary `0.1.0-alpha.202`，包标识 `1bcyk20lu3vsw`。隔离真实 WK 窗口加入两个名为「笔记」的根。默认显示「选中的文件夹」，切换「所有已加入的文件夹」后覆盖两篇。两个「内容.md」结果分别标明甲组与乙组完整根路径。依次打开命中，分别定位到对应文件的 `[5,10)`。
- 在乙组插入未保存词，查询覆盖两篇且仅乙组内存命中 `[12,17)`。定位后正文仍未保存。撤销后恢复已保存状态，旧命中随即失效。显式 `root:` 在多根模式下缩到甲组，清空恢复两根，再切回单根使旧结果消失。正常退出，两份夹具 SHA 不变，查询临时目录为空。
- 规格与规范独立复核无阻断。源码定向 21 项、包内 Bun 1.4.0 配合原生资源 21 项通过，包测另有 6 项条件外层跳过，由隔离子进程执行。根顺序与节点页变化、未完成扫描和筛选前上限通过定向测试覆盖。真实窗口使用浅色外观，深色、自然 IME 和最终离线未复验。
- 源码全量 1862 项通过、8 项条件跳过、0 项失败，共 38,923 断言。既有 FINAL-ISSUE-002 本次通过，保留历史记录。类型、Lint、文档、义务登记、锁文件和差异检查通过。
