## 功能说明

验证已保存主区标签的位置记录能随隔离会话跨进程写入和读回。R-15 的正式采集、位置匹配、关闭清理与窗口恢复留后续切片。

## 最小方案

- 沿用会话标签的目录身份、相对路径和文件指纹。隔离格式为每篇标签增加可选的版本化位置，使用固定长度的合成块摘要、同摘要块的出现序号和相对视口偏移。
- 位置记录不保存正文、绝对路径、运行期授权或编辑器对象。生产会话检查点继续按现行格式读写。
- 后续通过实际解析验证锚点生成、正文变化时的邻近块及回退策略，再确定正式记录与窗口恢复方案。

## 最小验收

- 用两个进程写入和读回一组有位置与无位置的标签，检查偏移、标签顺序与活动项。畸形和未来格式保持原字节。核对正式会话文件未变。
- 用同包普通窗口回归重新授权后恢复目录标签及正常退出。
