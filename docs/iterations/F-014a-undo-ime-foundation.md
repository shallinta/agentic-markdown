## 1. 功能说明

1. 每篇打开的文档使用独立撤销/重做历史。标签切换、保存和主题切换不清空历史，也不能撤销另一篇文档的操作。
2. 保存不成为清空历史的边界：保存后撤销可回到保存前内容，并重新标记未保存；重做到磁盘基线时清除未保存标记。保存失败或结果未确认时沿用现有保守状态，不能仅因文本相等误报已保存。
3. 无可撤销/重做步骤时命令禁用；撤销后再输入会按编辑器规则形成新的历史分支，旧重做分支不再可用。关闭标签后不保留历史；用户明确批准重新读取时，以磁盘内容建立新编辑状态，不恢复旧历史。
4. 中文输入候选尚未确认期间，不由 App 强行撤销、保存半成品或销毁编辑视图；确认/取消由输入法与编辑器正常完成，不吞候选选择按键。候选确认后的撤销不暴露逐个拼音预编辑状态、不串文档；具体历史分组依锁定编辑器的实际行为验证，不强制每个字符一条记录。
5. 编辑菜单与命令面板能作用于明确的当前文档；其他输入控件获得焦点时，普通撤销不得误改正文。打开命令面板后需保留其显式文档命令目标，执行时再核对文档和输入状态。

本轮不新增即时排版、正式编辑/源码模式、跨区移动、Markdown 自动配对或补全、自动保存、历史持久化。日文/韩文真实输入法，以及正式模式、装饰和补全消费者的完整 CJK 联动，留 F-014 后续切片；不得用粘贴中文或合成事件代替真实输入法验收。

## 3. 最小 happy path 与必要边界

1. 打开 A/B，分别编辑；在 A 撤销/重做后 B 内容及历史不变，切换回来选区和历史保持。菜单、命令面板和快捷键每次只执行一步，空历史禁用。
2. A 编辑后保存，再撤销为未保存，重做到已保存基线；继续输入后旧重做分支不可用。用含 BOM、CRLF/LF、孤立 CR 的样本确认撤销/重做和写回不发生无关归一化。
3. 使用 macOS 真实中文输入法，输入拼音、选择候选、确认与取消，测试插入及替换选区。确认前尝试撤销/保存/切标签/关闭，App 不主动打断组合输入、不误保存半成品或丢失正文；系统/输入法因菜单焦点自然提交或取消时，按平台实际行为记录，不承诺候选窗口绝不关闭。确认后再执行应正常。自动测试覆盖状态规则，真实候选交互仍由窗口实测及用户验收确认。
4. 验证普通非文档输入框的 `⌘Z` 不撤销正文；放弃确认期间不允许编辑。保存失败/未确认时撤销不清掉保守未保存状态；关闭重开或批准重读后旧历史不恢复。
5. 运行受影响测试、全量测试、类型、Lint、格式、文档/承接检查；代码打包前递增 alpha（当前 alpha.10，下一包 alpha.11），核对产物并交付人工验收。系统没有所需输入法时记录缺口，不自行更改用户输入源设置。

## 6. 人工验收步骤

使用 `0.1.0-alpha.12`，运行 `bun scripts/create-f014-fixtures.ts` 获取新的临时样本目录；只使用这些一次性样本，手动保存会真实写盘。

2. 保存 01 后撤销，确认出现未保存标记；重做到保存内容，确认恢复已保存。切换标签和浅深外观后，确认历史、选区仍在。命令面板输入搜索文字再 `⌘Z`，确认只影响搜索框、不误改正文。
3. 手动切换自己的中文输入法，在正文输入拼音、选择候选并确认；再测试 Escape 取消、选中文本后以候选替换。确认后的撤销/重做不出现逐个拼音预编辑状态，也不影响另一篇文档。
4. 候选尚未确认时尝试 `⌘Z`、`⌘S`、切标签和关闭，确认 App 不主动丢弃候选中的正文、保存半成品或误改其他文档。菜单焦点导致输入法自然提交/取消时记录实际表现，不要求系统候选窗口始终保持。
5. 打开 `03-mixed.markdown`，在末尾局部编辑并撤销/重做，检查诊断中的 BOM、原有 LF/CRLF、孤立 CR 与末尾属性未无故归一化；保存后重新读取复核。明确批准重新读取或关闭重开后，旧历史不恢复。
6. 有未保存内容时触发关闭确认，取消后内容和历史保留；确认期间不允许正文修改。保存失败或结果未确认时不得仅因撤销回旧基线而显示已保存（可结合 F-015a 一次性冲突样本复核）。
