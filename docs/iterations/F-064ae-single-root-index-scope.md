## 范围

给当前工作区中一个已授权、扫描完整的目录建立索引范围键与当次校验凭据。此片核对目录身份和扫描状态，正文快照与缓存写入留给后续。

## 最小实现

1. 在 Bun 内复用现有根捕获与搜索任务槽，按根句柄和扫描代获取完整根，保留现有最多 16 篇的入口约束。
2. 对索引范围版本、规范路径、根目录文件身份及隐藏规则的有序数据求 SHA-256。普通文件修改、重扫或重新加入同一目录可保持范围键，扫描代和句柄只用于即时校验。
3. 返回前核对目录及祖先身份。凭据提供同步的当前状态检查和重新核对磁盘身份的方法。撤权、换代、取消、目录或祖先替换均拒绝旧凭据。后续调用方须重新核对，范围键自身无法授权文件访问。

## 最小验收

- 比对同一目录重扫、重新加入的范围键。更换根目录、改变隐藏规则后键应变化。
- 验证非完整根、过期扫描代、目录替换与取消。确认凭据只给出范围键和校验能力，运行期间不读取正文、不创建索引缓存。
- 包内复跑，真实 WK 回归原搜索、定位和退出。

## 继承约束检查

- F-002 沿用现有本地授权，离线留最终人工。
- 中文与外观沿用现有搜索面板。
- 命令与键盘沿用现有搜索入口。
- 安全与日志方面，范围键留在 Bun 内部，无路径或正文日志。

## 验收结果

- macOS arm64 unsigned canary `0.1.0-alpha.218`，包标识 `1zndwwc623qa5`。包内 Bun 1.4.0 与正式原生资源复跑范围及既有搜索快照，9 项通过、11 项条件跳过。隔离范围子场景 3 项、50 条断言通过，数据目录为空。
- 同一物理目录编辑正文、重扫及重新加入后范围键相同。改变隐藏策略或在原路径更换物理目录后范围键不同。扫描未完成、过期扫描代、撤销、取消、并发和超过 16 篇均按边界处理。祖先被换成符号链接后旧凭据失效，恢复原路径也无法复活旧凭据。夹具的无效 UTF-8 和超出正文预算文件未改动，不影响范围身份的元数据核对。
- 真实 WK 回归一篇两处命中和第二处 `[19, 23)` 定位。夹具 SHA 不变，窗口 App 数据未创建索引槽，⌘Q 后启动器退出 0，窗口临时目录为空。
- 源码全量 1903 项通过、15 项条件跳过、1 项失败，39367 条断言。失败仍为已登记的 FINAL-ISSUE-002 长空白超时。首轮静态检查发现 TS lib 未覆盖 `Array.at`，另一次发现测试传递了未绑定的方法，分别改为下标和方法包装后复跑通过。类型、Lint、文档、锁文件及差异检查通过。
