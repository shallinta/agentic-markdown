## 功能说明

正文搜索选择「当前窗口」并输入文件名或路径条件时，可先从多个目录和独立文件中筛选，再读取匹配正文。扩大的是筛选前可检查的条目范围。

## 最小方案

1. 现有窗口直接查询请求正文片段并带有文件名或路径条件时，允许在一个合计 256 条的预算内核对已扫描目录条目和独立文件。预算计入传入的独立文件句柄。保留完整的目录顺序、代数、扫描快照和授权校验。
2. 按原规则识别目录已经覆盖的独立文件，避免重复计数。筛选后最多搜索 32 篇，单篇 64 KiB、合计 128 KiB。排除项不读取磁盘正文，现有打开文档的核验照旧。
3. 无条件、原有窄范围、原生索引及下拉框选项沿用既有路径。目录命中和独立文件命中使用已有的定位入口。

## 最小验收

- 两个目录合计超过 32 篇并有独立文件时，无筛选仍受限，加入条件后只读取匹配文档。验证目录及关闭标签的独立文档都可定位。
- 核对 256 条合计预算、筛选后篇数和字节、重复覆盖、未匹配超限文件及旧范围失效。
- 正式包回归，真实 WK 验证混合范围筛选、命中和正常退出。
