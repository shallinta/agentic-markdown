# F-032b 主副区路由与高度实验

## 功能说明

实验台用合成文档验证打开和显式移区的完整状态变化。同一文档只留一份。打开副区满载时，新文档回到主区；显式移入满载或收起的副区时，文档留在原位。移出副区时按已验证的相邻规则转移高度，最后一篇离开后收起副区。

## 最小方案

把 F-032a 的路由和 F-034a/c 的高度计算接成一次状态更新。实验使用独立的 66 px 副区和固定编号。布局展开、收起、活动区域和文档列表可独立观察；按钮模拟文件树双击和显式移区，普通窗口不接入。不决定主区激活项移走后的下一活动标签；实验此时暂不激活其他标签。

## 最小验收

- 展开空副区，打开两篇后恰好满载。重复打开已有实例只激活；第三篇回主；尝试移入失败，两个区域及高度不变。
- 把副区一篇移入主区，剩余一篇取得全部高度。收起后打开新文档走主区；尝试打开已有但不可见的副区文档，不改变归属。重新展开后把最后一篇移出，副区收起。
