## 最小实现

1. 用例启动真实扫描，按当次根句柄与扫描代取得新快照。缓存查询前后分别复核授权与文件版本，传入当次范围键及行 ID 和原文。
2. 核对冷建、关闭工作区后以新句柄重扫并重开、同路径新正文的增量。用当次快照映射命中，逐一比对合成正文预期的 UTF-16 位置。
3. 核对过期凭据拒绝、异范围的缓存拒绝，以及原生返回后正文变化时丢弃结果。后一次验证仅证明发布时检查已执行，不撤销之前的缓存写入，也不证明旧正文已擦除。
