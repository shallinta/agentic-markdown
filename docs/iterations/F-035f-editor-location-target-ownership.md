## 功能说明

快速打开后的聚焦和窗口正文搜索的命中定位，只使用目标文档当前会话的活动视图。后台视图、过期的登记和已经排队的旧通知都不能抢走焦点或定位。

## 最小方案

两种定位目标分别按文档、编辑会话和登记身份保存。保留快速打开的等待与消费规则、正文定位的超时及版本复核。回调准备就绪前后检查活动归属，复用视图重读后刷新登记；搜索、授权和标题折叠规则不变。
