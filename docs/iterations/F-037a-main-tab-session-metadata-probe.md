## 功能说明

验证跨进程能否读回一组主区常驻标签的顺序、固定状态、模式和活动项。先用隔离夹具验证目录内的已保存文档，为后续重授权解析准备数据边界。

## 最小方案

- 使用独立的版本化实验文件和严格的设置存储。每行只含持久根 ID、根相对 Markdown 路径、文件身份指纹、固定状态和模式。顺序由数组表达，活动项引用该数组。测试容器使用显式隔离目录。
- 记录有界，重复路径、无效活动项、未知字段和非预期格式拒绝。旧格式、未来版本和损坏记录保护原字节。写入失败时核对已观察结果，读取不触发写盘。
- 本片不接入正式主窗、启动或退出；不恢复授权、不自动打开文件、不写入正文、撤销历史、临时预览或副区状态。真实重授权后的定位与文件身份复核由下一片验证。

## 最小验收

- 两个同名根的合成标签由一个进程写入，另一个进程复读顺序、固定状态、模式和活动项。确认没有标签运行时句柄或正文落盘。
- 验证重复、格式保护、容量和失败保全。使用正式包内 Bun 复跑隔离实验，普通主窗启动与退出回归。
