# F-029c 恢复文件树手动展开状态

## 功能说明

通过系统选择器重新授权同一个目录后，恢复上次手动折叠的根和手动展开的子目录。文件树按已有扫描进度显示匹配的节点。

## 最小方案

- 复用 F-029b 的稳定根记录 ID。用单独的版本化 App 数据文件保存根折叠和已展开子目录的根相对路径。约束条目数和字节数，受保护的旧格式、损坏和未来版本保留原字节。
- 手动操作传当前根及节点句柄和期望状态。后端仅在目录仍已授权、当前代际匹配且节点在当前可见扫描中时解析相对路径。历史路径和旧句柄不参与授权、扫描或索引。
- 投影只返回当前已扫描节点的句柄，和文件树节点分页分开。随着扫描进度补应用；用户本次手动操作优先于迟到的恢复回复。临时定位或新建引发的自动展开留在当前窗口。
- 已删除的根记录 ID 不会复用，旧展开状态无法绑定新根。按当前已确认名册清理过期条目。目录被不同父根覆盖时保留各根的独立语义，后续再处理状态迁移。

## 最小验收

- 两个同名目录分别手动展开不同子目录，退出重启后依次通过选择器重授权。核对根折叠、深层展开、侧栏焦点和文件树内容。
- 受控测试核对逐页补到节点、隐藏与代际变化、手动状态覆盖迟到回复、精确重选和移除后的身份隔离。历史记录只在匹配当前授权后用于界面。

## 实施记录

- 独立存储使用版本化 `workspace-expansion.json`，最多 32 个根、每根 1,024 个目录、合计 4,096 个目录，文件上限 1 MiB。根默认展开，子目录默认折叠。最后一个非默认状态消失时移除该根记录。
- 独立复跑 7 项、87 次断言通过。覆盖同名根隔离、默认状态、严格格式和容量边界、保留原文件及写入失败后重试。纯读取缺失文件不落盘，首次默认写入可能建立空记录文件。
- 接入时丢弃受保护存储返回的旧快照。只有确认名册的持久状态后才可清理旧记录，确认期间仍需核对当前授权代际。
- 工作区先根据实时根和扫描代际核对目录句柄，名册再串行核对实时记录与磁盘记录的路径和 ID。读取响应只返回当前扫描的目录句柄，写入前在存储事务内再次核对凭据。存储、服务、授权及原有名册定向合计 25 项通过、258 次断言。
- 客户端合并同根的扫描进度并逐根请求恢复，用户手动操作立即覆盖恢复结果。自动定位和新建引发的展开只用于当前树。写入独立于恢复读取提交，由后台按到达顺序处理，正常退出先排空已接收的写入。
