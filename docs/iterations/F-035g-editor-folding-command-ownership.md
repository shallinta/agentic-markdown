## 功能说明

标题、代码围栏和 Frontmatter 的折叠命令由当前活动文档的视图处理。后台视图登记或卸载时，不会覆盖当前文档的折叠入口。

## 最小方案

三个命令统一由文档面板注册，再按活动文档、会话和视图身份调用已有折叠逻辑。沿用编辑与源码模式、Frontmatter 仅编辑模式、只读也可折叠、中文候选与选区保护。独立阅读窗口不变。

## 最小验收

- 控制器测试覆盖活动切换、后台登记、同文档重读和旧释放，验证命令只交给当前视图。
- 真实普通窗口验证标题快捷键与按钮、代码折叠、Frontmatter 的模式边界；切换标签和重读后继续操作。夹具字节不变。
