# F-069a 记录多标签状态与性能基线

> 状态：隔离基线经受托验收通过，沿用已验 alpha.269。以已验收的编辑器状态和标签切换为观察对象。

## 功能说明

用固定合成文档复跑 1、5、20、50 个标签的打开、切换和关闭。先验证多标签使用中权威正文、未保存状态、选区、模式和撤销历史可找回，再记录各阶段耗时及进程内存观察。结果供后续 F-039 判断哪些资源值得回收。

## 最小方案

- 在已验包的 Bun 中直接运行实际文档控制器，只替换文件授权和读取入口为固定合成快照。各档用独立子进程，保持输入与执行顺序可复跑。
- 记录档位、正文大小、操作次数、阶段耗时及 RSS/heap 观察值。校验正文、版本、选区、模式和撤销，检查非活动语法树是否驻留。结果没有固定性能门槛。
- 运行器只用匿名样本、临时数据和有界操作。先以主线、独立运行核对状态回执，再保留性能差异。Bun 控制器数据不代表 WK 原生窗口内存或真实输入耗时。

## 最小验收

- 每档独立运行后正常退出。不同档位的控制器行为符合固定样本预期，撤销后正文逐字节一致。首轮失败保留并另行复验。
- 记录两次运行的机器、包版本、运行时、样本与测量口径。数字用作同条件对照，后续另行测量实际 WK。

## 继承约束检查

- F-002 本机合成输入，不涉及用户文件或断网。
- 中文与外观无新增产品界面。
- 命令与键盘使用控制器入口验证状态，窗口实操另计。
- 安全与日志只记录匿名标识、校验和及统计，隔离运行不读取现有工作区。

## 验收记录

- 主线与独立复跑均用 alpha.269 / `2fwylu3393c17` 包内 Bun 1.4.0 执行同份源控制器，机器为 Apple M1 Pro arm64。每次使用隔离 HOME 和 TMPDIR，四个档位各在独立子进程运行。父子均自然退出 0，标准错误为空，临时目录为空。类型、Lint、文档及差异检查通过。
- 每篇合成文档恰好 4096 字节，含 BOM、CRLF、中文和 emoji。1、5、20、50 标签的实际切换次数分别为 0、9、39、99，撤销次数为 1、2、7、17。逐标签核对基线身份与摘要、原文、未保存状态、缓冲区版本、选区、模式及位置标记。撤销后原文恢复，关闭后控制器不再持有这些编辑状态。
- 打开和切换阶段抽点中只有活动标签保有语言配置与非零语法树，且每次实际切换后的旧标签无语言配置、树长为零。关闭后解析归属为零。此检查观察控制器中的派生树，不衡量运行时垃圾回收或 WK 编辑视图。
- 50 标签的实际切换中位数，主线约 0.649 ms，独立约 0.628 ms。主线/独立 RSS 在打开后约 120.0/120.9 MiB，切换后约 141.6/141.5 MiB，关闭后约 142.4/142.5 MiB。RSS 和 heapUsed 是阶段采样，基线包含合成快照队列。计时为控制器调用，未强制 GC、未测峰值、真实磁盘、渲染或自然键盘。两次结果不用于门槛，也不能单独归因留存内存。
- 两份回执排除时长及内存采样后语义一致，另由独立脚本重算合成文档摘要与计数。源脚本试配全局 TypeScript 覆盖时遇到 Lezer 实例重复，正式执行沿用桌面依赖实例，无全局覆盖。F-039 / OBL-024 的真实窗口观察与缓存策略、最终离线仍开放。
