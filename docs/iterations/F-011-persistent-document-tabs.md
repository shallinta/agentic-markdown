## 1. 功能说明

- 主区提供常驻标签栏，标签显示文件名和关闭按钮；同一文档最多一个标签，重复打开只激活已有标签。常驻不等于固定标签或跨重启恢复。
- 文件集合和打开标签分离：关闭标签不移除侧栏文件、不删除磁盘文件；从侧栏再次打开可重建标签。文件选择、侧栏打开沿用当前显式打开入口，正式临时预览由 F-032 处理。
- 切换已打开标签保留本轮只读快照，不因切换自动重读磁盘；显式“重新读取”才刷新。快照、身份、保真元信息一致，不创建多份正文视图。每文档可暂存当前运行期原文滚动位置，不宣称已完成稳定内容块锚点。
- 关闭非活动标签不改变活动文档；关闭活动标签优先激活右邻，没有右邻则左邻；全部关闭后显示无活动文档的空状态，保留侧栏集合。当前只读无未保存变更，不弹放弃确认；脏文档确认由 F-017 接入。
- 不实现编辑、保存、预览标签、排序、固定、MRU、分栏或重启恢复；不扩大 1 MiB 限制。

## 2. 最小技术方案

- 扩展现有文档控制器，分离文件集合和常驻标签快照；使用 documentId 保持唯一实例，现有 locationId 仅辅助当前规范化路径去重。复用现有授权，不让关闭标签导致仍在集合内的文件失去可重开入口。
- 同路径重新选择返回新句柄时，后端不在前端接收前撤销旧句柄；前端成功接收后更新集合/标签句柄并释放旧句柄，丢弃的迟到候选仅释放自身新句柄。两者仍限同一文件只读权限，不扩大授权范围；清空释放所持句柄。
- 标签切换只切换当前引用，正文视图仅挂载活动文档；成功重读原子更新对应标签。读取失败保留原快照，关闭/清空/切换不允许迟到结果复活标签或覆盖别的文档。
- 新增轻量标签组件，关闭按钮不嵌套在按钮中；键盘入口与原生命令可用性一致。复用现有 React 与样式依赖，不引入标签框架。
- 当前只读标签保留各自快照，记录内存成本，不提前设计未来缓存淘汰系统或固定性能门槛。

## 3. 最小 happy path

1. 打开 A/B，出现两个标签；重复打开 A 不增加标签，documentId 不变。
2. A/B/A 切换保持快照及诊断对应，不自动请求读取；显式重读更新当前文档。
3. 关闭非活动及活动标签，验证邻项规则；全部关闭侧栏保留，重新打开正常。
4. 检查关闭命令、键盘激活和窄窗口可达性；错误或迟到响应不新增幽灵标签、不覆盖当前状态；样本磁盘内容不变。
