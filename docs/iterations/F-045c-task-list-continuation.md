## 精确最小生产方案：任务参与与失败原子性（待主线批准，未编码）

1. **一次局部预检，三态结果。** 原始state/selection进入最外层调用时，收集`none / task / unknown`，不在递归中重新用不同偏向推断。空光标与非空范围端点统一使用主planner同一`resolveInner(-1)`及必要`(+1)`的ListItem祖先解析，去重；非空范围另查询相交公开块节点，查被范围覆盖的ListItem/首内容Paragraph，即使起点在普通段落也不能漏任务。只下探Document/List/Item/Quote等可能容器，跳过inline与code/HTML叶子；marker读取仅首内容固定前缀，不扫正文字符串。边界相邻节点只用于确定实际归属/是否触及，不把完全不相交邻项自动变为任务操作。
2. **可靠性与有界性。** 预检合并重叠选区窗口，使用当前state的树、既有保护区与公开覆盖判断；相关范围超过现LONG_LINE_UNITS聚合查询预算、保护/partial使无法确定祖先或被覆盖任务时结果为unknown，立即整次普通Enter。不得同步ensure全篇、canonical热路径或每range全文遍历。完全可靠且确认无任务的none继续原算法原递归行为；unknown不能伪称无任务。这是新任务适配的保守可靠性回退，不新增文件大小限制，也不把未知样本当作已证明的无任务兼容。
3. **统一任务领域。** 任务参与不依赖widget可见性或非空正文；首内容任务前缀及空`[ ]`/`[x]`/`[X]`均需识别。使用公开ListItem首内容节点与既有itemAt结果核前缀；没有可靠首内容节点时仅已有可证明列表标记之后的有限前缀可用于判定unknown，不能凭regex授权续写。marker触及、跨结构删除、正文不在允许位置等在task上下文标失败，不返回一个可与其它成功任务拼接的普通Plan。
4. **失败传播贯穿整个计划。** task上下文从最外层传入内部规划，只保存本次同步调用，不建全局状态。`getGroup`失败、保护/partial、父组提升失败、编号越界、缩进不可保真、结构删除冲突、任何invalid集合及最终edits碰撞，只要本次有任务参与即返回统一失败；不继续排除组递归以保住另一任务结果。无任务上下文仍走原有组退休/递归逻辑，不改旧CommonMark策略。实现优先内部result联合类型或局部失败标记，入口统一处理，避免每个分支直接dispatch。
5. **一次提交或一次原回退。** task计划全部成功才构造唯一最终state.update；task/unknown失败由外层对原始state完整selection调用一次公开insertNewlineAndIndent，返回该原事务，不调用改写后的planner二次模拟、不先提交成功范围。soft沿同一原子规则：失败回既有普通入口，不声称所有复杂结构soft均已支持。当前view/controller/IME/readonly入口沿原实现，不新增capture、原文通道或历史引擎。
