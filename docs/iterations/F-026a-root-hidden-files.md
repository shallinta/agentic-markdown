## 功能说明与范围

按已确认 W-16 / 基础结论 324，为每个 folder root 提供一个“显示隐藏文件”开关，默认关闭；开启后扫描与最小文件树统一纳入隐藏 Markdown 及其必要祖先，仍只展示 `.md` / `.markdown` 有效分支。`.git` 目录及其后代永远排除，目录 symlink 不递归，文件 symlink 沿用 F-025 授权与过滤。

每根偏好保存到 App 数据区、不写用户目录。重新显式加入同一规范根时复用偏好；此偏好不是权限，不恢复根集合、不自动授权或扫描历史路径。根集合/会话恢复留 F-029，侧栏隐藏/宽度及其他完整树交互留 F-026 后续，搜索/索引/watcher 在相应消费者接入同一策略，不宣称本片已实现它们。

隐藏开关改变发现和显示，不撤销已经打开的有效文档授权。原本通过单文件选择器显式打开的隐藏 Markdown，仅在实际被目录扫描覆盖后移除重复独立入口；关闭显示隐藏后恢复其显式 standalone 入口。仅从目录派生打开的隐藏文档在关闭隐藏后保留原标签和已有授权，但不因此新增 standalone 入口或独立授权。documentId、正文、dirty、撤销历史、模式及位置不因切换改变；`.git` 不享有该例外。

本片无主承接义务，声明 `none`；OBL-008 的主承接仍为 F-025，本片仅协作消费安全过滤并验证树集成，不关闭该义务。硬前置为 F-025a 安全扫描/树、统一命令和 App 设置存储边界；F-022b 资产授权保持，不用显示切换撤销有效 scope。

## 最小技术方案

1. 后端为每根维护 `showHidden` 值，默认 false；复用 App 数据区设置机制，以后端规范根定位读取偏好，持久数据仅是布尔显示偏好，不是 capability。只有通过本次目录选择/授权核验后才应用设置；损坏设置安全回退、写入失败中文提示，不写工作区。
2. 开关经中文统一命令及每根可聚焦控件调用，renderer 只提交 root opaque handle 与布尔意图。后台校验根和请求，传递同一隐藏策略至扫描 Worker；`.git` 硬排除在开关之外，既有 fd 相对遍历与链接安全不放宽。
3. 切换使该根扫描代次更新，取消/丢弃旧扫描页和迟到结果、渐进重扫；继续使用既有有界队列与派生缓存保护，不读正文或同步全树遍历。不影响其他根策略，不把逻辑取消当作阻塞 I/O 硬取消；paused/partial 状态保留准确提示，快速开关以最后选择为准。
4. 独立入口来源由后端权威元数据区分“已有显式单文件授权”与“仅目录派生”，不能仅按当前树是否可见推断。保留原显式授权，只有实际扫描覆盖才去重；关闭隐藏后仅恢复原显式入口，不为派生文档制造新授权。显示过滤不释放已开 grant、重读正文或更改资产授权代次；实际根撤销、身份变化仍走既有授权保护。
5. 开关状态持久化与扫描状态分离；快速切换写入须保证最终偏好一致，避免旧异步回执覆盖新意图。只保存本片偏好，不提前实现根恢复、完整 schema 或索引系统；资源与性能按真实样本记录，不预设数值门禁。

## 已核对的现状差异

当前 `StandaloneFileList` 仅凭 `coveredHandles` 和已加载树节点过滤全部文档 entries，没有显式/派生来源区别。因此不能只修改扫描器过滤：否则关闭隐藏时，仅目录派生的隐藏文档也可能出现在独立列表。本片须补齐来源元数据与显示判断，测试原授权保留及不新增独立授权；这是落实上述既有入口语义的必要接线，不将现状描述成已经支持。

## 最小 happy path 与异常验证

- 两根各含普通/隐藏 Markdown、隐藏目录有效分支、空目录及 `.git`：默认隐藏，开启仅目标根显示有效隐藏分支，`.git` 与危险链接始终排除；关闭恢复，其他根不变。
- 同一规范根再次显式加入或新进程重新授权后读取持久偏好；不自动恢复根或读取未重新授权路径。损坏设置与写失败安全处理，用户目录无设置文件。
- 显式隐藏单文件→开启根隐藏并实际扫描覆盖→关闭：独立入口消失再恢复，唯一文档身份与 dirty/历史/模式保持；仅目录派生隐藏文件关闭显示后保留标签，不新增独立入口或独立授权。
- 先目录派生打开、再通过单文件选择器显式选择同一文件：后端记录新增显式来源，不能永久以首次打开方式判断；之后关闭隐藏时恢复独立入口而不重复正文身份。
- 快速 on/off/on、扫描中关闭、迟到页及过期句柄均只显示最后策略；局部失败/预算暂停不伪装完成；重新扫描不撤销已开正文/资产授权。
- 真实 WK 通过每根控件和键盘/统一命令切换，核对树、显式入口与已开状态；浅/深/系统下中文开关及焦点可辨。按 alpha 规则构建，独立复核与受托代验后再记通过；受控竞态测试不冒充 UI 实操。
