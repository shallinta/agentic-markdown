## 功能说明与最小方案

- 自有 Markdown 解析适配和 CM 视图插件出现异常时，只隔离当前打开文档，退出解析、高亮和即时排版，保留控制器最后有效原文、选区、撤销历史与保存状态，进入可编辑保存的纯源码。
- 解析适配捕获同步及后台 advance 异常，以空语法结果完成当前解析；故障实例锁定，不再次调用故障解析器。视图 exceptionSink 异步调度同一路径，不在 CM 更新中重入。
- IME 候选期间暂缓视图重配置，提交后降级；关闭确认/busy 时等待可交互状态。只保留已进入有效 EditorState 的内容，不承诺未提交的系统候选字串。
- 隔离后本次打开期间不能通过模式快捷键重新启用故障模块；关闭后重新打开才重新尝试。保存、授权和 RPC 错误不作为编辑故障处理。
- 独立 `AGENTIC_MARKDOWN_EDITOR_FAULT_LAB=1` 启动环境开关才显示两个一次性注入按钮；注入由显式按钮触发，不通过 Markdown 内容触发，不写盘，不自动保存。正常启动不显示实验入口。
- 不覆盖进程崩溃、OOM、无限循环、CM 核心/原文历史损坏及未来阅读模块。恢复本身失败只报告固定错误、不循环，不声称已成功恢复。
- OBL-069/070 仅本片安全源码外观与上下文得到接入，完整高亮扩展、阅读返回与其他后续消费者仍保持开放；父 F-013 未完成。
